KAPE — Kroll Artifact Parser and Extractor
Targets — Ce qu'on collecte
  • !BasicCollection — artefacts essentiels (< 5 min)
  • !SANS_Triage — recommandations SANS
  • Windows_EventLogs — tous les EVTX
  • Prefetch — fichiers prefetch
  • RegistryHives — toutes les ruches
  • BrowserHistory — Chrome, Firefox, Edge
  • MFT — Master File Table
Modules — Ce qu'on parse
  • !EZParser — tous les outils Zimmerman
  • MFTECmd — parse la MFT
  • EvtxECmd — parse les Event Logs
  • PECmd — parse le Prefetch
  • RegRipper — extrait le Registre
  • Hayabusa — règles Sigma sur EVTX
💡 KAPE = entièrement gratuit, développé par Eric Zimmerman. Lancer depuis une clé USB forensique — ne jamais installer sur la machine suspecte.
Velociraptor — DFIR à grande échelle
Architecture & Capacités
  • Serveur + agents légers sur tous les endpoints
  • Collecte sur 10 000+ machines simultanément
  • Interrogation en temps réel (processus, connexions)
  • Chasse aux menaces (threat hunting) à l'échelle
  • Intégration Sigma / YARA rules
  • Open source gratuit
VQL — Velociraptor Query Language
-- Processus avec hash sur tous les clients
SELECT Pid, Name, Exe, Hash.MD5
FROM pslist()
WHERE NOT Name IN ('svchost.exe')
ORDER BY CreateTime DESC
