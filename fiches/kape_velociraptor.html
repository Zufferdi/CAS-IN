🎯 Triage DFIR à l'ère des incidents massifs
Face à un incident touchant 100 ou 10 000 machines simultanément (ransomware, supply-chain attack, APT), faire une image disque complète par machine est impossible — temps prohibitif, espace de stockage colossal, impact opérationnel inacceptable. Deux outils gratuits ont radicalement transformé l'approche : KAPE (Kroll Artifact Parser and Extractor) collecte les 1500+ artefacts forensiques essentiels d'un système Windows en moins de 5 minutes ; Velociraptor (Rapid7) déploie des agents sur des milliers d'endpoints et permet l'interrogation en temps réel via VQL (Velociraptor Query Language). Ces deux outils sont devenus standards industriels en réponse à incident.

🎯 KAPE — Kroll Artifact Parser and Extractor
Outil ligne de commande Windows · 100% gratuit · développé par Eric Zimmerman.
🎯 Targets — Ce qu'on collecte
  • !BasicCollection — artefacts essentiels (< 5 min)
  • !SANS_Triage — recommandations SANS
  • Windows_EventLogs — tous les EVTX
  • Prefetch — fichiers prefetch (.pf)
  • RegistryHives — toutes les ruches (SAM, SYSTEM, NTUSER, UsrClass)
  • BrowserHistory — Chrome, Firefox, Edge
  • MFT — Master File Table
  • USNJournal — journal NTFS
  • RecycleBin — fichiers supprimés
⚙️ Modules — Ce qu'on parse
  • !EZParser — tous les outils Zimmerman
  • MFTECmd — parse la MFT
  • EvtxECmd — parse les Event Logs
  • PECmd — parse le Prefetch
  • RegRipper — extrait le Registre
  • Hayabusa — règles Sigma sur EVTX
  • SrumECmd — System Resource Usage
  • Sortie : CSV / JSON exploitables
💻 Commande KAPE typique — Triage complet
# Lancer KAPE depuis clé USB forensique (E:\)
# Cible C: · Output sur le même USB · Targets + Modules en chaîne
.\kape.exe --tsource C: --target !SANS_Triage --tdest E:\KAPE-Output\Targets --mdest E:\KAPE-Output\Modules --module !EZParser --mflush --zip incident-001

# Sortie : ZIP horodaté avec hash SHA-256, prêt pour le rapport

🔍 VQL — Velociraptor Query Language

Langage SQL-like pour interroger les endpoints :

-- Processus suspects sur tous les clients
SELECT Pid, Name, Exe, Hash.MD5
FROM pslist()
WHERE NOT Name IN ('svchost.exe',
                   'explorer.exe',
                   'System')
ORDER BY CreateTime DESC

🧠 Testez-vous
Vous arrivez sur scène. 1 PC suspect allumé, écran déverrouillé. Vous avez 30 minutes avant transport. Quel outil ?Choix outil · Niveau : facile
KAPE. Une machine unique, ponctuel, on-site, time-boxed → KAPE est l'outil idéal. Workflow : (1) RAM dump avec WinPmem (priorité 1, RFC 3227), (2) lancer KAPE depuis clé USB forensique avec !SANS_Triage + !EZParser (env. 5-10 min selon volume), (3) calculer hash SHA-256 du ZIP de sortie, (4) sceller la machine. Velociraptor serait surdimensionné ici — il faut un serveur + déployer un agent, ce qui prend plus de temps que la fenêtre disponible.
Une entreprise vous contacte : ransomware sur 800 postes, tous chiffrés. Quel outil ?Incident massif · Niveau : moyen
Velociraptor. 800 endpoints en parallèle = impossible avec KAPE (manuel par machine). Workflow : (1) déployer agents Velociraptor par GPO/SCCM (10-30 min sur l'AD), (2) lancer hunts simultanés sur les 800 hôtes : recherche de l'extension du ransomware, des process suspects, des connexions C2 — tout en VQL, (3) identifier le patient zéro et la chronologie, (4) isoler les hôtes encore actifs (kill processus à distance), (5) collecter artefacts pour le rapport. Bonus : VQL permet aussi de chasser les persistance mechanisms du ransomware (services, scheduled tasks, run keys) sur les machines pas encore chiffrées.
Quelle différence entre un Target et un Module dans KAPE ?Architecture KAPE · Niveau : facile
Target = COLLECTER · Module = PARSER. (1) Target définit quels fichiers/artefacts copier depuis la machine source vers la destination (ex: !SANS_Triage copie la MFT, les Event Logs, le Prefetch, etc.). C'est de la copie brute. (2) Module définit quel outil de parsing exécuter sur les fichiers déjà collectés (ex: MFTECmd parse une MFT brute en CSV lisible). C'est de l'analyse. KAPE permet d'enchaîner Target + Module en une seule commande : --target X --module Y --mflush. C'est ce qui en fait un outil de triage complet et non juste un outil de copie.
🎓 À retenir pour la pratique — KAPE & Velociraptor

KAPE = Kroll Artifact Parser and Extractor (Eric Zimmerman, gratuit, désormais distribué par Kroll/Duff & Phelps)

Targets (collecte) + Modules (parsing) — deux concepts distincts à ne pas confondre · Targets définissent quoi collecter, Modules comment parser le résultat

!BasicCollection = artefacts essentiels en moins de 5 minutes (Registre + EventLogs + Prefetch + MFT + USN)

!EZParser = compound module qui enchaîne tous les outils de la suite Zimmerman après la collecte

Lancer KAPE depuis clé USB forensique — jamais installer sur la machine suspecte (principe P1 ACPO : pas d'écriture sur preuve)

Velociraptor = serveur + agents (Rapid7) · DFIR à l'échelle · hunting continu

VQL = Velociraptor Query Language (syntaxe SQL-like) pour interroger des milliers d'endpoints simultanément

10 000+ endpoints en parallèle · live forensics · threat hunting · acquisition à distance

Choix d'outil : KAPE = 1 machine ponctuel sur scène · Velociraptor = flotte entière en continu
