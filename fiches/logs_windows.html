Lateral Movement — à surveiller
  • 4624 Type 3 entre postes internes → mouvement latéral SMB
  • 4624 Type 10 depuis un poste vers un autre → RDP interne suspect
  • 4648 + compte admin → pass-the-hash ou runas suspect
  • 7045 sur plusieurs machines → service de propagation
  • 4698 suivi de 4624 Type 3 → persistance à distance
Outils d'analyse
Chainsaw

Analyse EVTX rapide basée sur des règles Sigma. Détecte les patterns d'attaque connus.

# Chasse rapide aux attaques
chainsaw hunt C:\evtx\ --rules rules/ --mapping mappings/sigma-event-logs-all.yml
Hayabusa

Analyseur japonais rapide — génère des timelines forensiques et des alertes de niveau MITRE ATT&CK à partir des EVTX.

# Timeline CSV en 1 commande
hayabusa csv-timeline -d C:\evtx\ -o timeline.csv
💡 PowerShell ScriptBlock Logging (4104) : Même si le script utilise des techniques d'obfuscation (base64, IEX, Invoke-Expression), Windows décode le script avant exécution et l'enregistre décodé dans l'Event 4104. Une des sources forensiques les plus précieuses contre les attaques "living off the land".
