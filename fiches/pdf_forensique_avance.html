🏗️ PDF Format = Container Structuré (ISO 32000)
PDF = composition de objects (text, images, streams). Structure = File header → Objects → xref table → trailer. Chaque élément géolocalisable forensiquement.
Anatomy: File Structure
PDF File Structure (Hex View)

Offset 0x000 | %PDF-1.7 ← File Header (magic bytes)
# Comments, metadata, version

Offset 0x100 | 1 0 obj ← Object 1 (catalog)
          stream
          ...
          endstream
          endobj

Offset 0x500 | 2 0 obj ← Object 2 (pages)

Offset 0xXXX | xref ← Cross-reference table
          0 15
          0000000000 65535 f
          0000000256 00000 n

Offset 0xYYY | trailer ← Trailer (metadata de fichier)
          startxref
          5678
          %%EOF ← File terminator
Key Forensic Elements
  • xref offset = Pointer à cross-reference table (où est le catalog)
  • Object IDs = Références internes (object 1 peut pointer object 5)
  • Streams = Compressed binary data (images, fonts)
  • Incremental updates = Versions antérieures du fichier (recovery possible)
📝 PDF Metadata = Document Properties
Métadonnées stockées dans objet special "/Info" ou dans streams. Révèlent : auteur, dates de création/modification, application, titre, etc.
Propriétés Standard PDF
Propriété Type Forensique
/Title String 👤 Intention du document (confidentiel?)
/Author String 👤 ✅ SIGNATURE (qui a écrit?)
/Subject String 📌 Contexte (résumé document)
/Keywords String 🔑 Tags (révèle contexte)
/CreationDate Date (D:YYYYMMDDhhmmss) 📅 Quand créé
/ModDate Date 📅 Dernière modification (important!)
/Producer String 🛠️ Quel logiciel (Adobe, LibreOffice?)
/Creator String 🛠️ Outil d'origine (Word, Excel?)
⚠️ Métadonnées Modifiables!
Tout peut être édité (Author, dates, titre). Incohérence forensique = suspect.
Exemple : Document dit "créé 2024-01-01" mais modification log dit "2024-03-20" = edited tardivement (coverup?)

📦 Hidden Objects = Embedded Data
PDFs peuvent contenir objects cachés : fichiers attachés, images, OLE objects, annotations, streams comprimés.
Types Objects Cachés
🚨 Embedded Files
EXE, DLL, macros
/EmbeddedFile stream
Often malware vector
Recovery: Extract + scan
🚨 Annotations
Comments, highlights
/Annots array
Author metadata
Can reveal reviewer names
🚨 JavaScript
/AA (Auto-action)
Runs on open
Malware delivery
Highly suspicious
🚨 OLE Objects
Embedded Office docs
/ObjStm streams
Macro-enabled sheets
Recovery: Extract as .ole
🔍 Detection Objects Cachés
# Chercher streams non-standard
/EmbeddedFile, /ObjStm, /AA, /OpenAction

# Tools: pdfminer, mutool, strings
$ strings file.pdf | grep -i "objstm\|embed\|javascript"
🔄 Incremental Updates = Versions Antérieures
PDFs peuvent être "updated" sans rewriting complet. Chaque update = nouveau xref table + trailer. Anciens objects = récupérables!
Mechanism: Update Process
Scenario : Document Modifié
Version 1 (Original)
├─ xref (points to objects)
└─ trailer (version 1)

[Éditeur ouvre + modifie + sauvegarde]

Version 2 (Updated)
├─ [OLD xref + trailer from V1]
├─ [NEW objects added]
├─ xref (NEW, points to V1 + new)
└─ trailer (version 2, links to V1)

→ Forensique: Extraire V1 objects = voir ce que changé!
✅ Recovery Versions Antérieures
  1. Identifier tous xref offsets (rechercher "xref" dans fichier)
  2. Extraire chaque trailer (liens entre versions)
  3. Reconstruire object trees pour CHAQUE version
  4. Dump text content de chaque version
  5. Timeline éditions (qui, quand, quoi changé)

CLI Quick Commands
# Extract metadata
$ pdfinfo document.pdf
$ exiftool document.pdf

# Extract text
$ pdftotext document.pdf - | less
$ pdfminer.six document.pdf

# Inspect structure
$ mutool info document.pdf
$ qpdf --qdf document.pdf document-out.pdf

# Find xref tables (incremental updates)
$ strings document.pdf | grep "^xref"
$ hexdump -C document.pdf | grep -B2 -A2 "78 72 65 66" # xref in hex

# Extract embedded files
$ mutool extract document.pdf # extracts all resources

# Search for suspicious strings
$ strings document.pdf | grep -i "javascript\|openaction\|embed"
✅ Workflow Complet PDF Forensique
  1. pdfinfo → Extraire metadata (Author, Dates, Producer)
  2. strings/mutool info → Chercher objects cachés (EmbeddedFile, JavaScript)
  3. mutool extract → Extraire embedded files + images
  4. grep "^xref" → Identifier incremental updates
  5. qpdf --qdf → Linearize et faire readable pour inspect
  6. pdftotext → Extraire texte de TOUTES versions
  7. Rapport : Auteur, dates, embedded files, version timeline
