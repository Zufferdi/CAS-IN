🖼 Cacher l'existence — pas seulement le contenu
Là où la cryptographie rend un message illisible mais visible, la stéganographie cache son existence même. Un fichier stéganographié paraît parfaitement normal — une image de chat, un MP3 anodin — et personne ne soupçonne qu'il contient des données. C'est l'arme préférée des attaquants discrets : le fichier ne déclenche aucune alarme tant qu'il n'a pas été analysé avec des outils spécialisés (zsteg, stegdetect, ELA).
🇨🇭 Cas réel : Des réseaux d'espionnage ont utilisé des images publiques (forums, réseaux sociaux) comme canal de communication caché. Les messages chiffrés étaient encodés dans les bits de poids faible (LSB) — invisibles à l'œil nu, indétectables sans outils spécialisés.

Outils de stéganalyse
🔎 Outils de détection
  • zsteg — zsteg image.png — analyse LSB PNG/BMP
  • Stegdetect — stegdetect image.jpg — détection JPEG
  • Binwalk — binwalk image.jpg — fichiers embarqués
  • ExifTool — exiftool -a -u image.jpg — métadonnées cachées
  • Steghide — steghide info image.jpg
🎨 Analyse visuelle & ELA
  • StegSolve — analyse par canal / bit plane (GUI Java)
  • FotoForensics — ELA (Error Level Analysis) en ligne
  • ELA — JPEG re-compressé → zones modifiées apparaissent différemment
  • Histogram analysis — distribution bits LSB anormale
Indicateurs de détection
📊 Indicateurs visuels & statistiques
  • Entropie anormalement élevée pour le type de fichier
  • Taille de fichier disproportionnée vs résolution
  • Métadonnées EXIF absentes ou suspectes
  • Distribution bits LSB non uniforme (test χ²)
  • Fichier JPEG avec peu d'artefacts de compression
📄 Stéganographie dans les documents
  • DOCX — texte blanc sur blanc → sélectionner tout révèle
  • Commentaires / révisions masqués dans le XML
  • Chemins fichiers liés révèlent structure interne
  • unzip -p doc.docx word/document.xml
Workflow de détection

strings image.jpg | grep -i "pass" # Texte caché

stegdetect image.jpg # Détection JPEG statistique

⚖️ Aspect légal : La stéganographie n'est pas illégale en soi en Suisse. Elle devient problématique si utilisée pour dissimuler des preuves (art. 144bis CP) ou dans le cadre d'infractions plus larges. Sa présence dans un dossier pénal est un indice de dissimulation intentionnelle.
Vous trouvez un fichier chat.png de 4 Mo, résolution 800×600. Que conclure ?Détection · Niveau : facile
Taille anormalement élevée pour la résolution. Une PNG 800×600 sans compression devrait peser 1–1,5 Mo maximum. 4 Mo sur ces dimensions = forte suspicion : (1) données embarquées via concaténation (vérifier avec binwalk), (2) stéganographie LSB (vérifier avec zsteg), ou (3) métadonnées EXIF gonflées (vérifier avec exiftool -a -u). Ne pas conclure sans les 3 outils — l'image peut aussi avoir été enregistrée sans compression PNG.
Un suspect a 200 photos JPEG sur son téléphone. Comment détecter rapidement celles qui pourraient contenir de la stéganographie DCT ?Stéganalyse · Niveau : moyen
Lancer stegdetect en batch sur le dossier (stegdetect *.jpg) — il identifie les signatures de Steghide, JPHide, JSteg, OutGuess, F5. Compléter par FotoForensics ELA sur les candidats : les zones modifiées apparaissent en couleur différente. Si DCT plus subtile (encrypted payload), passer en χ² test sur coefficients DCT via outils académiques (StegExpose). Croiser avec : (1) tailles disproportionnées, (2) photos sans EXIF cohérent (caméra/heure/GPS), (3) paires de photos identiques sauf hash (1 originale + 1 stégo).
🎓 Exam Tip — Stéganographie

Différence clé : cryptographie = rendre illisible · stéganographie = cacher l'existence du message

Combo courant : chiffrer d'abord (crypto) puis cacher (stégano) — défense en profondeur

LSB (Least Significant Bit) → PNG, BMP, WAV · détectable par analyse statistique χ²

DCT → JPEG · modification des coefficients DCT après compression · plus difficile à détecter

Outils stéganalyse : zsteg (PNG/BMP) · stegdetect (JPEG) · binwalk (fichiers embarqués) · exiftool (métadonnées)

ELA (Error Level Analysis) : FotoForensics — re-compression JPEG révèle zones modifiées

Indicateurs : entropie élevée pour le format · taille anormale · métadonnées EXIF absentes

Cadre légal : non illégale en soi en Suisse · indice de dissimulation intentionnelle (art. 144bis CP si destruction)

🎯 Essentiel terrain : Stéganographie = cacher l'existence d'un message (≠ chiffrement) · LSB = Least Significant Bit → PNG/BMP · DCT → JPEG (plus difficile à détecter) · Outils : zsteg (PNG), stegdetect (JPEG), binwalk (fichiers embarqués), exiftool (métadonnées) · ELA (Error Level Analysis) = FotoForensics · Taille fichier anormale = indicateur · Non illégale en soi en Suisse.
