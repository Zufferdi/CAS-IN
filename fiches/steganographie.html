Stéganographie Forensique

Détection · Stéganalyse · Images · Audio · Documents · Cas judiciaires

"Steganography doesn't hide that something is secret — it hides that there's a secret at all. The most dangerous hidden message is the one you don't know exists."
— Applied Cryptography, Bruce Schneier
🇨🇭 Cas réel : Des réseaux d'espionnage ont utilisé des images postées publiquement sur des forums comme canal de communication caché. Les messages chiffrés étaient encodés dans les bits de poids faible (LSB) des pixels — invisibles à l'œil nu, indétectables sans outils spécialisés.

🔍 Détection — Stéganalyse

💡
La stéganalyse est probabiliste, pas certaine. La détection repose sur des anomalies statistiques — une image avec stéganographie présente des distributions de bits légèrement anormales, détectables par analyse.

Indicateurs visuels

  • Entropie anormalement élevée pour le type de fichier
  • Bandes de bruit régulières dans l'image (LSB)
  • Taille de fichier disproportionnée vs résolution
  • Métadonnées EXIF absentes ou suspectes
  • Fichier JPEG avec trop peu d'artefacts de compression

Indicateurs statistiques

  • Distribution des bits LSB non uniforme (devrait être aléatoire)
  • Chi-squared test positif (StegDetect)
  • Corrélation inhabituelle entre canaux RGB
  • Histogramme de fréquences des pixels anormal

exiftool image.jpg                    # Métadonnées
binwalk image.jpg                     # Fichiers embarqués
strings image.jpg | grep -i "pass"   # Texte caché
zsteg image.png                       # Analyse LSB (PNG)
stegdetect image.jpg                  # Détection JPEG

📄 Stéganographie dans les documents

⚠️
Documents Office (DOCX, XLSX) : Ces fichiers sont des ZIP — ils peuvent contenir des données cachées dans les parties non analysées ou dans les métadonnées XML internes.
  • DOCX : Texte blanc (taille 1pt) sur fond blanc — sélectionner tout le texte révèle le contenu
  • Commentaires cachés : Réviseurs supprimés mais données XML restant dans le fichier
  • Track changes masqués : Modifications acceptées mais historique conservé dans le XML
  • Propriétés de document : Auteur, organisation, révision — souvent révélatrices
  • Analyse ZIP : unzip -p doc.docx word/document.xml | grep -i "w:rStyle"

⚖️ Cadre légal suisse

La stéganographie n'est pas illégale en soi en Suisse. Elle devient problématique uniquement si elle est utilisée pour dissimuler des preuves (art. 144bis CP — destruction de preuves) ou dans le cadre d'infractions plus larges (trafic, espionnage, pédocriminalité).

  • Découvrir de la stéganographie sans en lire le contenu n'est pas une violation
  • L'extraction du contenu caché peut nécessiter un mandat spécifique si le support est sous scellés
  • La stéganographie détectée dans un dossier pénal est un élément à charge (indice de dissimulation intentionnelle)
