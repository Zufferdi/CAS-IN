💡 Réalité forensique suisse : Les données d'un Amazon Echo, d'une Apple Watch ou d'une caméra Ring apparaissent de plus en plus dans les dossiers pénaux helvétiques. Ces artefacts ne se trouvent ni dans un PC ni dans un smartphone — l'enquêteur non préparé les ignore.

Routeur domestique — mine d'informations négligée
Le routeur domestique est l'un des artefacts IoT les plus riches et les plus négligés. Il contient l'historique de tous les appareils connectés au réseau, souvent pour des semaines ou des mois.
Données extractibles
  • Table DHCP : historique MAC + noms d'appareils
  • Logs DNS : domaines consultés par tous les appareils
  • Journal connexions WiFi : quand chaque appareil s'est connecté
  • Firewall logs : tentatives d'accès bloquées
  • Port forwarding : services exposés, connexions entrantes
Acquisition
  • Interface web (192.168.1.1) + credentials admin
  • FRITZ!Box : export via FRITZ!NAS ou SSH
  • Scan réseau : arp -a · nmap -sn 192.168.1.0/24
  • Préserver AVANT extinction — données volatiles
⚖️ Examen CAS-IN : IoT = assistants vocaux → enregistrements sur cloud provider · Apple Watch / Fitbit = GPS + FC + sommeil (preuve de présence) · Routeur domestique = historique DHCP + DNS de tous les appareils · Demande légale auprès du cloud provider pour le contenu · Préserver AVANT extinction (état peut être perdu) · Ring / Nest Cam → vidéos horodatées sur cloud
