📟 IoT — Les témoins silencieux du quotidien
L'Internet des Objets (IoT) désigne tous les appareils connectés autres que les ordinateurs et smartphones : assistants vocaux (Alexa, Google Home), smartwatches (Apple Watch, Fitbit), caméras (Ring, Nest), thermostats intelligents, ampoules connectées, frigos, balances, brosses à dents… Ces objets collectent des données en permanence : audio ambiant, GPS, fréquence cardiaque, présence détectée, horaires d'activité, accès aux pièces. Pour le forensiste, c'est une source de preuves trop souvent négligée. Affaire emblématique : State v. Richard Dabate (Connecticut, meurtre du 23 décembre 2015 ; condamnation en 2022) — le mari prétend que sa femme Connie a été tuée par un cambrioleur peu après son retour de la salle de sport vers 9h00. Le Fitbit de la victime montre qu'elle a continué à se déplacer dans la maison jusqu'à 10:05, contredisant la chronologie du suspect. C'est l'un des premiers cas où un objet connecté constitue un élément de preuve déterminant — la presse l'a surnommé le « Fitbit murder ». Réalité forensique CH : les données d'un Echo, d'une Apple Watch ou d'une caméra Ring apparaissent de plus en plus dans les dossiers pénaux helvétiques. Ces artefacts ne se trouvent ni dans un PC ni dans un smartphone — l'enquêteur non préparé les ignore. Conséquence : il faut cartographier l'IoT du foyer dès la perquisition (caméra du salon, watch au poignet, Echo à la cuisine…).

🎙 Assistants vocaux — Focus forensique
🟠 Amazon Echo / Alexa
  • Enregistrements audio sur alexa.amazon.com (consultable par l'utilisateur)
  • Historique commandes, achats, alarmes, listes courses
  • Appareils connectés et événements (lumières, thermostat, serrures)
  • Logs d'utilisation des Skills (apps tierces)
  • Données partagées avec autres comptes du foyer
  • Demande légale : Amazon Law Enforcement Request Form
  • Affaire célèbre : Bates v. Arkansas (2016) — premier mandat Echo
🔵 Google Nest / Assistant
  • Activité : myactivity.google.com
  • Historique des requêtes vocales (texte + audio)
  • Agenda et rappels synchronisés
  • Logs thermostat Nest (présence détectée, températures)
  • Caméras Nest : vidéos + détections IA (personne/animal)
  • Demande légale : Google Law Enforcement Portal
  • Routine : actions automatiques par horaire
💡 Activation accidentelle : Les assistants s'activent sur des mots proches du déclencheur (« Alexa » ↔ « Alexis », « Hey Google » ↔ « OK Google ») — des conversations ambiantes peuvent être partiellement enregistrées. Ces enregistrements ont valeur de preuve si obtenus légalement. Bloomberg a révélé en 2019 que des employés Amazon écoutent ces enregistrements pour entraîner les modèles.

🌐 Routeur domestique — Mine d'informations négligée
Le routeur domestique est l'un des artefacts IoT les plus riches et les plus négligés. Il contient l'historique de tous les appareils connectés au réseau, souvent pour des semaines ou des mois.
📊 Données extractibles
  • Table DHCP : historique MAC + noms d'appareils (Apple iPhone de Jean, etc.)
  • Logs DNS : domaines consultés par tous les appareils (révélateur !)
  • Journal connexions WiFi : quand chaque appareil s'est connecté/déconnecté
  • Firewall logs : tentatives d'accès bloquées, intrusions
  • Port forwarding : services exposés, connexions entrantes
  • VPN / Tor : signatures DNS spécifiques détectables
🔧 Acquisition
  • Interface web (192.168.1.1) + credentials admin (souvent défaut)
  • FRITZ!Box : export via FRITZ!NAS ou SSH, fichier config.export
  • Sunrise/Swisscom : interface web, parfois SSH selon modèle
  • Scan réseau : arp -a · nmap -sn 192.168.1.0/24
  • Capture passive : SPAN port (rarement disponible sur box résidentielle)
  • Préserver AVANT extinction — données volatiles (DHCP non persistant)
  • Photographier toutes les LEDs et statuts au moment de l'arrivée
🧠 Testez-vous
Vous arrivez sur une scène de crime. Le suspect dit qu'il dormait. Quels objets IoT pouvez-vous interroger pour vérifier ?Cartographie IoT · Niveau : facile
Cartographier tous les objets connectés du foyer. Témoins potentiels : (1) Smartwatch / Fitbit : pulse cardiaque + activité (sommeil profond ? marche ? mouvement nocturne ?). Si pulse à 90+ et marche détectée à 3h00 = pas en sommeil. (2) Assistant vocal Echo/Nest : déclenchement à des heures suspectes ? Phrase prononcée pendant la nuit ? (3) Caméras Ring/Nest : détection mouvement ? Vidéo de la zone ? Audio capté ? (4) Smart TV : apps ouvertes la nuit ? Watch history ? (5) Thermostat Nest : changements de température (mouvement détecté) ? (6) Serrures connectées (August, Yale) : log des ouvertures/fermetures avec horodatage. (7) Routeur domestique : appareils connectés-déconnectés à quelle heure ? (8) Frigo / four / lave-vaisselle connecté : ouvert/utilisé pendant la nuit ? (9) Apple HomeKit / Google Home centralise certaines actions. Procédure : audit visuel des pièces (chercher microphones, caméras, hubs Zigbee/Z-Wave), scan WiFi du foyer, demandes légales aux providers cloud pour le contenu.
Une caméra Ring a filmé une effraction. Comment obtenir les vidéos ?Caméras connectées · Niveau : moyen
Plusieurs voies : (1) Demander à l'utilisateur (s'il coopère) : il peut télécharger les vidéos depuis son app Ring sur son smartphone, les partager via export. Le plus rapide. (2) Compte Ring du suspect/victime : si saisie du smartphone, l'app Ring permet d'accéder aux vidéos (avec mot de passe / Face ID). (3) Demande légale à Amazon (Ring est filiale d'Amazon) : Law Enforcement Request via portail dédié. Amazon coopère généralement (vs Apple plus restrictif). Délai : quelques jours à semaines pour les non-urgences. Particularité Ring : programme « Neighbors » + collaboration avec polices US — Amazon a des accords pour partager certaines vidéos avec polices locales (controversé). En Suisse : passe par MLAT ou entraide judiciaire. (4) Rétention : Ring conserve les vidéos sur cloud selon plan d'abonnement (60 jours typique, jusqu'à 180 jours premium). AGIR VITE avant expiration. (5) Caméras voisines Ring/Nest peuvent aussi avoir filmé (zone publique = vue trottoir). Format : MP4 H.264 horodaté, métadonnées EXIF avec GPS dans l'app.
Vous saisissez un FRITZ!Box. Que pouvez-vous extraire et combien de temps remontent les données ?Routeur · Niveau : difficile
FRITZ!Box (AVM, leader DACH) est très complet forensiquement. Données extractibles : (1) Liste des appareils sur l'interface web (192.168.178.1) : MAC + nom (« iPhone de Jean ») + dernière connexion + IP attribuée. Rétention : DHCP non purgé = peut remonter à plusieurs mois. (2) Journal système : connexions VPN, ouverture/fermeture ports, redémarrages. Rétention : 7 jours par défaut, jusqu'à 30 jours configurable. (3) Liste WiFi : tous les appareils WiFi historiques avec heures connexions. (4) Téléphonie (FRITZ!Box ont DECT intégré) : appels reçus/émis avec numéros et durées — historique 30+ jours. (5) Repondeur : messages enregistrés (audio). (6) FRITZ!NAS si activé : fichiers sur USB connecté. (7) Configuration export : System → Backup → Save settings → fichier .export chiffré (mot de passe utilisateur). Procédure : (a) photographier les LEDs et l'écran, (b) ne pas couper l'alimentation (perd certains caches), (c) accéder à l'interface web avec credentials par défaut ou ceux du suspect, (d) exporter Configuration + Journal Système + Téléphonie, (e) hash SHA-256 des exports. Si pas accès admin : reset réinitialise le mot de passe mais EFFACE TOUTES LES DONNÉES — ne jamais le faire en forensique.
🎓 Exam Tip — IoT Forensique

Catégories IoT : assistants vocaux · wearables · caméras · domotique · routeurs · véhicules · smart TV

Affaire référence : State v. Richard Dabate (CT, meurtre 2015 → condamnation 2022) — Fitbit prouve que la victime était active alors que le mari prétendait qu'elle avait été tuée plus tôt

Assistants vocaux :

  • Amazon Echo / Alexa → enregistrements sur cloud Amazon

  • Google Nest / Assistant → myactivity.google.com

  • Apple HomePod → Apple Legal Process Guidelines

Wearables : Apple Watch (HealthKit) · Fitbit (cloud) · Garmin (cloud) → GPS + FC + sommeil + ECG + paiements

Caméras connectées : Ring (Amazon) · Nest (Google) · Arlo · Eufy · Wyze → vidéos cloud

Routeur domestique = artefact négligé : DHCP + DNS + journaux WiFi + firewall

Demande légale au cloud provider pour le contenu (audio, vidéo, logs détaillés)

Préserver AVANT extinction : couper le routeur = perte des leases DHCP volatiles

Cartographier le foyer dès l'arrivée — audit visuel + scan WiFi pour identifier tous les objets

Outils : ALEAPP / iLEAPP (companion apps) · Cellebrite UFED (modules IoT) · scan WiFi avec WiGLE

Activation accidentelle : assistants s'activent sur mots proches → conversations ambiantes parfois enregistrées

Rétention typique : Echo/Nest = jusqu'à suppression user · Ring = 60-180 jours selon abonnement · Routeur = 7-30 jours
