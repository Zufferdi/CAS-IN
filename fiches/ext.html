EXT
Forensique Linux Filesystem
Linux Extended File System · Groupes de blocs · Inodes · Journalisation · Récupération
⚠ EXT4 efface les pointeurs de blocs à la suppression (block pointer zeroing). La récupération passe par le journal ou le carving sur l'espace non alloué — contrairement à EXT2 qui laissait les pointeurs intacts.
Structure d'un volume EXT
Superblocoffset 1024, 1024 octets
GDTGroup Descriptor Table
Bitmap blocs1 bit/bloc
Bitmap inodes1 bit/inode
Table inodes128 o/inode (EXT2/3)
DonnéesBlocs de données
Superbloc
  • Toujours à l'offset 1024 octets du début du volume
  • Contient : inode_count, block_count, s_inodes_per_group, s_blocks_per_group
  • Magic number : 0xEF53 (LE : 53 EF)
  • Copies de secours dans certains groupes (sparse_super)
  • s_last_mounted, s_mkfs_time, s_uuid → forensique
Groupes de blocs
  • Volume divisé en groupes de blocs de taille fixe
  • Chaque groupe contient : superbloc (copie), GDT, bitmap blocs, bitmap inodes, table inodes, blocs données
  • Taille typique : 32768 blocs × 4 Ko = 128 Mo par groupe
  • Formule groupe d'un inode : (inode−1) ÷ s_inodes_per_group
L'inode — Cœur du système EXT
Inodes réservés
  • Inode 0 : n'existe pas
  • Inode 1 : liste blocs défectueux
  • Inode 2 : répertoire racine /
  • Inode 7 : quota
  • Inode 8 : journal EXT3/4
  • Inodes normaux : ≥ 11
Contenu d'un inode
  • Mode (type + permissions Unix)
  • UID/GID propriétaire
  • Taille du fichier
  • Timestamps : atime, mtime, ctime
  • i_links_count (hardlinks)
  • Pointeurs de blocs ou extents
Permissions Unix
  • 0644 : rw-r--r-- (standard fichier)
  • 0755 : rwxr-xr-x (standard dossier)
  • 0777 : rwxrwxrwx (⚠ risque sécu)
  • 0000 : aucune permission

Suppression et récupération forensique
1
L'entrée de répertoire est invalidée (rec_len étendu pour "sauter" l'entrée). Le nom reste lisible dans les répertoires EXT2.
2
i_links_count passe à 0. Sur EXT3/4 : les pointeurs de blocs dans l'inode sont effacés. Sur EXT2 : pointeurs conservés → récupération directe possible.
3
Les bits dans les bitmaps blocs et inodes sont remis à 0 (libres). Les données restent sur le disque jusqu'à réécriture.
Formule groupe = (inode − 1) ÷ s_inodes_per_group (division entière)
Index dans groupe = (inode − 1) mod s_inodes_per_group
Offset inode = Début_table_inodes + index × taille_inode
💡 Récupération EXT4 : Utiliser le journal (contient les anciens pointeurs), le carving sur l'espace non alloué (PhotoRec, Scalpel), ou l'outil ext4magic. La journalisation EXT4 en writeback protège moins les données qu'en data=ordered ou data=journal.
