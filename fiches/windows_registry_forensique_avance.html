🏗️ Registry = Windows Configuration Database
Hierarchical database storing system settings, user preferences, software config. Binary format organized as "hives" (files). Separate from filesystem.
Registry Hives (Fichiers Physiques)
Hive Localisation Forensique Critique
HKLM\System C:\Windows\System32\config\SYSTEM 🔴 Services, drivers, hardware profiles
HKLM\Software C:\Windows\System32\config\SOFTWARE 🔴 Installed apps, config
HKLM\Security C:\Windows\System32\config\SECURITY 🟠 Account policies, audit
HKCU\* (per-user) C:\Users\[user]\NTUSER.DAT 🔴 User preferences, MRU, timeline
HKU\Classes C:\Users\[user]\AppData\Local\Microsoft\Windows\UsrClass.dat 🟠 File associations, COM objects
Key Registry Paths (Quick Reference)
# System Services (startup type = persistence)
HKLM\System\CurrentControlSet\Services\*

# Auto-start programs
HKLM\Software\Microsoft\Windows\CurrentVersion\Run
HKCU\Software\Microsoft\Windows\CurrentVersion\Run

# User activity (MRU)
HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\RecentDocs

# USB devices (device tracking)
HKLM\System\CurrentControlSet\Enum\USBSTOR
🚨 Persistence via Registry = Malware #1 Vector
Malware modify registry to auto-execute on reboot. Multiple techniques: Run keys, Services, WMI, COM, Image File Execution Options, AppInit_DLLs.
Persistence Techniques (MITRE ATT&CK)
Technique Registry Path Detection
Run Keys ...CurrentVersion\Run* 🔴 Most common (Emotet, Conti)
Services ...Services\[name] 🔴 Legitimate-looking service
WMI Event Subscriptions ...WMI\EventFilter 🟠 Sophisticated (APT)
Image File Execution Options ...Image File Execution Options 🟠 Hijack .exe behavior
AppInit_DLLs ...Windows NT\CurrentVersion 🔴 DLL injection (all processes)
COM Autorun ...Software\Classes\CLSID 🟠 Component Object Model
🔍 Detection Checklist
  • Scan ALL Run key variants (Run, RunOnce, RunEx, RunServices)
  • Check Services with unusual startup type (auto-start)
  • Identify services created AFTER system initialization
  • Look for DLL names: random chars, temp folder, system folder spoofing
  • Cross-reference with known-bad hashes (VirusTotal)

💀 Rootkit Detection = Anomaly Hunting
Rootkits hide via registry manipulation: hiding keys, hooking SSDT (System Service Dispatch Table), manipulating security descriptors. Detection = look for anomalies, missing standard keys, weird values.
Rootkit Indicators
Indicator Normal 🚨 Suspicious
Hidden Keys All services visible Key in file but not enumerable
Missing Standard Keys HKLM\Software\Microsoft present Critical software keys absent
SSDT Hooks SSDT entries = kernel.exe SSDT = third-party module
Security Descriptors Proper ACLs (admin/system) Wide-open or modified ACLs
Detection via Volatility
# Scan for hidden registry keys
volatility3 -f memory.raw windows.registry.printkey

# Check SSDT integrity
volatility3 -f memory.raw windows.ssdt

# Unusual API hooks
volatility3 -f memory.raw windows.apihooks
📅 Registry Timestamps ≠ NTFS
Registry has own timestamp mechanism: LastWrite times (100-nanosecond intervals, 64-bit). Different from file NTFS timestamps. Both needed for complete timeline.
Timestamp Precision & Anomalies
Registry Timestamp Format
LastWrite: 2024-03-20 14:32:15.123456 UTC
(100-nanosecond precision)

Stored as: 64-bit Windows FILETIME
= 100-nanosecond intervals since 1601-01-01

Forensic use:
• Precise malware installation time
• Persistence modification timestamp
• When key last modified (not file)
• Possible timestamp manipulation (clock rollback)
⚠️ Timestamp Anomalies = Forensic Indicators
  • Future timestamps = clock set wrong or tampering
  • Identical timestamps = possible manipulation (too coincidental)
  • Backward jumps = system clock rolled back (hide timeline)
  • Huge gaps = system powered off or hibernation

CLI Quick Commands
# Dump registry with RegRipper
$ rip.pl -r SYSTEM -p services
$ rip.pl -r NTUSER.DAT -p typedpaths

# Extract with PowerShell
PS> Get-Item 'Registry::HKLM\Software\Microsoft\Windows\CurrentVersion\Run'

# Parse offline hive (Python)
$ python3 -c "from Registry import Registry; r = Registry.Registry('SYSTEM'); print(r.root.subkeys)"

# Timeline all Run keys
$ rip.pl -r SOFTWARE -p userassist | grep -i "run\|autorun"

# Find persistence
$ grep -r "CurrentVersion.*Run" /registry/path
✅ Workflow Complet Registry Forensique
  1. Locate hives → C:\Windows\System32\config\ (offline) ou live registry
  2. Extract with RegRipper → Dump all keys + timestamps
  3. Scan for persistence → Run*, Services, AppInit_DLLs
  4. Cross-check with VirusTotal → Hash executables referenced
  5. Timeline user activity → RecentDocs, USB, typed URLs
  6. Detect anomalies → Unusual timestamps, missing keys
  7. Volatility analysis → Memory-resident registry for hidden keys
  8. Rapport → Persistence mechanisms, timeline, indicators
