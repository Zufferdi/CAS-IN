Métadonnées EXIF & Documents
EXIF forensique
  • Coordonnées GPS : précision jusqu'à 3 mètres
  • Modèle d'appareil + numéro de série → lien suspect
  • DateTimeOriginal (prise) ≠ FileModifyDate (FS)
  • Plateformes sociales suppriment les EXIF à l'upload (mais pas les messages privés/mails)
  • exiftool photo.jpg · exiftool -GPS* photo.jpg
Métadonnées Office
  • .docx = ZIP : unzip -p doc.docx docProps/core.xml
  • Contient : auteur (nom d'utilisateur Windows), organisation, dates
  • Chemins complets des fichiers liés
  • Versions antérieures dans les métadonnées XML
📍 GEOINT : végétation + architecture + plaques + enseignes + ombres/soleil → localisation sans GPS. What3Words : 3 mots = carré de 3m×3m sur Terre entière (w3w.app).
🧠 Testez-vous
Pourquoi LinkedIn est-il un risque OPSEC en OSINT ?
LinkedIn notifie le propriétaire du profil quand quelqu'un consulte sa page (sauf mode navigation privé LinkedIn avec compte gratuit). Un enquêteur qui consulte le profil d'un suspect avec son compte personnel révèle son identité et son organisation. Solution : compte anonyme dédié, ou utiliser l'aperçu Google cached (sans visiter LinkedIn directement).
Une photo est partagée sur WhatsApp. Contient-elle encore ses métadonnées EXIF ?
Cela dépend du moyen d'envoi. WhatsApp compresse et supprime les EXIF lors de l'envoi standard. Exception : si le fichier est envoyé en "document" (pas comme photo), les EXIF sont préservés. Les emails conservent généralement les EXIF sauf si l'application les supprime. Les plateformes sociales (Instagram, Twitter) suppriment systématiquement les EXIF à l'upload.
