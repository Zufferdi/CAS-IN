🕵 Silk Road (2013) : Ross Ulbricht ("Dread Pirate Roberts") a été identifié via un post sur un forum crypto de 2011 — il cherchait des développeurs pour un "site de vente anonymous" et avait utilisé son vrai email. L'OPSEC commence dès le premier message publié, même des années avant. L'FBI a ensuite confirmé via les serveurs Tor (compromis) et l'arrestation physique dans une bibliothèque de San Francisco.

Fondamentaux OSINT
ℹ Règle d'or : une information confirmée par 1 source = indice. Confirmée par 3 sources indépendantes = assertion défendable en justice.
Cycle du renseignement
  1. Planification : définir la question précise à élucider
  2. Collecte : sources ouvertes documentées
  3. Traitement : structurer et normaliser
  4. Analyse : croiser, éliminer les artefacts
  5. Diffusion : rapport adapté au destinataire
Cloisonnement obligatoire
  • Navigateur dédié (Brave ou Firefox profil vierge)
  • VPN ou Tor pour les recherches actives
  • LinkedIn notifie les visites de profil → compte anonyme obligatoire
  • Documenter : URL + date d'accès + capture d'écran archivée
Sources suisses officielles
  • Zefix.ch : registre du commerce cantonal
  • FOSC (shab.ch) : Feuille Officielle Suisse du Commerce
  • Moneyhouse.ch : données entreprises et dirigeants
  • OFAS : registre foncier (cantonal)
  • Casier judiciaire : accès réservé aux autorités (pas OSINT public)
Sources web générales
  • Wayback Machine (archive.org) : snapshots depuis 1996
  • HIBP (haveibeenpwned.com) : vérifier si email dans des fuites
  • Google cache: : version en cache d'une page
  • Shodan.io : services exposés sur Internet
  • crt.sh : Certificate Transparency logs
Outils et automatisation OSINT
Maltego
  • Graphe de pivot visuel
  • Transforms : email → domaines → IPs → certificats
  • Valeur judiciaire : la chaîne de connexions visible par un juge non-technique
theHarvester & Recon-ng
  • theHarvester : emails + sous-domaines depuis moteurs de recherche
  • Recon-ng : framework modulaire Python (similaire Maltego en CLI)
  • theHarvester -d domain.ch -b google,bing
Identités & Pseudonymes
  • Sherlock : pseudonyme sur 300+ plateformes
  • Holehe : email présent sur quel service ?
  • Pivoting : un pseudo trouvé → trouver les autres profils liés
Google Dorks essentiels
  • site:domain.ch filetype:pdf
  • inurl:admin "index of"
  • filetype:xls "username" "password"
  • "index of" filetype:pdf confidential
WiGLE & Géolocalisation WiFi
  • WiGLE.net : milliards de réseaux WiFi géolocalisés par BSSID
  • BSSID dans les logs d'un appareil → localisation physique du réseau
  • Wardriving = collecte systématique de données WiFi
Images GAN (deepfake detection)
  • Texte illisible dans l'image
  • Asymétrie yeux/oreilles
  • Arrière-plan flou/incohérent
  • Artefacts sur dents et cheveux
  • Outils : Illuminarty, FotoForensics, Hive Moderation
Métadonnées et EXIF
EXIF forensique
  • Coordonnées GPS : précision jusqu'à 3 mètres avec smartphone
  • Modèle d'appareil + numéro de série → lien avec un suspect
  • DateTimeOriginal (prise de vue) ≠ FileModifyDate (FS)
  • Les plateformes sociales suppriment les EXIF à l'upload (mais pas les messages privés/mails)
  • exiftool : exiftool photo.jpg · exiftool -GPS* photo.jpg
Métadonnées Office
  • .docx = ZIP : unzip -p doc.docx docProps/core.xml
  • Contient : auteur (nom d'utilisateur Windows), organisation, dates, templates
  • Chemins complets des fichiers liés (révèlent la structure interne)
  • Versions antérieures parfois dans les métadonnées XML internes
What3Words : divise la Terre en 57 000 milliards de carrés de 3m × 3m. Trois mots = rendez-vous discret. Vérifiable sur w3w.app.
GEOINT (géolocalisation d'image) : végétation + architecture + plaques + enseignes + ombres/soleil → localisation sans GPS.
