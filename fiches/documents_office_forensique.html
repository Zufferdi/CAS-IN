📦 Office Format = ZIP Archive (OOXML)
Depuis Office 2007 (.docx, .xlsx, .pptx), les documents = archives ZIP contenant XML + éventuels binaires anciens.
Structure Interne Document .docx
Document.docx (ZIP archive)
├─ [Content_Types].xml ← Types MIME
├─ _rels/.rels ← Relationships
├─ word/document.xml ← Contenu principal
├─ word/styles.xml ← Styles
├─ word/theme/theme1.xml ← Thème
├─ word/numbering.xml ← Listes numérotées
├─ word/fontTable.xml ← Polices
├─ word/settings.xml ← Réglages (macro, tracked changes)
├─ word/webSettings.xml ← Paramètres Web
├─ docProps/ ← MÉTADONNÉES
│ ├─ core.xml ← Core properties (auteur, date)
│ ├─ app.xml ← App properties (temps édition, nb pages)
│ └─ custom.xml ← Propriétés personnalisées
└─ word/media/ ← Images/OLE objects
🔓 Extraction Rapide
# Renommer .docx → .zip
$ mv document.docx document.zip
$ unzip -l document.zip

# Extraire et explorer XML
$ unzip document.zip
$ cat docProps/core.xml | grep -i creator
📝 Propriétés Core (Métadonnées Standards)
Propriété Élément XML Forensique
Creator <creator> 👤 Auteur d'ORIGINE (signature)
lastModifiedBy <lastModifiedBy> 👤 Dernier éditeur (peut ≠ auteur)
created <created> 📅 Quand créé (timestamp)
modified <modified> 📅 Dernière modification
title <title> 📌 Titre document (peut révéler intention)
subject <subject> 🔍 Sujet/description
keywords <keywords> 🔑 Mots-clés (contexte)
comments <comments> 💬 Commentaires (résumé auteur)
Exemple Extraction
<?xml version="1.0" encoding="UTF-8"?>
<cp:coreProperties ...>
  <dc:creator>Jean Martin</dc:creator>
  <cp:lastModifiedBy>Marie Dupont</cp:lastModifiedBy>
  <dcterms:created>2024-03-15T10:30:00Z</dcterms:created>
  <dcterms:modified>2024-03-20T14:45:30Z</dcterms:modified>
  <dc:title>Secret Project Alpha</dc:title>
</cp:coreProperties>
📋 Word : Tracked Changes & Versions
Tracked Changes = "Suivi des modifications" = historique éditions = PREUVE DE RÉDACTION.
Tracked Changes : Signature Auteur
Structure XML : Tracked Changes
<w:ins w:id="0" w:author="Jean Martin" w:date="2024-03-15T10:30:00Z">
  <w:r><w:t>"Cette phrase est confidentielle"</w:t></w:r>
</w:ins>

<w:del w:id="1" w:author="Marie Dupont" w:date="2024-03-20T14:45:00Z">
  <w:r><w:t>"Phrase supprimée"</w:t></w:r>
</w:del> 👤 Qui a écrit quoi + 📅 Quand + 🕐 Timestamps précis
Indicateurs Forensiques Word
🚨 Rédacteur vs Éditeur
Creator ≠ lastModifiedBy
= Document volé/modifier par tiers
Tracked changes = preuve
🚨 Versions Antérieures
Version History (Word backup)
Peut montrer texte supprimé
Timestamp précédent édition
🚨 Comments
Commentaires auteur caché
Souvent oubliés lors suppression
Révèlent contexte/intention
🚨 Hidden Text
Formatting hidden = pas affiché
Mais présent en XML
Format <w:vanish/>
📊 Excel : Formules Cachées & Feuilles Masquées
Excel documents peuvent cacher : formules, feuilles, macros, données supprimées.
Forensique Excel Critiques
Élément Forensique Extraction
Hidden Sheets Feuilles masquées = données cachées workbook.xml.rels + sheets.xml (state="hidden")
Formulas Formules calcul manipulées = fraude Voir XML: <f>=SUM(...)>
Macros VBA code = malware potentiel xl/vbaProject.bin (binaire)
OLE Objects Objets incorporés = shellcode? word/embeddings ou xl/media/
Workflow : Révéler Données Cachées
  1. Extraire .xlsx comme ZIP
  2. Chercher <sheet ... state="hidden" /> dans workbook.xml
  3. Restaurer feuille : supprimer attribut "hidden"
  4. Re-zipper et ouvrir → feuilles maintenant visibles
  5. Documenter trouvailles (formules, données)
🔧 Outils : Extraction Office Metadata
Outil Usage CLI/GUI

LibreOffice Ouvrir + voir Properties (File → Properties) GUI
7-Zip / WinRAR Extraire ZIP archive (docx/xlsx) GUI
Python zipfile Script extraction batch + parsing XML CLI
Microsoft Word Voir Tracked Changes natif (Review tab) GUI
CLI Quick Commands
# Extract docx metadata
$ exiftool document.docx

# OR unzip manually
$ unzip -q document.docx
$ cat docProps/core.xml
$ cat word/document.xml | grep -i "lastModifiedBy" | head -1

# Extract Excel metadata
$ unzip -q spreadsheet.xlsx
$ cat workbook.xml | grep "sheet " | grep -i hidden

# Search tracked changes
$ grep -r "w:ins\|w:del" word/document.xml | head -20
🧪 Workflow Complet Office
  1. exiftool document.docx → auteur, dates, subject
  2. unzip document.docx → extraire tout
  3. grep "w:ins\|w:del" word/document.xml → tracked changes
  4. Voir docProps/core.xml → creator vs lastModifiedBy
  5. Libreoffice document.docx → vérifier si hidden text/sheets
  6. Rapport : Auteur original, derniers éditeurs, timeline éditions, données cachées
