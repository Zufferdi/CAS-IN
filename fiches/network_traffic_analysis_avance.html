📦 PCAP = Packet Capture Format
Standard format for capturing network traffic. Contains every packet: headers + payload. Forensic goldmine for network behavior reconstruction.
PCAP File Structure
PCAP Structure (Hex):

Offset 0x00 | Global Header
    Magic number: 0xA1B2C3D4 (little-endian) or 0xD4C3B2A1
    Version: 2.4
    Snapshot length: 65535 bytes (typical)

Offset 0x18 | Packet 1 Header
    Timestamp (sec): 1710918735
    Timestamp (usec): 123456
    Packet length: 1514 bytes

    → Packet 1 Data (raw bytes)

Offset 0xXX | Packet 2 Header
    ...

Result: Multiple packets (TCP SYN, HTTP GET, DNS query, etc.)
Capture Methods
Method Tool Forensique
Packet Sniffer tcpdump, Wireshark 🔴 Live capture (disk mirror, SPAN)
IDS/IPS Suricata, Snort, Zeek Continuous monitoring + alerts
Firewall Logs Palo Alto, Fortinet, Check Point Flow-level data (not full packets)
PCAP Forensic Value
  • Complete traffic record (every packet)
  • Precise timestamps (microsecond accuracy)
  • Payload inspection (see actual data transmitted)
  • Protocol reconstruction (rebuild flows, files)
🔍 Zeek (formerly Bro) = Network Security Monitor
Reads PCAP, generates structured logs (connection, http, dns, ssl, etc.). Not signature-based (like Suricata), but behavioral. Open-source, powerful for forensics.
Zeek Output Logs
Log File Content Forensique
conn.log TCP/UDP connections (src IP, dst IP, port, bytes) 🔴 Traffic timeline + volume
http.log HTTP requests (URI, method, user-agent) 🔴 Web activity, downloads
dns.log DNS queries (domain, query type, response) 🔴 Domains queried (C2?)
ssl.log TLS/SSL connections (cert, cipher) Encrypted traffic metadata
files.log Extracted files (hash, MIME type) Malware samples, downloads
Zeek CLI Usage
# Process PCAP file
$ zeek -r traffic.pcap

# Output logs to directory
$ zeek -r traffic.pcap -w logs/

# Load custom script
$ zeek -r traffic.pcap intel.zeek

# Live capture mode
$ zeek -i eth0
⚠️ Suricata = Signature-Based IDS
Uses detection rules (similar to Snort). Generates alerts when traffic matches suspicious patterns. EVE JSON output for structured logging.
Suricata Alert Types
Alert Category Example Forensique
Malware/Trojan C2 beacon detection, exploit kit 🔴 Known malware communication
Command & Control Cobalt Strike, Metasploit callback 🔴 Active compromise evidence
Exploit Buffer overflow, SQL injection payload Initial access vector
Policy Violation Suspicious user-agent, protocol anomaly Unusual behavior
Suricata CLI
# Run on PCAP file
$ suricata -r traffic.pcap -S rules.rules -l output/

# Output JSON (EVE)
$ suricata -r traffic.pcap -o eve-log.json

# Live interface
$ suricata -i eth0 -S rules.rules
🚨 Threat Hunting = Proactive Detection
Look for behavioral patterns (not just signatures): C2 beaconing, data exfiltration, lateral movement, anomalous protocols.
C2 Detection Patterns
🚨 Periodic Beacons
Same IP:port
Every 60 seconds (or interval)
Constant size packets
= Regular check-in
🚨 DNS Tunneling
High entropy subdomains
Excessive query rate
Non-existent domains (NXDOMAIN)
= Data exfiltration
🚨 Data Exfiltration
Large outbound volume
Unusual destination
Off-hours transfer
= Stealing data
🚨 Lateral Movement
User ID from strange IP
Uncommon ports (3389, 5985)
Failed attempts then success
= Spreading inside network
🔍 Anomaly Scoring
HIGH RISK:
• Known C2 IP/domain
• Exploit pattern match
• Credential stuffing (many failed logins)

MEDIUM RISK:
• Unusual outbound port
• High DNS entropy
• Uncommon protocol

LOW RISK:
• Off-hours activity (benign)
• Non-standard user agent
• Policy violation

CLI Quick Commands
# Capture traffic
$ tcpdump -i eth0 -w traffic.pcap

# Process with Zeek
$ zeek -r traffic.pcap

# Analyze with Suricata
$ suricata -r traffic.pcap -S rules.rules

# Extract HTTP requests
$ tshark -r traffic.pcap -Y "http.request" -T fields -e http.host -e http.request.uri

# Find DNS queries
$ tshark -r traffic.pcap -Y "dns" -T fields -e dns.qry.name

# Timeline from Zeek conn.log
$ cat conn.log | awk '{print $1, $2, $3, $4, $5, $7, $8}' | sort

# Extract files from PCAP
$ tcpflow -r traffic.pcap -o extract/

# Look for C2 beacons (periodic)
$ zeek -r traffic.pcap | grep -E "10\.[0-9\.]+:443" | sort | uniq -c
✅ Workflow Complet Network Forensique
  1. Capture or obtain PCAP (tcpdump, Zeek, IDS)
  2. Process with Zeek (generate conn.log, http.log, dns.log, ssl.log)
  3. Process with Suricata (generate EVE alerts)
  4. Extract timeline (connections, flows, bytes transferred)
  5. Hunt for C2 patterns (periodic beacons, unusual destinations)
  6. Check DNS queries (C2 domain, DGA, tunneling)
  7. Analyze HTTP requests (user-agent, URIs, payloads)
  8. Extract files (malware samples, exfiltrated data)
  9. Correlate with other forensics (registry, logs, memory)
  10. Rapport: C2 IPs, domains, exfiltration volume, timeline
