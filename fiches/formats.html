Principe des Magic Bytes (File Signatures)
Qu'est-ce qu'un magic byte ?

Séquence d'octets en début de fichier (header) identifiant son format réel — indépendamment de l'extension. Peut être accompagné d'un footer (marqueur de fin).

Utile pour le file carving : retrouver des fichiers supprimés en scannant les données brutes.

⚠️ Extension ≠ Format

Un attaquant peut renommer image.jpg en rapport.pdf. Le magic byte ne ment pas.

X-Ways : colonne "Type" vs "Extension" → discordance = signature mismatch, indice forensique fort.

File Carving — Récupérer sans système de fichiers
Principe du carvin
Prérequis :📖 Encodage
Pratiquer :🧪 ✨ Magic Bytes🧪 🎭 Mismatch
Voir aussi :🔗 Acquisition
g

Scan linéaire de l'espace brut à la recherche de headers connus. Reconstruit les fichiers sans passer par la FAT/MFT (utile après formatage ou corruption).

Outil de référence : Scalpel, PhotoRec, Foremost, X-Ways.

Limitations du carving
  • Ne récupère pas les noms de fichiers (perdus avec la FAT)
  • Fragmentation = carving incomplet
  • Faux positifs si les magic bytes apparaissent dans d'autres fichiers
  • Chiffrement = pas de magic bytes → carving impossible
💡 Signature mismatch (X-Ways) : X-Ways compare l'extension déclarée au header réel et signale les discordances en rouge. Un .txt avec header FF D8 FF = JPEG dissimulé.
Formats d'image forensique
DD / RAW

Copie bit-à-bit brute. Pas de métadonnées intégrées. Compatible avec tous les outils. Poids = taille exacte du support.

dd if=/dev/sdb of=image.dd bs=512

E01 (Expert Witness Format)

Format propriétaire EnCase. Supporte les métadonnées (hash MD5, infos cas), la compression et le split en volumes. Standard de facto dans beaucoup de procédures.

AFF / AFF4

Advanced Forensic Format. Open source, supporte la compression, les métadonnées, les signatures. AFF4 est la version moderne utilisée par Velociraptor et GRR.

VMDK / VHD / VHDX

Images de machines virtuelles. Mountable directement dans X-Ways ou Arsenal Image Mounter. Utilisées lors d'analyses cloud forensique ou VM suspects.

⚖️ Examen CAS-IN : Un fichier sans extension ou avec extension modifiée est identifié par ses magic bytes. JPEG toujours FF D8 FF. PDF toujours 25 50 44 46 ("%PDF"). Les 4 premiers octets suffisent dans la majorité des cas.
