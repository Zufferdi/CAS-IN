Fait notable
"Les QuarantineEventsV2 de macOS sont l'équivalent d'un journal de navigation complet — chaque fichier téléchargé y est référencé avec son URL source exacte, même des années après sa suppression."
— Sarah Edwards, Mac Forensics, SANS FOR518, 2022
🐧 Fun fact Unix : rm vient de "remove" mais ne supprime pas vraiment les données — il supprime juste le lien (dentry) entre le nom et l'inode. Si le fichier est ouvert par un process au moment du rm, il reste accessible via /proc/<pid>/fd/ jusqu'à la fermeture du process. Technique de récupération en temps réel.

macOS — Artefacts et analyse
ArtefactCheminValeur forensique
QuarantineEventsV2~/Library/Application Support/com.apple.LaunchServices/URL source exacte de chaque téléchargement. Persist après suppression du fichier.
Historique Safari~/Library/Safari/History.dbSQLite. Downloads.plist & BrowserState.db persistent après effacement de l'historique Safari.
FSEvents/.fseventsd/Modifications système de fichiers. Similaire à $USNJrnl NTFS. Survit aux redémarrages.
Spotlight~/.Spotlight-V100/Store-V2/Index de recherche très riche. Contient métadonnées de fichiers supprimés.
Unified Logvar/db/uuidtext/ · /var/db/diagnostics/Remplace les anciens syslog depuis macOS 10.12. Binaire .tracev3. log show --last 24h
Recent Items~/Library/Preferences/com.apple.recentitems.plistFichiers et apps récents. Persist après effacement via menu.
LaunchDaemons/Library/LaunchDaemons/Persistance au démarrage système (root, sans session utilisateur). Cible des malwares macOS.
LaunchAgents~/Library/LaunchAgents/Persistance par session utilisateur. Chargement à l'ouverture de session.
Fuseau horaire/etc/localtime · /Library/Preferences/.GlobalPreferences.plistComparer avec EXIF : manipulation timezone = indicateur de falsification timeline.
Timestamps macOS
  • HFS+ : secondes depuis 01.01.1904 (Mac Epoch)
  • APFS : nanosecondes depuis 01.01.2001 (macOS Epoch)
  • plist : secondes depuis 01.01.2001
  • Conversion : plutil -convert xml1 fichier.plist
Outils forensiques macOS
  • Autopsy / TSK : analyse images HFS+/APFS
  • mac_apt : extraction automatisée artefacts macOS
  • Cellebrite / AXIOM : extraction complète + corrélation
  • plutil : conversion plist binaire → XML
  • log : lecture Unified Log (natif macOS)
Linux — Artefacts et analyse
Logs système
  • /var/log/auth.log : authentifications, sudo, SSH
  • /var/log/syslog : logs système général
  • journald : journalctl -u sshd --since "1h ago"
  • /var/log/apache2/ : logs web (oubliés par les attaquants)
Répertoires volatils clés
  • /tmp/ : effacé au redémarrage (souvent tmpfs en mémoire)
  • /var/tmp/ : persiste entre redémarrages → scripts malveillants
  • /proc/<pid>/ : infos processus en cours (cmdline, environ, maps)
  • /dev/shm/ : mémoire partagée — malwares fileless
Persistance Linux
  • ~/.ssh/authorized_keys : accès SSH permanent silencieux
  • /etc/cron.d/ · /var/spool/cron/crontabs/ : tâches planifiées
  • systemd : /etc/systemd/system/ (système) · ~/.config/systemd/user/ (utilisateur)
  • ~/.bashrc / ~/.profile : exécuté à chaque connexion
Corbeille & Suppression
  • Corbeille FreeDesktop : ~/.local/share/Trash/files/ (contenu) + ~/.local/share/Trash/info/*.trashinfo (chemin original + date suppression)
  • rm sur EXT3/4 : efface pointeurs de blocs
  • Récupération : ext4magic ou carving
~/.bash_history : souvent effacé (history -c && unset HISTFILE). Alternatives : journald, /proc/<pid>/cmdline, auth.log.
Inode 2 = répertoire racine / sur tous les volumes EXT (constante universelle).
/root/ = home de root (et non /home/root/). Contient .bash_history, .ssh/, fichiers de session.
💡 Tip : Sur macOS, les QuarantineEventsV2 contiennent l'URL complète du téléchargement, le nom de l'application et le hash du fichier — tout cela persiste après suppression du fichier lui-même. Source forensique souvent négligée mais très riche.
