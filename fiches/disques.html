MBR — Master Boot Record (secteur 0)
OffsetTailleContenu
0x000440 bytesCode de démarrage (Bootstrap) — charge le OS bootloader
0x1B84 bytesSignature disque (Windows Disk Signature)
0x1BE64 bytesTable de partition — 4 × 16 bytes (4 partitions primaires max)
0x1FE2 bytesSignature de boot : 55 AA — valeur magic obligatoire
Note Endianness : La valeur mathématique est 0xAA55 mais stockée en Little Endian → 55 puis AA sur le disque. Si le BIOS ne trouve pas 55AA aux offsets 510-511 → "No Bootable Device Found".
GPT — GUID Partition Table (au-delà de 2.2 To)
Structure GPT

LBA 0 : Protective MBR (code 0xEE — signale un disque GPT aux vieux systèmes)
LBA 1 : En-tête GPT primaire (CRC32 inclus)
LBA 2–33 : Table des partitions primaire (128 entrées × 128 bytes)
… (données)
LBA −34 à −2 : Table des partitions secondaire
LBA −1 : En-tête GPT secondaire (sauvegarde)

La redondance primaire/secondaire permet la récupération si un en-tête est corrompu.

Avantages vs MBR

MBR max : 2.2 To (adresses 32 bits)
GPT max : 8 Zettaoctets (adresses 64 bits LBA)

MBR : 4 partitions primaires
GPT : jusqu'à 128 partitions

UEFI obligatoire pour démarrer sur GPT. Le "Protective MBR" au LBA 0 signale aux vieux systèmes de ne pas toucher au disque GPT.

Adressage — CHS vs LBA
CHS — Cylindre/Head/Secteur

Adressage physique hérité : Cylindre (0–N), Tête (0–M), Secteur (1–S).

Limites : la densité de pistes varie entre intérieur et extérieur du disque. Le CHS ne reflète plus la géométrie réelle depuis les disques > 504 Mo.

CHS 0/0/1 = LBA 0 (premier secteur du disque).

LBA — Logical Block Addressing

Numérotation séquentielle des secteurs de 0 à la fin du disque. Abstraction complète — le contrôleur du disque fait la traduction LBA → CHS en arrière-plan.

Les outils forensiques modernes travaillent directement en LBA — accès direct à n'importe quel secteur indépendamment des structures logiques (partitions, systèmes de fichiers).

Secteurs et Clusters
Secteur — Plus petite unité physique

Historiquement 512 bytes. Disques modernes : 4096 bytes (Advanced Format / 4Kn).

Les outils forensiques lisent en secteurs — si un secteur n'est pas à 512 bytes, les calculs d'offset sont faussés.

Vérifier dans X-Ways : Options → Disque → Taille de secteur.

Cluster — Unité d'allocation

Groupe de secteurs consécutifs. Le système de fichiers alloue toujours des clusters entiers.

FAT32 : taille variable selon la partition
NTFS : souvent 4096 bytes (8 secteurs × 512)

Si un fichier de 7 bytes occupe un cluster de 4096 bytes → 4089 bytes de slack space contenant potentiellement des données résiduelles.

HPA et DCO — Zones cachées
HPA — Host Protected Area

Zone à la fin du disque, hors adressage LBA normal. Invisible pour l'OS et les outils standards.

Utilisée par les fabricants pour stocker les outils de restauration. Peut être utilisée pour cacher des données.

Détection : comparer la taille annoncée (IDENTIFY DEVICE) avec la taille maximale (READ NATIVE MAX ADDRESS).
Commande : hdparm -N /dev/sdX

DCO — Device Configuration Overlay

Couche de con

Prérequis :📖 Encodage
Pratiquer :🧪 🔄 Endianness
Voir aussi :🔗 FAT16/32🔗 NTFS🔗 EXT4
figuration qui peut masquer des fonctionnalités ou réduire la taille visible du disque.

Un fabricant peut "brider" un disque de 2 To pour le vendre comme 1 To via le DCO.

Forensiquement : toujours vérifier l'existence de zones HPA et DCO avant l'acquisition (mentionner dans le rapport si non vérifié).
Commande : hdparm --dco-identify /dev/sdX

SSD et TRIM — Problème forensique
HDD — Récupération classique

Supprimer un fichier sur HDD ne supprime jamais les données physiquement. Le système de fichiers marque les clusters comme libres mais les octets restent.

Le carving peut retrouver des données même longtemps après la suppression — tant que les clusters n'ont pas été réécrits.

SSD — TRIM efface immédiatement

TRIM est une instruction envoyée au contrôleur SSD lors d'une suppression : "ces blocs ne contiennent plus rien d'utile, tu peux les effacer."

Le contrôleur efface physiquement lors de ses cycles de maintenance.

Conséquence forensique : la récupération après suppression sur SSD est très difficile et la fenêtre est très courte. Acquérir immédiatement.
