① Concept — qu'est-ce qu'un ShellBag ?
🪟 Définition

Les ShellBags sont un ensemble de clés de registre que Windows utilise pour mémoriser les préférences d'affichage des dossiers dans l'Explorateur.

Concrètement, quand vous :

  • ouvrez un dossier,
  • redimensionnez sa fenêtre,
  • choisissez l'affichage Détails ou Grandes icônes,
  • triez par date ou par taille,

…Windows enregistre ces choix pour que, la prochaine fois, le dossier soit exactement comme vous l'avez laissé.

② Pourquoi c'est une mine d'or en forensique

La valeur des ShellBags réside dans leur persistance.

👁 Mémoire visuelle

Ils tracent la navigation de l'utilisateur via l'Explorateur Windows (GUI). Chaque dossier ouvert laisse une trace durable.

♾️ Survivance

Si un utilisateur crée C:\Documents\Projet_Secret, l'ouvre, puis le supprime, le ShellBag reste dans le registre.

🔌 Preuve d'existence

Ils prouvent qu'un dossier a existé, même si le disque dur externe ou la clé USB n'est plus connecté à l'ordinateur. Même si la clé a été détruite.

③ Architecture & localisation

Les ShellBags ne se trouvent pas dans un fichier unique, mais dans les ruches du registre utilisateur.

🗝 USRCLASS.DAT — le plus important (Windows 7/10/11)

Contient les ShellBags des dossiers locaux, des fichiers ZIP et des dossiers partagés.

// Chemin fichier
C:\Users\%User%\AppData\Local\Microsoft\Windows\UsrClass.dat

// Chemin registre
HKCU\Software\Classes\Local Settings\Software\Microsoft\Windows\Shell\BagMRU
🗝 NTUSER.DAT — legacy & cas spécifiques

Contient les ShellBags des dossiers réseaux (UNC paths), du Bureau et de certaines configurations système.

// Chemin fichier
C:\Users\%User%\NTUSER.DAT

// Chemin registre
HKCU\Software\Microsoft\Windows\Shell\BagMRU
HKCU\Software\Microsoft\Windows\ShellNoRoam
④ Structure — BagMRU vs Bags

Deux sections qui fonctionnent en tandem.

🗺 BagMRU — la Carte

Structure arborescente qui reproduit la hiérarchie des dossiers explorés.

  • Système de numérotation : 0, 1, 2, 3…
  • Ordre de visite + noms des dossiers
  • Chaque nœud peut avoir des sous-nœuds
⚙️ Bags — les Réglages

Contenu des préférences associées à chaque nœud BagMRU.

  • Coordonnées de la fenêtre (position, taille)
  • Mode de tri (par date, nom, taille)
  • Type de vue (détails, icônes, liste…)
  • Chaque numéro BagMRU renvoie à une clé Bags
🧩 Modèle mental : BagMRU = quels dossiers dans quel ordre. Bags = comment ils étaient affichés.

🔍 Preuve d'accès et de connaissance

Si un ShellBag existe pour D:\Recettes_Fraudes, cela prouve non seulement que le dossier a existé, mais que l'utilisateur a navigué dedans via l'Explorateur Windows.

Cela réfute l'argument : « Je ne savais pas que ce dossier était là, c'est un virus qui l'a créé ».

👉 Un virus n'utilise généralement pas l'interface graphique — il ne crée donc pas de ShellBags. La présence d'un ShellBag implique une action humaine consciente.

⑥ Périphériques externes (USB) — l'usage le plus puissant
🔌 Reconstruire une clé USB absente

Lorsqu'une clé USB est insérée, Windows ne crée pas seulement des artefacts USB (setupapi, USBSTOR) — il crée aussi des ShellBags dès que l'utilisateur explore la clé.

Vous pouvez voir l'arborescence complète d'une clé USB même si la clé est détruite :

E:\
├── Documents\
│   ├── Confidentiel\       ← dossier visité
│   │   └── Projet_X\       ← sous-dossier visité
│   └── Factures\
└── Photos\
    └── Vacances\

Toute cette structure est reconstituable depuis le seul USRCLASS.DAT du suspect.

⑦ Archives ZIP & RAR
📦 Windows traite les ZIP comme des dossiers

Si l'utilisateur double-clique sur un ZIP pour voir son contenu sans le décompresser, un ShellBag est créé pour ce ZIP.

Conséquence forensique : on peut prouver que l'utilisateur a ouvert et exploré le contenu d'une archive, même s'il n'a jamais extrait les fichiers.

⑧ L'horodatage — attention à l'interprétation
⏱ Last Write Time — ce qu'il signifie vraiment

Le Last Write Time de la clé de registre BagMRU indique la dernière fois que l'utilisateur a interagi avec ce dossier :

  • l'a ouvert,
  • l'a fermé,
  • ou a changé la vue.

👉 Permet de reconstituer une chronologie précise : « Le suspect a parcouru le dossier Photos le 12 janvier à 14h30 ».

⚠️ Attention : le Last Write Time ne donne PAS toutes les visites — seulement la dernière. Pour une chronologie complète, corréler avec les LNK files, Jump Lists et RecentDocs.
⑨ Les outils d'analyse

Ne jamais tenter regedit — les données sont en binaire hexadécimal illisible.

🗝 ShellBags Explorer (Eric Zimmerman) — l'outil de référence

Gratuit, dédié, open source. Standard de l'industrie.

  • Fonctionnement : charger USRCLASS.DAT et/ou NTUSER.DAT
  • Affichage : reconstruit l'arborescence comme si vous étiez dans l'explorateur
  • Colonnes clés : Absolute Path · Last Write Time · Slot Key

Voir aussi : Suite Zimmerman

🔍 X-Ways Forensics

Trois approches possibles :

  • Viewer de registre interne — voit les clés brutes (difficile à interpréter)
  • X-Tensions (plugins) — scripts qui parsent les ShellBags dans le rapport
  • Méthode recommandée : extraire USRCLASS.DAT et NTUSER.DAT depuis X-Ways → ouvrir dans ShellBags Explorer
🏢 AXIOM / EnCase

Suites commerciales avec parsers automatiques intégrés. Les ShellBags apparaissent dans la catégorie « Artefacts OS » ou « Navigation Dossiers ».

⑩ Méthodologie d'analyse
1
Extraction. Récupérer NTUSER.DAT et USRCLASS.DAT pour chaque utilisateur suspect (via X-Ways ou montage lecture seule).
2
Parsing. Charger les fichiers dans ShellBags Explorer.
3
Filtrage par type. Chercher les entrées vers lettres de lecteurs amovibles (E:, F:, G:) et les chemins UNC (\\Serveur\Partage).
4
Recherche de mots-clés. Noms de dossiers suspects — « Factures », « Photos », « Hack », « Secret », etc.
5
Analyse chronologique. Trier par Last Write Time pour voir ce que l'utilisateur faisait à l'heure de l'incident.
6
Corrélation. Comparer avec les LNK files, Jump Lists et RecentDocs pour confirmer l'ouverture de fichiers spécifiques dans ces dossiers.
⑪ Limites & pièges

Crucial pour ne pas sur-interpréter en audience.

🚨 Dossiers ≠ fichiers. Les ShellBags prouvent l'ouverture d'un dossier, pas l'ouverture des fichiers à l'intérieur. Pour prouver qu'un PDF a été lu, il faut regarder les LNK files, Jump Lists ou RecentDocs.
⚠️ Accès ligne de commande — angle mort. Si l'utilisateur copie des fichiers via cmd.exe ou PowerShell (copy c:\source d:\dest), aucun ShellBag n'est créé. Les ShellBags sont exclusifs à l'interface graphique Explorer.
🧹 Nettoyage / anti-forensique. Des outils comme CCleaner ou BleachBit peuvent effacer les clés MRU, supprimant les ShellBags. Une absence totale de ShellBags sur un vieux système est suspecte — ce vide est en soi un indicateur d'activité anti-forensique.
