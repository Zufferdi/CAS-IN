Principe fondamental FAT12

Cluster utilisable minimal = cluster 2 (0 et 1 réservés). Offset physique d'un cluster n :

offset = (n − 2) × SectorsPerCluster × BytesPerSector + dataAreaStart

  • Suppression = 1er octet entrée répertoire → 0xE5 · données toujours présentes
  • Boot signature obligatoire : 55 AA aux offsets 510–511
  • FS Type identifiant à l'offset 0x36 : "FAT12 " (8 chars avec espaces)

Encodage FAT12 — Entrées de 12 bits

La FAT12 utilise 12 bits par entrée cluster. Deux entrées occupent donc 3 octets. La lecture diffère selon la parité du numéro d'entrée.

Exemple : FAT = F8 FF FF → entrées 0 et 1
F8oct.0
FFoct.1
FFoct.2
Entrée 0 (paire) → lire octets [0] + nibble bas de [1] = 0xFF8 → Média descriptor
Entrée 1 (impaire) → lire nibble haut de [1] + octet [2] = 0xFFF → EOF

Formule paire n : val = byte[pos] | ((byte[pos+1] & 0x0F) << 8)
Formule impaire n : val = (byte[pos] >> 4) | (byte[pos+1] << 4)

Points forensiques FAT12
⚠️ Attention examen

Le premier cluster utilisable est le cluster 2 (0 et 1 réservés). Offset dans la zone de données = (cluster − 2) × taille_cluster + début_données.

Récupération fichiers

Fichier supprimé : 1er octet = 0xE5. Clusters libérés dans la FAT mais données encore présentes → carving possible.

Slack space FAT12

Avec 512 o/cluster, même un fichier de 1 octet occupe 512 octets. Jusqu'à 511 octets de slack exploitables forensiquement.

Signature bootable

Offset 510 = 55, offset 511 = AA. Absent → secteur non bootable. Vérifier aussi l'OEM ID à l'offset 0x03.

🎓 Exam Tip — FAT12

Entrées 12 bits : 2 entrées = 3 octets · paire n : byte[pos] | ((byte[pos+1] & 0x0F) << 8) · impaire n : (byte[pos+1] >> 4) | (byte[pos+2] << 4)

Valeurs spéciales : 0x000 = libre · 0xFF7 = bad cluster · 0xFF8–0xFFF = EOF

Root directory : taille FIXE · 224 entrées max (disquette 1.44Mo) · commence après FAT2

Boot signature : 55 AA aux offsets 510–511 · absent = non bootable

Suppression : 1er octet entrée = 0xE5 · clusters libérés dans FAT · données encore sur disque → carving

FS Type : offset 0x36 = "FAT12 " (FAT12/16) · offset 0x52 = "FAT32 " (FAT32)

La FAT d'un volume FAT12 contient les octets A3 5B C2 aux positions 7, 8, 9. Quelle est la valeur de l'entrée cluster 5 (impaire) ?FAT12 encodage · Niveau : difficile
Entrée 5 est impaire. pos = 5×3/2 = 7 (entier). Formule : (byte[pos+1] >> 4) | (byte[pos+2] << 4)
= (0x5B >> 4) | (0xC2 << 4) = 0x05 | 0xC20 = 0xC25
→ Pointeur vers le cluster 0xC25 de la chaîne.
Sur un FAT12 avec BPS=512, SPC=1, reserved=1, FATs=2, SPF=9, rootEntries=224 : quel est l'offset du cluster 5 ?FAT12 calcul offset · Niveau : moyen
Root dir start = (1 + 2×9) × 512 = 9 728 octets
Root dir size = 224 × 32 = 7 168 octets
Data area start = 9 728 + 7 168 = 16 896 octets
Cluster 5 = 16 896 + (5−2) × 1 × 512 = 16 896 + 1 536 = 18 432 octets
