🧠 Mémoire Volatile

RAM Forensique

ℹ️ La RAM est le support forensique le plus volatile — toutes les données disparaissent à l'extinction. Elle contient des artefacts impossibles à trouver ailleurs : clés de chiffrement, processus actifs, connexions réseau, malwares fileless, mots de passe en clair.
Ordre de volatilité — RFC 3227
RFC 3227 — Ordre de volatilité obligatoire

Règle fondamentale : collecter du plus volatile au moins volatile. Ne jamais inverser cet ordre sous peine de détruire des preuves irremplaçables.

  • Registres CPU → Cache L1/L2 → RAM → État réseau → Processus → Disque → Sauvegardes
  • La RAM est perdue à l'extinction en quelques secondes
  • Un malware fileless n'existe que en RAM — invisible sur disque

Outils d'acquisition RAM
WinPmem Windows
winpmem.exe memdump.raw
Outil open-source d'Rekall. Produit un dump brut (.raw) ou un AFF4. Fonctionne depuis Windows XP jusqu'à Windows 11. Recommandé par SANS.
DumpIt Windows
DumpIt.exe /output memdump.raw
Un seul exécutable, interface minimale. Écrit le dump dans le répertoire courant. Très utilisé en intervention d'urgence.
LiME Linux — kernel module
insmod lime.ko "path=/mnt/usb/mem.lime format=lime"
Linux Memory Extractor. Chargé comme module kernel. Format LiME ou raw. Peut exporter via réseau (path=tcp:4444). Indispensable sur Linux/Android.
osxpmem macOS
sudo osxpmem memdump.aff4
macOS impose des restrictions kernel. SIP doit être désactivé ou l'outil signé. Alternativement : Cellebrite UFED pour Mac saisi verrouillé.
Magnet RAM Capture Windows · Gratuit
MRC.exe
Interface graphique simple. Capture la RAM physique et le fichier de page. Format brut + compression optionnelle. Très utilisé par les forces de l'ordre.
Belkasoft RAM Capturer Windows
RamCapture64.exe
Capture même sur systèmes protégés (ELAM/Early Launch). Format .mem. Intégration directe avec Belkasoft Evidence Center.
Ce que la RAM contient — Artefacts clés
🔑 Clés de chiffrement

Clés BitLocker VMK (Volume Master Key), clés TrueCrypt/VeraCrypt, clés de session TLS, clés PGP — toutes présentes en RAM tant que la session est active.

🦠 Malwares fileless

Malwares qui ne s'écrivent jamais sur disque (PowerShell Empire, Cobalt Strike). Invisibles à l'analyse disque — RAM uniquement.

🌐 Connexions réseau

Toutes les connexions TCP/UDP actives avec IPs, ports et processus associés — même après que l'attaquant a fermé sa session.

👤 Sessions & credentials

Hashes NTLM, tickets Kerberos, mots de passe en clair (XP/Vista), tokens d'accès, secrets LSA — extractibles avec Mimikatz.

📋 Processus & DLLs

Processus masqués par rootkits (détection par comparaison PsList vs PsScan), DLLs injectées, handles ouverts.

📄 Données en transit

Contenu des pages web HTTPS, pièces jointes email avant chiffrement, texte de documents Word ouverts.

Analyse avec Volatility 3
Volatility est le standard forensique RAM. La v3 (Python) est plus rapide que v2. Profils remplacés par les Symbol Tables (ISF).
COMMANDES ESSENTIELLES — Volatility 3
python3 vol.py -f memdump.raw windows.pslist # Liste des processus (PEB) python3 vol.py -f memdump.raw windows.psscan # Scan brut MFT (détecte rootkits) python3 vol.py -f memdump.raw windows.cmdline # Arguments ligne de commande python3 vol.py -f memdump.raw windows.netscan # Connexions réseau (actives+fermées) python3 vol.py -f memdump.raw windows.malfind # Injection de code (rwx regions) python3 vol.py -f memdump.raw windows.dlllist # DLLs chargées par processus python3 vol.py -f memdump.raw windows.hashdump # Hashes NTLM (SAM) python3 vol.py -f memdump.raw windows.cachedump # Credentials cachés python3 vol.py -f memdump.raw windows.lsadump # Secrets LSA python3 vol.py -f memdump.raw windows.registry.hivelist # Registre en RAM python3 vol.py -f memdump.raw bitlocker # Clé VMK BitLocker
Cas particulier — BitLocker & FileVault
⚠️ Procédure si chiffrement actif

BitLocker (Windows) : Si la session est déverrouillée, la VMK est en RAM. Capturer avec WinPmem puis extraire avec python3 vol.py bitlocker ou Elcomsoft Forensic Disk Decryptor. Ensuite monter le volume avec la VMK avant extinction.

FileVault (macOS) : Si la session est ouverte, clé en RAM. Utiliser osxpmem + Volafox. Sinon demander la clé de récupération iCloud au prestataire cloud (via MLAT si nécessaire).

Intégrité du dump RAM

Contrairement au disque, un dump RAM ne peut pas être parfaitement identique à l'original — la RAM évolue pendant la capture (processus actifs continuent). C'est forensiquement acceptable et documenté. L'hash MD5/SHA-256 du fichier dump suffit à prouver que le fichier n'a pas été altéré après la capture.

Hash(dump_après_capture) == Hash(dump_à_l'analyse) → intégrité prouvée

🎓 Exam Tip — RAM Forensique

Ordre de volatilité RFC 3227 : Registres → Cache → RAM → Réseau → Processus → Disque → Backups

Outils Windows : WinPmem (SANS recommandé) · DumpIt (urgence) · Magnet RAM Capture (forces de l'ordre)

Linux : LiME (module kernel) · insmod lime.ko "path=/mnt/usb/mem.lime"

Ce que la RAM contient : clés BitLocker VMK · malwares fileless · connexions C2 actives · hashes NTLM · tickets Kerberos

Volatility 3 : windows.pslist (processus) · windows.malfind (injection) · bitlocker (VMK) · windows.netscan

Hash dump RAM : acceptable d'avoir un hash post-capture (RAM évolue pendant la capture — c'est documenté)

BitLocker : si session déverrouillée → VMK en RAM → extraire avec Volatility avant extinction

Pourquoi un malware "fileless" est-il introuvable à l'analyse disque ?RAM forensique · Niveau : moyen
Un malware fileless (ex: PowerShell Empire, Cobalt Strike) s'exécute uniquement en mémoire RAM sans jamais écrire sur le disque. Il injecte du code dans des processus légitimes (svchost, explorer). À l'extinction, il disparaît sans laisser de trace sur le disque. Seule une capture RAM pendant que le système est allumé permet de le détecter.
Quelle commande Volatility 3 permet de détecter une injection de code malveillant ?Volatility · Niveau : facile
python3 vol.py -f dump.raw windows.malfind — détecte les régions mémoire avec permissions RWX (read-write-execute) inhabituelles, signature typique d'une injection de shellcode.
