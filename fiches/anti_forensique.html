Techniques anti-forensiques
Timestomping
Modification des timestamps NTFS ($STANDARD_INFORMATION) pour faire apparaître un fichier malveillant comme ancien. Outils : timestomp (Metasploit), SetMace.
Comparer $SI et $FILE_NAME — divergence = manipulation. Vérifier $UsnJrnl et $LogFile pour les vraies dates.
Wiping sécurisé
Écrasement des données avec des patterns aléatoires (DoD 5220.22-M : 7 passes). Outils : Eraser, SDelete, shred (Linux). Sur SSD, le trim rend le wiping partiellement inefficace.
Traces dans $UsnJrnl (fichier créé puis modifié intensivement), partitions formatées mais avec zones non allouées aléatoires.
ADS (Alternate Data Streams)
Cacher un exécutable ou des données dans un flux alternatif NTFS. Ex: calc.exe:malware.exe. Invisible dans l'explorateur Windows.
X-Ways → colonne ADS. Dir /r (cmd). SysinternalsSuite streams.exe. Tout fichier avec ":" dans le nom dans X-Ways.
Chiffrement / VeraCrypt
Volumes chiffrés indiscernables d'un espace aléatoire. Volume caché (déni plausible) : deux MDP pour deux volumes dans le même fichier.
Entropie ≥ 0.997, taille ronde, absence de magic bytes. Passware + RAM dump pour FVEK. Le déni plausible est légalement reconnu en Suisse.
Stéganographie
Cacher des données dans une image JPEG, PNG ou un fichier audio. Outils : Steghide, OpenStego, DeepSound. Le fichier apparaît normal visuellement.
StegDetect pour JPEG. Comparer la taille avec des images similaires. Analyser LSB (Least Significant Bit). Chi-square test sur distribution des pixels.
Effacement des logs
Vidage ou falsification des Event Logs Windows (wevtutil cl Security), modification des logs Linux (/var/log). Rootkits : hooks kernel pour masquer les entrées.
Gap dans les Event IDs (séquence non continue). $LogFile NTFS peut révéler les opérations même après effacement log. Sysmon écrit dans son propre canal.
Living off the Land
Utiliser des outils système légitimes (PowerShell, WMI, certutil, mshta) pour exécuter du code malveillant. Aucun binaire malveillant sur disque.
Event 4104 (ScriptBlock logging), Sysmon sur WMI et certutil, comparer les arguments de ligne de commande avec les usages normaux.
Rootkits
Code s'installant dans le noyau OS pour masquer processus, fichiers, connexions réseau. UEFI rootkits survivent au formatage.
Volatility : pslist vs psscan (processus cachés). Comparer les fichiers sur disque vs en mémoire. Analyse depuis un OS live externe.
Hiérarchie des contre-mesures
Détection systématique
  • Toujours comparer $SI vs $FILE_NAME (timestomping)
  • Analyser l'espace non alloué (données résiduelles)
  • Vérifier les flux ADS sur chaque fichier suspect
  • Calculer l'entropie des fichiers non reconnus
  • pslist vs psscan (Volatility) → rootkit
Sources alternatives
  • Si logs effacés → $UsnJrnl NTFS (difficile à effacer)
  • Si fichiers effacés → $MFT résiduel + carving
  • Si RAM sans volume chiffré → analyse Passware
  • Si timestamps altérés → registre + Prefetch + Event Logs
  • Si navigateur effacé → Volume Shadow Copy
Volume Shadow Copies (VSS)
Snapshots Windows — Contournement de l'effacement

Windows crée automatiquement des Shadow Copies avant les mises à jour et restaurations. Elles contiennent des versions antérieures de fichiers — même effacés depuis. X-Ways peut monter un VSS directement. vssadmin list shadows pour lister.

🇨🇭 Déni plausible (VeraCrypt) — droit suisse : Un suspect peut refuser de donner le mot de passe d'un volume caché en invoquant le nemo tenetur (art. 113 CPP). La preuve de l'existence d'un volume caché est forensiquement très difficile à établir par design.
