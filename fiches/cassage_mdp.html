Passware — cas d'usage
  • BitLocker, VeraCrypt, TrueCrypt
  • Documents Office (Word, Excel, PowerPoint)
  • PDF protégés par mot de passe
  • Archives ZIP, 7z, RAR
  • Fichiers p12 / PFX / PKCS#12
  • KeePass, 1Password, LastPass
  • Extraire FVEK depuis une image mémoire RAM
  • Comptes Windows (SAM, SYSTEM)
Hashcat — cas d'usage
  • Hashes NTLM (Windows SAM)
  • Hashes Linux /etc/shadow (SHA-512, bcrypt)
  • Hashes de bases de données (MySQL, MSSQL)
  • Hashes Wi-Fi WPA/WPA2 (PMKID, 4-way handshake)
  • Mode masque (pattern de MDP connu)
  • Attaque par règles complexes (best64, d3ad0ne)
  • Combinaison dictionnaire + masque (hybride)
  • Audit de MDP en entreprise
💡 Complémentarité : Passware récupère souvent la clé FVEK d'un volume BitLocker depuis un dump RAM, puis Hashcat peut être utilisé si seul le hash du mot de passe est disponible. Les deux outils s'utilisent ensemble dans une investigation réelle.

Commandes Hashcat — Exemples forensiques
# 1. Extraire les hashes NTLM depuis SAM + SYSTEM (avec secretsdump)
impacket-secretsdump -sam SAM -system SYSTEM LOCAL

# 2. Attaque dictionnaire sur hashes NTLM
hashcat -a 0 -m 1000 ntlm_hashes.txt rockyou.txt

# 3. Dictionnaire + règles (plus efficace)
hashcat -a 0 -m 1000 ntlm_hashes.txt rockyou.txt -r best64.rule

# 4. Masque ciblé — MDP type Mot123 (?u?l?l?d?d?d)
hashcat -a 3 -m 1000 hash.txt ?u?l?l?d?d?d

# 5. VeraCrypt AES — dictionnaire
hashcat -a 0 -m 13711 vc_header.bin rockyou.txt

# 6. Afficher progression + ETA
hashcat --status --status-timer 10 -a 0 -m 22600 bitlocker.hash words.txt

Fonctions clés de Passware
🧠 Analyse mémoire (RAM)

Fonctionnalité unique : Passware peut analyser une image RAM (dump mémoire) pour en extraire directement la FVEK (Full Volume Encryption Key) de BitLocker ou VeraCrypt si le volume était monté.

Outils RAM compatibles : Volatility, WinPMem, Magnet RAM Capture.
Format : .raw, .mem, .dmp, .vmem (VMware)

⚙️ Options d'attaque
  • Dictionnaire — listes intégrées + importation
  • Brute-force — charset et longueur configurables
  • Masque — pattern avec jokers
  • Xieve — intelligence artificielle de patterns
  • Previous passwords — réutilisation de MDP connus
  • GPU acceleration — CUDA (NVIDIA uniquement)
💡 Workflow Passware recommandé : (1) Essayer l'extraction RAM si une image mémoire est disponible → (2) Dictionnaire rockyou + dicts natifs → (3) Masque avec informations sur la cible → (4) Brute-force si court (≤ 6 car.)
BitLocker — Processus de récupération
1
Chercher la clé de récupération
Compte Microsoft, Active Directory, fichier .BEK sur clé USB, fichier texte imprimé. Souvent la solution la plus rapide.
2
Analyser une image RAM
Si le système était actif lors de la saisie, la FVEK peut être dans la mémoire. Passware → "Analyze Encrypted Disk" → sélectionner le dump RAM.
3
Attaque sur le hash BitLocker
Extraire le header BitLocker avec bitlocker2john ou Passware, puis attaquer avec Hashcat -m 22600.
4
TPM seul ?
Si le volume ne demande pas de MDP (TPM transparent), le déchiffrement peut être possible en montant le disque sur la machine d'origine ou via des attaques TPM hardware avancées.
Stratégie globale d'investigation
1
Inventaire des artefacts chiffrés
Identifier tous les fichiers/volumes chiffrés via X-Ways (attribut eIA), Axiom (section Chiffrement), entropie élevée (≥ 0.95). Lister les algorithmes détectés.
X-Ways → Rapport → Fichiers chiffrés confirmés
2
Chercher les indices de mot de passe
Fichiers texte, sticky notes, navigateur (mots de passe sauvegardés), boîte mail (compte Microsoft, clé de récupération), Active Directory, registre Windows (HKCU\Software).
X-Ways → Recherche texte "password" "mdp" "pass" "bitlocker"
3
Analyse de la mémoire RAM
Si disponible : analyser le dump RAM avec Passware (FVEK) ou Volatility (processus, artefacts en mémoire). Priorité absolue si le système était en cours d'exécution lors de la saisie.
Passware → Memory Imager / Analyze RAM · Volatility bitlocker plugin
4
Attaque dictionnaire + règles
Lancer Hashcat avec rockyou.txt + best64.rule sur les hashes extraits. Paralléliser avec Passware sur les fichiers Office/archives. Durée typique : 1–24h selon GPU.
hashcat -a 0 -m [type] hashes.txt rockyou.txt -r best64.rule
5
Profiler la cible pour masque ciblé
Analyser les autres MDP connus du suspect (SAM, navigateur), identifier des patterns (prénom+date, ville+chiffres). Construire un masque sur mesure.
hashcat -a 3 -m [type] hashes.txt ?u[prénom]?d?d?d?d
6
Documenter et rapporter
Chaque tentative doit être documentée (outil, version, durée, résultat). Le mot de passe trouvé est une preuve : noter les conditions exactes de récupération.
Inclure dans le rapport forensique : méthode + hash avant/après + timestamp
Cadre légal suisse
⚖️ Aspects juridiques — CPP & Droit suisse
Art. 265 CPP — Obligation de remise : le prévenu peut être contraint de remettre les mots de passe sur ordonnance du Ministère public. Refus = possible sanction.
Art. 113 CPP — Nemo tenetur : le prévenu n'est pas tenu de contribuer à sa propre incrimination. Le cassage forensique contourne ce principe légalement.
Art. 246–248 CPP — Perquisition informatique : le cassage de mot de passe est une mesure de contrainte nécessitant une autorisation judiciaire si hors flagrant délit.
LRens / LSCPT — Accès aux données chiffrées par les services de renseignement : procédure séparée du CPP.
Rapport forensique — Documenter : autorisation légale obtenue, méthode utilisée, temps écoulé, résultat, chaîne de possession du hash et du MDP trouvé.
