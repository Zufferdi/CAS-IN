🏗️ USB = Universal Serial Bus Protocol
Standard for connecting peripherals. From forensic perspective: device tracking, exfiltration detection, data recovery. Windows logs all USB connections in registry.
USB Protocol Layers
Layer Fonction Forensique
Physical USB connectors, wiring, power Device identification (connector type)
Protocol Handshake, data transfer, power mgmt PCAP analysis (if captured)
Device Class Mass storage, HID, CDC (what type?) Classify device (thumb drive, keyboard, etc.)
Filesystem FAT32, exFAT, NTFS (what data?) File recovery, timestamps
Common USB Device Classes
  • Mass Storage (0x08): USB stick, external drive, SD card reader
  • HID (0x03): Keyboard, mouse, joystick
  • Printer (0x07): Printer, scanner
  • Communications (0x02): Modem, phone, Ethernet adapter
📝 Windows USBSTOR Registry = Device History
Every USB device connected = logged in USBSTOR. Contains: device ID, vendor, model, serial number, connection timestamps.
USBSTOR Registry Path & Keys
HKLM\System\CurrentControlSet\Enum\USBSTOR

Example subkey:
Disk&Ven_Kingston&Prod_DataTraveler_3.0&Rev_1.10\
    E6B4C3D2F5A1B0C9

Inside:
├─ FriendlyName: "Kingston DataTraveler 3.0"
├─ Manufacturer: "Kingston"
├─ Model: "DataTraveler 3.0"
├─ Serial Number: "E6B4C3D2F5A1B0C9"
└─ LastWrite timestamp: 2024-03-20 14:32:15

⚠️ LastWrite = when device FIRST connected
Additional USB Artifact Locations
Registry Path Information
...Enum\USB USB device descriptors (VID, PID)
...MountedDevices Drive letters assigned to USB devices
...Explorer\MountPoints2 USB connections (per user)
...Class\{36fc9e60...} USB mass storage class descriptor
🚨 ForensicValue: USBSTOR
  • First connection time → When device first plugged
  • Serial number → Uniquely identify device
  • Vendor/Model → Trace ownership (registered owner?)
  • Multiple connections → Device used repeatedly
📅 USB Connection Timeline = Exfiltration Proof
Combining USBSTOR timestamps + filesystem access times = complete USB usage timeline. Proves device connection, data transfer, disconnection.
Timeline Reconstruction Process
Step-by-step:
  1. USBSTOR LastWrite → Device first connected (exact time)
  2. MountedDevices → What drive letter assigned
  3. File modification times → When files copied to USB
  4. Recycle Bin → Files deleted from USB?
  5. Event Log → Device safely removed (if logged)
  6. USB descriptor fields → ParentIdPrefix (disconnection indicator)

🆔 Device ID = Unique Identification
Every USB device has unique identifiers: VID (Vendor ID), PID (Product ID), serial number. Used to identify device across connections, track ownership.
VID/PID Structure & Lookup
Example Device ID:
VID_0951&PID_1666
├─ VID_0951 = Kingston Technology Corporation
├─ PID_1666 = DataTraveler 3.0 (Kingston product code)

Serial: E6B4C3D2F5A1B0C9
↓
This identifies EXACTLY which Kingston stick
(if serial recovered, can trace owner/retailer)
VID/PID Lookup Resources
  • usb.org → Official VID database (if public)
  • Linux USB IDs → usb-ids.grepcode.com (crowd-sourced)
  • Registry keys → Device names sometimes stored locally
  • DeviceManager → Windows Device Manager shows name
Serial Number Forensics
🔍 Serial Number = Ownership Trace
  • Unique per device (manufacturer assigns)
  • Traceable through retailer (e.g., Amazon receipt)
  • Possible identify actual owner (if serial registered)
  • Valuable for attribution (this device = that person)

CLI Quick Commands
# Export USBSTOR from offline registry
$ rip.pl -r SYSTEM -p usbdevices

# List connected USB devices (Linux)
$ lsusb -v

# Extract USB artifacts from memory dump
$ volatility3 -f memory.raw windows.registry.printkey --key "Enum\\USBSTOR"

# Parse USBSTOR timestamps (Windows)
$ reg query "HKLM\System\CurrentControlSet\Enum\USBSTOR" /s

# Timeline USB connections
$ rip.pl -r SYSTEM -p usbdevices | grep -i "timestamp\|serial"
✅ Workflow Complet USB Forensique
  1. Extract USBSTOR from offline registry (RegRipper or regedit)
  2. Parse device IDs (VID, PID, serial numbers)
  3. Lookup vendors (usb-ids, manufacturer)
  4. Collect timestamps (USBSTOR LastWrite = first connection)
  5. Check MountedDevices (drive letter assigned)
  6. Correlate with filesystem timestamps (files copied when?)
  7. Check Event Log (device safely removed entry?)
  8. Timeline: connection → data transfer → disconnection
  9. Rapport: device identification, timeline, exfiltration proof
