Splunk — Investigation forensique (SPL)
-- Échecs d'authentification sur 24h (Event ID 4625)
index=windows EventCode=4625
| stats count by src_ip, user | sort -count

-- Timeline d'un IP suspect
index=* src_ip="10.0.0.42"
| timechart span=1h count by EventCode

-- Connexions hors horaires de bureau
index=windows EventCode=4624 LogonType=2
| eval hour=strftime(_time,"%H")
| where hour<7 OR hour>20
| table _time, user, src_ip, host

Sigma Rules — Langage universel de détection
🛡️ Sigma est un format YAML générique pour les règles de détection — le "YARA des logs". Une règle Sigma peut être convertie vers Splunk SPL, Elastic KQL, Azure Sentinel KQL, etc.
title: Mimikatz via ProcessAccess
status: stable
logsource:
  product: windows
  service: sysmon
detection:
  selection:
    EventID: 10
    TargetImage|endswith: '\lsass.exe'
  condition: selection
level: high
tags:
  - attack.credential_access
  - attack.t1003.001

Conversion : pySigma, sigmac · Repo : github.com/SigmaHQ/sigma · Intégration : Chainsaw, Hayabusa (sur EVTX), Elastic SIEM
