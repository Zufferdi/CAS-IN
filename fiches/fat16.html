FAT32 supprime le Root Directory fixe et le place dans les clusters de données — le root directory est alors un fichier ordinaire.

Entrées de répertoire — SFN et LFN (32 bytes chacune)
SFN — Short File Name (8.3)

Maximum 8 caractères + 3 pour l'extension. Tout en majuscules à l'origine. Le tilde (~) est utilisé pour générer les noms courts : SEPTEM~1.TXT

Structure 32 bytes : nom (8B) + ext (3B) + attributs (1B) + réservé (10B) + heure (2B) + date (2B) + cluster de début (2B) + taille (4B)

LFN — Long File Name (13 chars/entrée)

Chaque entrée LFN stocke 13 caractères en UTF-16 (26 bytes). Placées avant le SFN correspondant.

Attribut = 0x0F (00001111 = Read-Only + Hidden + System + Volume — combinaison impossible → signature LFN)

Un fichier de 26 caractères → 2 entrées LFN + 1 SFN = 96 bytes au total

Valeurs spéciales FAT16

0x0000 — Cluster libre
0x0001 — Réservé
0x0002–0xFFEF — Cluster suivant
0xFFF7 — Secteur défectueux
0xFFF8–0xFFFF — Fin de fichier (EOF)

FAT32 : EOF = 0x0FFFFFFF

Clusters 0 et 1 réservés

Les données commencent toujours au cluster 2.

Cluster 0 = signature FAT (F8FF)
Cluster 1 = toujours FFFF

La FAT 2 est un miroir exact de FAT 1, utilisée uniquement en cas de corruption. Si FAT 1 ≠ FAT 2 → corruption partielle détectée.

Effacement d'un fichier — Mécanisme E5
1
La 1ère lettre du nom SFN est remplacée par 0xE5 — marqueur de suppression. RAPPORT.TXT → ?APPORT.TXT (premier byte = E5). La première lettre est théoriquement récupérable via les entrées LFN.
2
Toutes les entrées LFN associées reçoivent aussi 0xE5 à leur premier byte. Le checksum LFN n'est plus valide.
3
Le chaînage des clusters dans la FAT est remis à 0x0000 — les clusters sont marqués comme libres. Les données ne sont pas effacées physiquement — elles restent sur le disque jusqu'à leur réécriture.
✓
Récupération (carving) : Lire le SFN pour trouver la taille et le cluster de début → calculer le nombre de clusters → vérifier si les clusters sont contigus → reconstruire le fichier. WinHex : réécrire le premier byte du SFN + le chaînage dans la FAT.
Slack Space — Espace résiduel
Définition

Un cluster entier est alloué même pour un fichier de 7 bytes (sur cluster de 4096 bytes → 4089 bytes de slack). Les 4089 bytes résiduels peuvent contenir des fragments de fichiers précédents qui occupaient ces clusters.

Valeur forensique

Le slack space peut contenir des fragments de documents, images, mots de passe, messages — des données prétendument effacées. X-Ways → Data Interpreter indique précisément où s'arrête le fichier logique et où commence l'espace résiduel.

Horodatage MS-DOS — 32 bits compressés
Date (16 bits)
Bits 15–9 : Année (depuis 1980, max 127 = 2107) · Bits 8–5 : Mois (1–12) · Bits 4–0 : Jour (1–31)
Heure (16 bits)
Bits 15–11 : Heures (0–23) · Bits 10–5 : Minutes (0–59) · Bits 4–0 : Secondes/2 (résolution : 2 secondes)
Précision limitée à 2 secondes — En forensique, deux fichiers copiés en moins de 2 secondes peuvent avoir le même timestamp FAT. exFAT améliore la résolution à 10 millisecondes.
