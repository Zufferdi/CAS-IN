Encodages de caractères
ASCII — 1 byte par caractère

128 caractères (0–127). Lettres A–Z (41–5A), a–z (61–7A), 0–9 (30–39).
Mnémotechnique : A = 65 = 0x41 · a = 97 = 0x61 (diff = 32 = 0x20)

UTF-8 — 1 à 4 bytes

Compatible ASCII pour les 128 premiers. Europe occidentale = 2 bytes. Asiatiques = 3 bytes. Le plus utilisé sur le web et Linux. Encodage variable.

UTF-16 — 2 bytes par caractère
Pratiquer :🧪 🔄 Endianness🧪 🔢 Bases & Encodages
Voir aussi :🔗 Disques🔗 Magic Bytes

Utilisé dans LFN des systèmes FAT et Windows. Dans un hexdump, chaque caractère a un octet nul intercalé : 68 00 = 'h', 65 00 = 'e'. Attention au Little Endian.

ROT13 — substitution +13

A→N, B→O… Utilisé dans UserAssist du registre Windows pour obfusquer les chemins d'exécutables. Outil : CyberChef (recette ROT13).
