Les ruches du registre (Hives)
Structure du Registre — Points d'entree principaux
HKLM (Machine)
SAM · SYSTEM · SOFTWARE · SECURITY
HKCU (Utilisateur courant)
NTUSER.DAT · USRCLASS.DAT
HKU (Tous utilisateurs)
Un NTUSER.DAT par SID
Offline (forensique)
C:\Windows\System32\config\
SAM
C:\Windows\System32\config\SAM
Comptes locaux + hashes NTLM (avec SYSTEM). Nécessite les deux ruches pour extraire les hashes.
SYSTEM
C:\Windows\System32\config\SYSTEM
Configuration matérielle, périphériques USB connectés (USBSTOR), nom machine, clé de déchiffrement du SAM (SysKey).
SOFTWARE
C:\Windows\System32\config\SOFTWARE
Applications installées, autorun, MRU, dernières connexions réseau, type de timezone.
SECURITY
C:\Windows\System32\config\SECURITY
Politiques de sécurité, LSA secrets (MDP de services), sessions réseau.
NTUSER.DAT
C:\Users\[utilisateur]\NTUSER.DAT
Préférences utilisateur, MRU (fichiers récents), TypedURLs (URLs tapées IE/Edge), UserAssist (programmes lancés).
USRCLASS.DAT
C:\Users\[user]\AppData\Local\Microsoft\Windows\UsrClass.dat
ShellBags (navigation explorateur de fichiers, y compris dossiers supprimés), associations de fichiers.
DEFAULT
C:\Windows\System32\config\DEFAULT
Profil par défaut pour les nouveaux utilisateurs. Parfois utilisé pour la persistance.

Outils d'analyse
RegRipper

Extracteur de plugins Perl — analyse automatique des ruches. Plus de 200 plugins spécialisés (usbstor, userassist, shellbags, autoruns, etc.).


# Analyser NTUSER.DAT
rip.pl -r NTUSER.DAT -f ntuser

# Plugin spécifique USB
rip.pl -r SYSTEM -p usbstor
Registry Explorer (Eric Zimmermann)

GUI Windows pour l'analyse de ruches hors ligne. Supporte les ruches de transactions (.LOG), la reconstruction de ruches corrompues, la recherche full-text.


Outil de référence forensique — gratuit sur ericzimmermantools.com

impacket-secretsdump
impacket-secretsdump -sam SAM -system SYSTEM LOCAL

Extrait les hashes NTLM à partir des fichiers SAM+SYSTEM copiés hors ligne. Nécessite les deux fichiers ensemble.

ShellBags Explorer (EZtools)

Analyse des ShellBags — révèle les dossiers navigués même si supprimés, les lecteurs réseau et périphériques amovibles accédés.


Clé forensique : prouve qu'un utilisateur a accédé à un dossier à une date donnée.

🎓 Exam Tip — Registre Windows

USBSTOR : USB (modele + S/N + dates) — ruche SYSTEM

UserAssist : programmes GUI — encode ROT13 — decoder avant lecture

ShellBags : dossiers navigues meme supprimes — USRCLASS.DAT

Run/RunOnce : persistance malware — HKLM + HKCU

SAM + SYSTEM : hashes NTLM — impacket-secretsdump — hashcat -m 1000

AmCache : hash SHA-1 des executables + date execution

ShimCache : preuve de presence (pas forcement d'execution)

Pourquoi UserAssist est-il encode en ROT13 et ou le trouver ?Registre Windows
ROT13 masque les chemins de programmes depuis Windows XP. Ruche : NTUSER.DAT a la cle Software\Microsoft\Windows\CurrentVersion\Explorer\UserAssist. Decoder avec CyberChef ROT13, RegRipper ou Registry Explorer (automatique).
Difference forensique entre ShimCache et AmCache ?Registre Windows
ShimCache : presence sur le systeme (pas forcement execute). Mis a jour au demarrage.
AmCache : execution prouvee + hash SHA-1 + chemin + date. Fichier : C:\Windows\AppCompat\Programs\Amcache.hve
