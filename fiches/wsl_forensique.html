WSL Forensique — Windows Subsystem for Linux

WSL1 vs WSL2 · Artefacts Windows · ext4.vhdx · Détection d'usage

"WSL has become a common tool for attackers on Windows — it provides a Linux environment inside Windows, bypassing some AV solutions and leaving artefacts in unexpected places."
— SANS FOR508 · WSL as an attack vector, 2022
💡 Double danger forensique : WSL peut être utilisé par des attaquants pour exécuter des outils Linux (nmap, wget, bash scripts) tout en restant dans Windows, souvent sans que les solutions EDR Windows ne les détectent correctement.

📁 Artefacts WSL — Localisation Windows

ℹ️
Les artefacts WSL se trouvent dans le profil utilisateur Windows, sous %LocalAppData%\Packages\. Chaque distribution installée a son propre répertoire.
  • Distributions installées : HKCU\Software\Microsoft\Windows\CurrentVersion\Lxss\
  • Ubuntu : %LocalAppData%\Packages\CanonicalGroupLimited.Ubuntu…\LocalState\
  • Debian : %LocalAppData%\Packages\TheDebianProject.DebianGNULinux…\
  • Historique bash : dans le VHD : /root/.bash_history ou /home/user/.bash_history
  • Logs Linux : /var/log/ dans le VHD
  • Réseau WSL2 : Logs dans Event Log → Microsoft-Windows-Hyper-V-VmSwitch

🔍 Détection de l'usage WSL

Windows Event Logs

  • Event ID 4688 : processus wsl.exe lancé
  • Event ID 4688 : bash.exe, ubuntu.exe, debian.exe
  • Prefetch : WSL.EXE-*.pf, BASH.EXE-*.pf
  • Amcache : entrées pour wsl.exe et les distros

Registre Windows

  • HKCU\Software\Microsoft\Windows\CurrentVersion\Lxss\
  • Clés par distribution : GUID + chemin + version WSL
  • DefaultDistribution = distribution par défaut
  • BasePath = chemin vers les fichiers de la distro

🔧 Analyser le ext4.vhdx (WSL2)

1
Localiser le VHDX
Chercher ext4.vhdx dans le profil utilisateur. Calculer le hash avant manipulation.
%LocalAppData%\Packages\CanonicalGroupLimited.Ubuntu...\LocalState\ext4.vhdx
2
Convertir ou monter
Option 1 : Monter le VHDX sous Windows et l'accéder via un outil forensique Linux. Option 2 : Convertir en raw avec qemu-img.
qemu-img convert -f vhdx -O raw ext4.vhdx disk.raw
3
Analyser avec outils Linux
Monter le raw sur Linux pour accéder à l'arborescence EXT4. Récupérer .bash_history, /var/log/, /tmp/, /home/, /root/.
sudo mount -o ro,loop disk.raw /mnt/wsl && ls /mnt/wsl/root/
