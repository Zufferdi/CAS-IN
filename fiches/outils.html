X-Ways — Volume Snapshot & Refine
Volume Snapshot

Reconstruction complète de la structure d'un volume : fichiers existants, supprimés, carving, slack space. Ne modifie pas la source.

Workflow recommandé :
① Snapshot simple (rapide) pour exploration initiale
② Refine Snapshot ciblé sur les objets pertinents
③ Ne jamais refaire un snapshot partiel sur un existant → risque de corruption

Refine Snapshot

Analyse approfondie configurable :
• Carving par signature (magic bytes)
• Vérification des signatures de fichiers (Type Status)
• Extraction des emails (PST/OST/MBOX)
• Analyse des archives (ZIP, 7z, RAR)
• Test de mots de passe (liste configurable)
• Calcul d'empreintes (hash) par secteur
• Extraction des métadonnées internes (EXIF)

Recherche — Logique vs Physique
ModePortéeVitesseUsage

Recherche physique sur 1 To = plusieurs heures. Toujours limiter le périmètre selon l'hypothèse d'enquête. Contexte de résultat par défaut : 128 bytes avant/après.

Type Status — Détection de dissimulation
Valeurs de Type Status

OK — Extension correspond à la signature détectée
Mismatch — Extension ≠ signature → probable dissimulation (rapport.pdf qui est en réalité un .exe)
Unknown — Type non reconnu dans la base X-Ways
e — Probablement chiffré
e? — Probablement chiffré (haute entropie)

Analyse d'entropie

L'entropie mesure le caractère aléatoire des données. Haute entropie ≈ 1.0 → chiffrement ou compression forte.

Dans X-Ways : icône loupe → afficher l'entropie. CyberChef → recette "Entropy" pour analyser un fichier spécifique.

Un fichier vidéo compressé peut aussi avoir une haute entropie sans être chiffré.

Carving — Récupération par signature
Principe

Récupération de fichiers basée sur leurs magic bytes, sans système de fichiers. Parcours de l'espace non alloué à la recherche de signatures connues (FF D8 FF = JPEG, 50 4B 03 04 = ZIP/DOCX).

Fonctionne même sans entrée de répertoire valide — parfait pour les supports FAT après effacement E5.

Stratégie

1. Chercher d'abord un fichier existant dans le système
2. Si supprimé : vérifier si les clusters sont contigus
3. Si contigus → reconstruction directe depuis le cluster de début + taille du SFN
4. Si fragmentés → carving multi-fragment plus complexe
5. Résultat potentiellement corrompu si clusters réalloués

Fuzzy Doc & Emails
Fuzzy Doc — Logique floue

Recherche de fichiers similaires (ex. toutes les factures). X-Ways crée un set de hash "fuzzy doc" basé sur un fichier de référence.

Applications : rechercher des variantes d'un document, identifier des copies modifiées, retrouver des doublons partiels.

PST/OST — Messagerie

Les fichiers PST (Outlook) et MBOX (Thunderbird) sont des conteneurs complexes de milliers d'objets.

Workflow X-Ways : 1. Identifier le type (PST/OST) via Type Status · 2. Refine Snapshot → extraire les emails · 3. Filtrer par expéditeur/destinataire · 4. Exporter avec pièces jointes · 5. Vérifier les éléments supprimés dans le dossier Deleted Items

CyberChef — Couteau suisse de la donnée
Principe des recettes

Chaîne d'opérations appliquées séquentiellement. Glisser-déposer des opérations. Utiliser hors ligne en contexte forensique (télécharger le .zip depuis GitHub, ouvrir CyberChef_vX.html directement).

Opérations clés : From Base64, From Hex, ROT13, MD5/SHA2, Extract IP/Email/URLs, Magic (détection automatique), XOR, Entropy

Exemples forensiques

From Hex → 4D 5A = MZ = exécutable Windows
ROT13 → décode les chemins UserAssist du registre
Entropy → taux d'aléatoire d'un fichier
From Base64 → décode les scripts PowerShell obfusqués
Magic → détecte l'encodage inconnu automatiquement
