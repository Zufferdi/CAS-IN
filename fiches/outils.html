X-Ways Forensics — Philosophie et workflow
ℹ X-Ways oblige l'analyste à comprendre ce qu'il cherche avant de lancer la moindre opération. Rien n'est automatisé sans validation explicite — en contexte judiciaire, l'expert doit pouvoir justifier chaque résultat.
Accès physique vs logique
  • Physical Media (F9) : bypasse l'OS, lit chaque secteur (MBR, espace non alloué, HPA). Méthode forensique correcte.
  • Logical Drive : passe par Windows → peut bloquer des zones, modifier des timestamps, ignorer l'espace non alloué.
  • Toujours ouvrir en Physical Media.
Volume Snapshot & Refine
  • Snapshot simple : vue globale rapide
  • Refine Snapshot : carving par signature, fausses extensions, archives, messagerie, calcul hashes
  • Un snapshot mal configuré = résultats manquants ou trop de faux positifs
  • Nouveau cas pour chaque investigation (évite la contamination)

Suite Eric Zimmerman (outils gratuits, référence DFIR Windows)
PECmd

Parse les fichiers Prefetch (.pf). Extrait : timestamps (8 max), compteur, DLL chargées, hash interne.

PECmd.exe -d C:\Windows\Prefetch --csv output.csv

MFTECmd

Parse la $MFT entière → CSV exploitable sous Excel. $SI vs $FN (timestomping). Fichiers supprimés.

MFTECmd.exe -f $MFT --csv output.csv

LECmd

Parse les fichiers .LNK. Extrait : chemin cible, Volume Serial Number, timestamps cible, machine source.

LECmd.exe -d C:\...\Recent --csv output.csv

EvtxECmd

Parse les Event Logs .evtx → CSV normalisé pour Timesketch ou Excel.

EvtxECmd.exe -d C:\...\winevt\Logs --csv output.csv

ShellBagsExplorer

Analyse USRCLASS.DAT et NTUSER.DAT. Reconstruit l'arborescence des dossiers explorés avec timestamps.

AmcacheParser

Parse Amcache.hve. Hash SHA-1 des exécutables présents sur le système.

Autres outils forensiques de référence
Acquisition & Analyse disque
  • Autopsy/TSK : open-source, modules automatiques, bonne entrée de gamme
  • FTK Imager : acquisition E01, preview sans modification
  • Guymager : acquisition Linux GUI, AFF/E01/DD
  • Scalpel/Foremost : file carving par signatures
  • PhotoRec : récupération multiformat (y compris EXT4)
Mémoire & Réseau
  • Volatility3 : analyse RAM. vol.py -f mem.raw windows.pslist
  • WinPmem / DumpIt : capture RAM Windows
  • Wireshark : analyse PCAP. Filtres : tcp.flags.syn==1
  • Zeek (Bro) : analyse logs réseau longue durée
  • Plaso (log2timeline) : super-timeline multiformat
Mobile & OSINT
  • Cellebrite UFED : extraction physique/logique mobile
  • Magnet AXIOM : mobile + desktop + cloud, corrélation cross-appareils
  • DB Browser for SQLite : Chrome/Firefox history, WhatsApp, iOS databases
  • exiftool : métadonnées EXIF multiformat
Malware & Hachage
  • pestudio : analyse statique PE Windows (imports, exports, entropy)
  • Ghidra : décompilateur/désassembleur (NSA, open-source)
  • Hashcat : cassage passwords GPU
  • Passware : cassage fichiers chiffrés (Office, PDF, p12)
  • ssdeep : fuzzy hashing pour variantes malware
