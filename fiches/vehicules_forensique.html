🇨🇭 Jurisprudence suisse : Le TF a validé les données GPS de véhicules comme preuve dans plusieurs affaires pénales. Les données intégrées au véhicule sont pleinement recevables — contrairement au GPS posé sans mandat (affaire Soleure, art. 269 CPP).

EDR — Event Data Recorder
Données enregistrées (5s avant impact)
  • Vitesse du véhicule à t-5s, t-1s, t0
  • Position de l'accélérateur (%)
  • Pression sur la pédale de frein
  • Engagement des airbags (quels, quand)
  • Port ceintures conducteur + passagers
  • Delta-V (variation vitesse = force de l'impact)
Extraction EDR
  • Outil standard : Bosch CDR (Crash Data Retrieval)
  • Connexion via port OBD-II du véhicule
  • Logiciel CDR → export PDF + CSV
  • Expert certifié Bosch CDR pour recevabilité judiciaire
  • Obligatoire sur véhicules neufs UE depuis 2022
Tesla — Cas particulier forensique
Sources de données Tesla
  • Dashcam : vidéo 360° continue (clé USB)
  • Sentry Mode : enregistrement si mouvement détecté à l'arrêt
  • Logs de conduite : GPS précis 1m, vitesse, Autopilot actif/inactif
  • Logs de charge : quand, où, durée, état batterie
  • Contacts / Bluetooth : appareils appairés
Accès aux données
  • Clé USB : vidéos Dashcam + Sentry (format MP4)
  • Portail Tesla → données personnelles (LPD/RGPD)
  • Demande légale à Tesla → logs serveur complets
  • Précision GPS : 1 mètre, timestamp à la seconde
Infotainment — Risque vie privée persistant
⚠️ Donnée persistante après vente : Quand un smartphone se connecte via Bluetooth, le véhicule peut importer contacts, historique d'appels et SMS. Ces données persistent après la vente si le reset usine n'est pas effectué.
  • Constructeurs concernés : Toyota, Honda, BMW, Mercedes, Volkswagen, Hyundai
  • Outil forensique : Cellebrite UFED 4PC avec module véhicule
  • Reset usine souvent insuffisant — données dans des partitions annexes
⚖️ Examen CAS-IN : EDR = 5 secondes avant collision (vitesse, freinage, airbags, ceintures) · Outil extraction EDR = Bosch CDR · Tesla = logs GPS précis 1m + Dashcam + Sentry Mode · Infotainment = contacts Bluetooth importés persistants même après vente sans reset · Cloud constructeur = télémétrie via demande légale · OBD-II port = accès données ECU · Données GPS intégrées au véhicule = preuve recevable en Suisse
