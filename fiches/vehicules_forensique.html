Véhicules Connectés — Forensique Automobile

EDR · Infotainment · GPS · Bluetooth · Tesla · Données probantes

"Modern vehicles are rolling computers with 100+ ECUs, terabytes of sensor data, and cloud connectivity. The car knows where it went, how fast, who sat in it, and what music played."
— SANS FOR585 · Smartphone Forensics (et vehicules)
🇨🇭 Jurisprudence suisse : Le Tribunal fédéral a validé l'utilisation des données GPS des véhicules comme preuve dans plusieurs affaires pénales. Un cas célèbre (Soleure, 2015) impliquait justement des données GPS — mais d'un traceur posé sans mandat (voir fiche Droit Suisse). Les données intégrées au véhicule, elles, sont pleinement recevables.

🚨 EDR — Event Data Recorder

ℹ️
L'EDR (boîte noire automobile) enregistre les 5 secondes précédant un événement déclencheur (déploiement airbag, freinage d'urgence). Obligatoire dans les véhicules neufs en UE depuis 2022.

Données EDR typiques

  • Vitesse du véhicule à t-5s, t-1s, t0
  • Position de l'accélérateur (%)
  • Pression sur la pédale de frein
  • Engagement des airbags (quels, quand)
  • Port ceintures (conducteur, passagers)
  • Position du volant
  • Delta-V (variation de vitesse = force de l'impact)

Extraction EDR

  • Outil standard : Bosch CDR (Crash Data Retrieval)
  • Connexion via port OBD-II du véhicule
  • Logiciel CDR analyse et exporte en PDF + CSV
  • Expert certifié Bosch CDR pour la recevabilité judiciaire
  • Connexion directe à l'ECU si OBD non disponible

⚡ Tesla — Cas particulier forensique

💡
Tesla = ordinateur sur roues avec des logs extrêmement détaillés et des caméras intégrées (Dashcam + Sentry Mode). Les logs Tesla ont été utilisés dans de nombreuses affaires pénales et civiles.

Sources de données Tesla

  • Dashcam : Vidéo 360° continue (clé USB)
  • Sentry Mode : Enregistrement si mouvement détecté à l'arrêt
  • Logs de conduite : GPS précis, vitesse, autopilot activé/désactivé
  • Logs de charge : Quand, où, durée, état batterie
  • Contacts / Bluetooth : Appareils appairés

Accès aux données

  • Clé USB : vidéos Dashcam + Sentry (format MP4)
  • Portail Tesla → données personnelles (RGPD/LPD)
  • Demande légale à Tesla → logs serveur complets
  • Extraction locale : interface service (port Ethernet sous le capot avant)
  • Logs Tesla ont une précision GPS de 1m et timestamp à la seconde

📱 Infotainment — Contacts et appels Bluetooth

⚠️
Risque de vie privée ignoré : Quand un smartphone se connecte via Bluetooth, le véhicule peut importer automatiquement les contacts, l'historique des appels et des SMS. Ces données persistent après la vente du véhicule si le reset usine n'est pas effectué.
  • Constructeurs concernés : Toyota, Honda, Hyundai, BMW, Mercedes, Volkswagen
  • Outil forensique : Cellebrite UFED 4PC avec module véhicule
  • Données extractibles : contacts (vcf), historique appels, SMS fragmentés, Wi-Fi passwords
  • Certains systèmes stockent la localisation GPS associée aux contacts ("maison", "bureau")
  • Reset usine souvent insuffisant — certaines données persistent dans des partitions annexes
