🚗 Véhicule moderne — 100+ ordinateurs sur roues
Une voiture neuve en 2026 contient typiquement 100 à 150 ECU (Electronic Control Units), plusieurs téraoctets de données capteurs, et une connectivité cloud permanente (4G/5G, WiFi, Bluetooth). Forensiquement, le véhicule est un témoin silencieux extraordinaire : il sait où il est allé (GPS), à quelle vitesse (EDR, ECU), qui était à bord (Bluetooth appairé, capteurs sièges, ceintures), quelle musique a joué (infotainment), combien de fois la portière s'est ouverte (logs CAN bus), et même — pour les Tesla — quelles vidéos ont été enregistrées autour du véhicule (Dashcam + Sentry Mode). Cinq sources principales : EDR (5 sec avant impact ; obligatoire dans l'UE par le Règlement 2019/2144 — nouveaux types depuis le 6 juillet 2022, tous véhicules neufs depuis le 7 juillet 2024), GPS / Navigation (itinéraires, favoris), Infotainment IVI (contacts Bluetooth, appels, SMS importés du smartphone), ECU / OBD-II (paramètres moteur, codes erreur), et Cloud constructeur (télémétrie temps réel — accessible sur réquisition). En Suisse, le TF a validé les données GPS intégrées au véhicule comme preuve dans plusieurs affaires pénales (contrairement au GPS posé sans mandat — affaire Soleure, art. 269 CPP).

💥 EDR — Event Data Recorder
Boîte noire automobile · obligatoire sur véhicules neufs UE — Règlement 2019/2144 (juillet 2022 nouveaux types · juillet 2024 tous neufs).
📊 Données enregistrées (5s avant impact)
  • Vitesse du véhicule à t-5s, t-1s, t0 (impact)
  • Position de l'accélérateur (% pédale)
  • Pression sur la pédale de frein
  • Engagement des airbags (quels, à quel timing)
  • Port ceintures conducteur + passagers
  • Delta-V (variation vitesse = force de l'impact)
  • Régime moteur (RPM)
  • Position du volant
  • Cap véhicule (yaw rate)
🔧 Extraction EDR
  • Outil standard : Bosch CDR (Crash Data Retrieval)
  • Connexion via port OBD-II du véhicule
  • Logiciel CDR → export PDF + CSV standardisé
  • Expert certifié Bosch CDR requis pour recevabilité judiciaire
  • Obligatoire sur véhicules neufs UE depuis 2022
  • Norme : SAE J1698 (standard EDR US)
  • Format de données : CDX (Bosch)
  • Si véhicule détruit : extraction directe depuis l'airbag control module
⚡ Tesla — Cas particulier forensique
Tesla est l'un des véhicules les plus instrumentés au monde — mine d'or pour l'enquêteur.
📹 Sources de données Tesla
  • Dashcam : vidéo 360° continue (4 caméras) sur clé USB FAT32 dédiée
  • Sentry Mode : enregistrement si mouvement détecté à l'arrêt (10 min de buffer)
  • Logs de conduite : GPS précis 1m, vitesse, Autopilot actif/inactif, modes
  • Logs de charge : quand, où, durée, état batterie début/fin
  • Contacts / Bluetooth : appareils appairés (jusqu'à 10)
  • Profils conducteur : sièges, miroirs, climatisation par utilisateur
  • Logs Autopilot : disengagements, alertes, override conducteur
🔓 Accès aux données Tesla
  • Clé USB : vidéos Dashcam + Sentry (format MP4, 1280×960)
  • Portail Tesla → données personnelles RGPD/LPD
  • Demande légale à Tesla → logs serveur complets via MLAT
  • Précision GPS : 1 mètre, timestamp à la seconde
  • Données chiffrées en transit mais Tesla a les clés (pas E2EE)
  • Tesla Service Center peut extraire MCU (Media Control Unit) en cas de défaillance
  • Ordinateur principal : Tesla MCU (basé sur Linux NVIDIA Tegra)
📱 Infotainment — Risque vie privée persistant
⚠️ Donnée persistante après vente : Quand un smartphone se connecte via Bluetooth, le véhicule peut importer contacts, historique d'appels et SMS. Ces données persistent après la vente si le reset usine n'est pas effectué — pratique courante des concessionnaires.
  • Constructeurs concernés : Toyota, Honda, BMW, Mercedes, Volkswagen, Hyundai, Audi, Ford, GM
  • Outil forensique principal : Berla iVe (référence judiciaire) + Cellebrite UFED 4PC avec module véhicule
  • Reset usine souvent insuffisant — données dans des partitions annexes de l'IVI
  • Cas pratique : un véhicule revendu peut contenir tous les contacts + SMS + historique GPS du précédent propriétaire
  • Forensiquement : interroger systématiquement l'IVI lors de saisies — pas juste le smartphone
🧠 Testez-vous
Vous enquêtez sur un accident mortel. Le conducteur affirme rouler à 50 km/h. Comment vérifier ?EDR · Niveau : facile
Extraire l'EDR du véhicule avec Bosch CDR. Procédure : (1) Identifier le port OBD-II du véhicule (sous le tableau de bord, conducteur), (2) Faire intervenir un expert certifié Bosch CDR (recevabilité judiciaire), (3) Connecter le boîtier Bosch CDR via OBD-II, (4) Lancer l'extraction → fichier CDX, (5) Logiciel CDR génère un rapport PDF/CSV avec les données 5 secondes avant impact : vitesse à t-5s, t-4s, t-3s, t-2s, t-1s, t0. (6) Comparer avec la déclaration du conducteur. Bonus : l'EDR enregistre aussi la pression frein et accélérateur — utile pour distinguer une perte de contrôle d'une accélération volontaire. Si le véhicule est détruit, l'extraction se fait directement depuis l'airbag control module récupéré sur l'épave. Norme légale : EDR obligatoire UE — Règlement 2019/2144 · nouveaux types depuis le 6 juillet 2022 · tous les véhicules neufs vendus dans l'UE depuis le 7 juillet 2024.
Une Tesla est impliquée dans un délit de fuite. Le suspect a effacé les vidéos de la clé USB. Tout est-il perdu ?Tesla · Niveau : moyen
Probablement pas. Plusieurs angles : (1) Récupération sur la clé USB — la clé est en FAT32, les vidéos « supprimées » ne sont pas écrasées tant qu'aucune nouvelle écriture n'a eu lieu. PhotoRec ou Recuva permettent souvent de récupérer les MP4 supprimés. (2) Logs de conduite Tesla stockés dans la MCU (Media Control Unit, ordinateur central Tesla) — non effaçables par l'utilisateur — contiennent : GPS précis 1m, vitesse, mode Autopilot, événements (freinage urgent, etc.). Saisie de la voiture + extraction par expert ou par Tesla Service. (3) Cloud Tesla — les vidéos Sentry Mode sont parfois sauvegardées dans le cloud Tesla (selon configuration). Demande légale à Tesla via MLAT (Tesla coopère avec autorités, plus que Telegram). (4) Témoins automatiques — autres Tesla à proximité peuvent avoir filmé via Sentry/Dashcam. (5) Caméras de circulation municipales. (6) Sentry Mode events log — même si les vidéos sont effacées, le log des déclenchements Sentry peut subsister. Procédure : ne pas allumer le véhicule (préserver l'état), demande Tesla immédiate.
Vous saisissez un BMW d'occasion (vente récente). Quelles données du précédent propriétaire pouvez-vous trouver ?Infotainment · Niveau : moyen
Souvent énormément de choses. Un reset usine standard chez le concessionnaire ne nettoie pas tout — les données des modules infotainment et des partitions annexes persistent. Données potentielles : (1) Tous les contacts du smartphone Bluetooth précédemment appairé (synchronisés en local), (2) Historique d'appels entrants/sortants, (3) SMS importés depuis le smartphone (BMW iDrive importe certains SMS), (4) Adresses GPS : domicile, travail, favoris, dernières destinations, itinéraires complets, (5) Calendrier synchronisé via Bluetooth/CarPlay/Android Auto, (6) Audio joué : titres récents Spotify/Apple Music, stations radio favorites, (7) Profils conducteur : positions sièges, climatisation préférée, paramètres personnalisés, (8) Notifications email/messagerie récentes. Outils : Berla iVe (référence) ou Cellebrite UFED avec module véhicule. Implication : interroger systématiquement l'IVI lors de saisies de véhicules d'occasion. La revente sans reset complet est un problème massif de vie privée documenté par Privacy International (2018+).
