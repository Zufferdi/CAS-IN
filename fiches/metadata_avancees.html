📷 EXIF = Exchangeable Image File Format
Standard 1998 pour encoder métadonnées dans images JPEG/RAW. Contient : timestamp, appareil photo, settings (ISO, F-stop, focal length), géolocalisation GPS.
Champs EXIF Critiques pour Forensique
DateTime Original
2024:03:15 14:32:07
⏰ Quand photo prise (heure locale appareil)⚠️ = modifiable
Make & Model
Canon EOS 5D Mark IV
📱 Quel appareil ? (signature)
GPS Coordinates
46.9479°N, 7.4474°E
🗺️ Où photo prise = CRITIQUE
Software
Photoshop 2024, Adobe Lightroom
🛠️ Outil de traitement (tampering ?)
ExposureTime & F-Number
1/500s, f/2.8

Orientation

🔄 Orientation physique (smartphone)
⚠️ EXIF = MODIFIABLE
Tout applicatif (Photoshop, ExifTool, téléphones) peut modifier EXIF.
Forensique : Comparer EXIF vs création fichier (filesystem timestamps) vs contenu image.
Incohérence = tampering suspect
📝 IPTC vs XMP : Métadonnées Éditeur
IPTC (InterPress Telegraph Council) + XMP (Extensible Metadata Platform) = données créées volontairement par photographe/éditeur.
Comparaison EXIF vs IPTC vs XMP
Métadonnée Origine Contenu Typique Forensique
EXIF Appareil photo DateTime, GPS, apparel, settings Timestamp origine ⚠️ modifiable
IPTC Photographe/Éditeur Caption, keywords, copyright, author Signature auteur (parfois faux)
XMP Adobe apps (Lightroom, PS) Rating, edit history, creator tool Quel logiciel ? Éditions successives
💡 Cas d'usage DFIR
Exemple : Photo prétendument prise "à Paris le 15 mars".
• EXIF DateTime: 2024:03:15
• EXIF GPS: 48.8566°N, 2.3522°E (Paris) ✓
• EXIF Software: Photoshop CC 2024 (= édition ultérieure)
• XMP CreatorTool: Lightroom (autre outil = plusieurs éditeurs)
→ Indicateur : Photo a été fortement éditée APRÈS prise initiale
🗺️ GPS : Coordinate Forensics
Coordonnées GPS dans EXIF = localisation exacte lieu photo. Critique pour : établir mouvements suspects, associer suspect à scène, géolocalisation temporelle.
Format GPS EXIF
Exemple Raw EXIF GPS:
GPSLatitude: 46, 56, 52.44
GPSLatitudeRef: N
GPSLongitude: 7, 26, 50.64
GPSLongitudeRef: E
GPSAltitude: 540 meters
GPSDateStamp: 2024:03:15
GPSTimeStamp: 14:32:07
→ Berne, Suisse, 540m d'altitude, 15 mars 14:32

🔍 Analyse GPS Forensique
1. Cohérence temporelle : GPS timestamp vs EXIF DateTime (écart = suspect)
2. Mouvement trajectoire : Plusieurs photos → tracer timeline géographique
3. Altitude anomale : GPS altitude aide identifier faux (montagne vs plaine)
4. Zones interdites : Présence GPS en zone restrictive = probe
5. Appairage avec téléphone : Numéro de série caméra vs GPS phone = cross-validation
✅ Authenticité Image : ELA & Analyse Compression
ELA (Error Level Analysis) = technique détecte zones modifiées en utilisant artefacts JPEG compression. Zones éditées = pattern compression différent.

Workflow : Vérifier Authenticité
  1. Extraction EXIF complète → ExifTool dump
  2. Comparaison : EXIF DateTime vs file mtime vs photo content
  3. ELA analysis → détecter zones modifiées
  4. Clone detection → copier-coller régions
  5. Metadata consistency → cohérence Make/Model vs Software
  6. GPS validation → coordonnées plausibles + altitude logique
  7. Conclusion forensique : Authentique vs Tampering probable

CLI Quick Commands
# Dump ALL metadata
$ exiftool -a -G1 photo.jpg

# Extract GPS only
$ exiftool -GPS* photo.jpg

# Compare two photos
$ exiftool photo1.jpg > meta1.txt
$ exiftool photo2.jpg > meta2.txt
$ diff meta1.txt meta2.txt

# Batch extract all JPGs
$ exiftool -csv *.jpg > metadata.csv

# Remove EXIF (anonymize)
$ exiftool -all= photo.jpg (strip all metadata)
🧪 Workflow Complet
1. exiftool -a -G1 photo.jpg | tee metadata.txt
2. Forensically.eu → télécharger photo pour ELA
3. JPEGsnoop photo.jpg → vérifier quantization
4. Créer rapport → "EXIF DateTime 2024-03-15, GPS Berne, Software Photoshop CC (indication édition)"
