Base de registre — Ruches (Hives)
HKLM\SAM
Comptes locaux, hash des mots de passe (NTLM), groupes. Accès restreint — analyse hors-ligne nécessaire.
HKLM\SYSTEM
Configuration système, services, USBSTOR (périphériques USB connectés), MountedDevices, timezone.
HKLM\SOFTWARE
Applications installées, Run Keys, Amcache, ShimCache (AppCompatCache). Programmes au démarrage.
HKCU\NTUSER.DAT
Profil utilisateur : UserAssist (ROT13), MRU, ShellBags (HKCU), Run Keys utilisateur, wallpaper.
HKCU\USRCLASS.DAT
ShellBags pour lecteurs réseaux et supports amovibles. BagMRU + Bags pour les dossiers explorés.

Chemin physique : C:\Windows\System32\config\ (SYSTEM, SAM, SOFTWARE) · C:\Users\<user>\NTUSER.DAT

Prefetch — Preuve d'exécution
Qu'est-ce que c'est ?

Windows crée un fichier .pf dans C:\Windows\Prefetch\ lors du premier lancement d'un programme. Optimisation de démarrage : mémorise les 10 premières secondes d'accès disque.

Preuve d'exécution même si le programme est supprimé — le .pf survit.

Contenu forensique

✓ Nom de l'exécutable + chemin
✓ Nombre d'exécutions (compteur)
✓ Jusqu'à 8 dates d'exécution (W8+)
✓ Liste des DLL et fichiers accédés
✓ Hash de vérification intégré

Outil : PECmd.exe (Eric Zimmerman) → --csv

Limites à mentionner dans le rapport : Prefetch désactivé par défaut sur les serveurs Windows. Sur SSD, peut être désactivé (paramètre EnablePrefetcher=0). Sur Windows 10+, format compressé XPRESS Huffman — seul PECmd peut le lire correctement.
ShellBags — Navigation humaine prouvée
Les ShellBags sont créés par l'Explorateur Windows lors de la navigation. Un virus ou un logiciel de sync n'utilise pas l'interface graphique → présence de ShellBags = action humaine.
Clé registre
Rôle
Contenu
BagMRU
La carte — arborescence
Nœuds numérotés (0, 1, 2…) représentant les dossiers visités. Reconstruit l'arborescence complète avec timestamps.
Bags
Le contenu — préférences
Préférences d'affichage (tri, taille de fenêtre, position). Moins forensiquement pertinent que BagMRU.
NTUSER.DAT (dossiers locaux)

HKCU\Software\Microsoft\Windows\Shell\BagMRU
HKCU\Software\Microsoft\Windows\Shell\Bags

Dossiers locaux, bureau, documents. Persiste même après suppression du dossier cible.

USRCLASS.DAT (réseau/amovibles)

HKCU\Software\Classes\Local Settings\Software\Microsoft\Windows\Shell

Lecteurs réseau (UNC \\serveur\partage), supports amovibles. Plus riche en informations sur les déplacements de données.

Outil : ShellBags Explorer (Eric Zimmerman) — parse USRCLASS.DAT + NTUSER.DAT et reconstruit l'arborescence.
Anti-forensique : CCleaner/BleachBit peuvent supprimer les ShellBags. Absence totale sur un système ancien = suspect.

Thumbcache — Miniatures persistantes
Localisation

C:\Users\<user>\AppData\Local\Microsoft\Windows\Explorer\

Fichiers : thumbcache_1280.db, thumbcache_96.db, thumbcache_48.db, thumbcache_32.db

Valeur forensique critique

Les miniatures persistent après suppression de l'image originale. Une image illicite supprimée peut continuer d'exister dans le thumbcache en résolution identifiable.

_1280 = images vues dans l'explorateur · _96 = images issues de la navigation web

UserAssist (ROT13) & Corbeille
UserAssist — Obfuscation ROT13

Clé : HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\UserAssist

Enregistre les programmes exécutés depuis le menu Démarrer ou le bureau. Les chemins sont encodés en ROT13.

Décodage : CyberChef → recette ROT13 · ou RegRipper automatiquement.

Contient : nombre d'exécutions + timestamp de dernière exécution.

Corbeille — $R et $I

Chemin : C:\$Recycle.Bin\<SID_utilisateur>\

Pour chaque fichier supprimé :
$RXXXXXX — données du fichier (contenu récupérable)
$IXXXXXX — métadonnées : nom original, chemin complet, taille, date/heure exacte de suppression

Le $I subsiste après vidage de la corbeille — prouve l'acte conscient de suppression. Identifier l'utilisateur via le SID du sous-répertoire.

⚡ Amcache & ShimCache
HKLM\SYSTEM\...\AppCompatCache + Amcache.hve
AmcacheParser + AppCompatCacheParser
Compatibilité applicative. Enregistrent les exécutables avec leur hash SHA-1 (Amcache) — permet d'identifier un programme même supprimé. ShimCache : chemin + timestamp des exécutables.
