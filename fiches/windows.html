Windows — Registre et artefacts
Ruches système (C:\Windows\System32\Config\)
  • SYSTEM : config matérielle, services, réseau, USB connectés
  • SOFTWARE : logiciels installés, clés licence, programmes récents
  • SAM : comptes locaux, hashes mots de passe, dates connexion
  • SECURITY : politiques locales, droits, audit
  • DEFAULT : profil par défaut nouveaux utilisateurs
Ruches utilisateur
  • NTUSER.DAT : C:\Users\<nom>\ — préférences utilisateur
  • USRCLASS.DAT : C:\Users\<nom>\AppData\Local\Microsoft\Windows\ — ShellBags !
  • HKCU = référence NTUSER.DAT chargé
  • Modifiable SANS droits administrateur → malwares sans élévation

Windows — Artefacts d'exécution
Prefetch (.pf)
  • Chemin : C:\Windows\Prefetch\
  • Prouve l'exécution d'un programme
  • Contient : timestamps (jusqu'à 8), compteur lancements, DLL chargées
  • Désactivé sur Windows Server
  • Outil : PECmd (Zimmerman)
Amcache.hve
  • Chemin : C:\Windows\AppCompat\Programs\
  • Hash SHA-1 des exécutables
  • Prouve la présence physique du binaire sur le disque
  • Persiste après désinstallation
  • Outil : AmcacheParser (Zimmerman)
LNK & Jump Lists
  • LNK : C:\...\AppData\Roaming\Microsoft\Windows\Recent\
  • Contient : chemin cible, Volume Serial Number, timestamps cible
  • Prouve l'accès à un fichier même si supprimé
  • Jump Lists : AutomaticDestinations & CustomDestinations
  • Outil : LECmd (Zimmerman)
ShellBags (USRCLASS.DAT)
  • Mémorise les dossiers explorés via l'interface graphique
  • Survive à la suppression des dossiers explorés
  • Prouve la navigation humaine (≠ malware)
  • Outil : ShellBagsExplorer (Zimmerman)
$I30 Résiduel (NTFS)
  • $INDEX_ALLOCATION d'un répertoire = B-Tree
  • Après suppressions, des nœuds orphelins subsistent
  • Révèle les fichiers supprimés même si MFT réalloué
  • Outil : X-Ways, Autopsy, indxparser
VSS (Volume Shadow Copies)
  • Snapshots copy-on-write automatiques
  • Accès : \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1
  • Ransomwares suppriment les VSS en premier
  • Commande : vssadmin list shadows

Event IDs essentiels

4625Échec d'authentification → brute force ?
4688Création d'un processus (audit requis)
4698Tâche planifiée créée → persistance ?
7045Nouveau service installé → rootkit ?
4720Création d'un compte utilisateur
4663Accès à un objet (audit fichiers)
1102Log Security effacé (Security.evtx)
Corrélation multi-sources

Scénario type : 4624 (connexion réseau) + ShellBag créé même instant + Prefetch horodaté = tableau cohérent difficile à contester.

Effacement paradoxal : Event ID 1102 (log effacé) est lui-même journalisé si l'audit est actif.

Logs alternatifs : Chercher IIS, Apache, antivirus — souvent oubliés par l'attaquant.

Outil : EvtxECmd (Zimmerman) → export CSV pour analyse temporelle

💡 Suite Eric Zimmerman (gratuite) : PECmd · MFTECmd · LECmd · ShellBagsExplorer · EvtxECmd · AmcacheParser · AppCompatCacheParser. Standard de facto DFIR Windows. Citer l'outil dans le rapport renforce la crédibilité judiciaire.
