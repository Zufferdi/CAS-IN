Chiffrement en couches (oignon)

Le client chiffre le message avec 3 clés successives (Exit → Middle → Guard). Chaque relais ne décrypte qu'une couche et ne connaît que ses voisins immédiats dans la chaîne.


Circuit Tor = 3 relais minimum. Renouvelé toutes les 10 minutes.

Limites de l'anonymat Tor
  • Le nœud de garde voit l'IP réelle du client
  • Le nœud de sortie voit le trafic non chiffré (HTTP, DNS)
  • Corrélation temporelle : observer entrée ET sortie = désanonymisation
  • JavaScript activé = fuites d'IP potentielles (exploits navigateur)
  • Habitudes comportementales (timing, contenu) = fingerprinting
Artefacts Tor Browser — Investigation forensique
Localisation Tor Browser

Tor Browser est portable — pas d'installation standard. Peut être sur n'importe quel chemin, clé USB ou dossier.


Browser\TorBrowser\Data\Tor\Config + logs de circuit
Browser\TorBrowser\Data\Browser\profile.default\Profil Firefox (SQLite)
Browser\TorBrowser\Tor\tor.exeL'exécutable Tor
Artefacts persistants malgré le mode privé
  • Prefetch : TOR.EXE-XXXXXX.pf → preuve d'exécution
  • AmCache / ShimCache : tor.exe référencé même après suppression
  • LNK files : raccourci vers tor.exe si lancé depuis l'interface
  • Registre UserAssist : tor.exe dans les programmes exécutés (ROT13)
  • $UsnJrnl : création/suppression des fichiers Tor
  • RAM : circuits actifs, pages visitées, identifiants de session
Fichiers SQLite du profil Tor Browser

Tor Browser est basé sur Firefox → mêmes fichiers SQLite :

  • places.sqlite : historique (souvent vide en mode privé)
  • cookies.sqlite : effacé à la fermeture
  • sessionstore.jsonlz4 : session courante (très utile en live)
  • formhistory.sqlite : formulaires remplis
Tor — Fichiers de configuration

torrc : configuration Tor (bridges, proxy, ports). Peut révéler des bridges personnalisés ou des configurations spéciales.


state : état du daemon Tor. Contient les statistiques de connexion et les nœuds de garde utilisés.


cached-microdescs : liste des relais Tor connus. La présence de ce fichier confirme l'utilisation de Tor.

Services .onion (Hidden Services)
Qu'est-ce qu'un service .onion ?

Un service onion est un serveur accessible uniquement via le réseau Tor, sans passer par un nœud de sortie. L'adresse .onion est dérivée cryptographiquement de la clé publique du serveur (Ed25519 en v3).


Format v3 (actuel) : xyz[56 caractères]d.onion
Format v2 (obsolète, 2021) : 16 caractères

Investigation des services .onion
  • Les adresses .onion ne peuvent pas être résolues en DNS classique
  • Recherche via moteurs spécialisés : Ahmia.fi (indexe les .onion)
  • Hunchly : capture automatique des pages visitées
  • L'hébergeur du serveur .onion n'est pas connu des autorités sans infiltration ou exploit
  • Les saisies de serveurs onion nécessitent souvent une coopération internationale (FBI, Europol)
Attribution — Techniques légales
Méthodes d'attribution documentées
  • Nœud de garde : si l'État contrôle le nœud de garde d'un suspect, il voit l'IP réelle
  • Corrélation temporelle : observer le pattern de connexion côté client + serveur
  • HUMINT / infiltration : achats sur les marketplaces, communication avec le suspect
  • OPSEC failure : erreur humaine (même email, même alias qu'en clearnet)
  • Exploit navigateur : faille Tor Browser → reveal IP réelle (utilisé par le FBI)

Identifié via un post public datant d'avant SR utilisant son vrai email pour recruter. Arrestation physique dans une bibliothèque SF quand son ordinateur était déverrouillé.

Cadre légal suisse — Tor & surveillance
⚖️ LSCPT — Loi sur la surveillance des communications

La LSCPT (RS 780.1) encadre la surveillance des communications en Suisse. Pour surveiller un suspect utilisant Tor :

  • Surveillance de l'abonné (IP + métadonnées) : ordonnance du TMC
  • Surveillance du contenu : conditions plus strictes (soupçon grave)
  • Tor rend la surveillance du contenu inutile (chiffrement) → focus sur les métadonnées de connexion chez l'ISP
  • Timing attacks sur les logs ISP possibles si Tor est utilisé régulièrement
Logs ISP et Tor

L'ISP voit que le client se connecte à un nœud Tor (IP connue publiquement via le directory Tor), mais pas la destination finale.


Les ISP suisses conservent les métadonnées de connexion 6 mois (LSCPT art. 26). Ces logs peuvent confirmer l'utilisation de Tor à une heure précise.


Bridges Tor : relais non listés publiquement → l'ISP ne voit qu'une connexion vers une IP inconnue.

🇨🇭 Coopération internationale : Les takedowns de marketplaces onion (Hydra, AlphaBay, DarkMarket) ont tous impliqué une coopération entre le FBI, Europol, la BKA (Allemagne) et d'autres services. La Suisse participe via le MLAT et les accords bilatéraux.
