🗺️ Compétence Territoriale en Cybercriminalité
La règle : Crime commis dans le canton X → enquête dirigée par canton X. Mais en cyber = c'est compliqué (attaquant peut être ailleurs).
Déterminant de Compétence
Principe : Où le dommage/résultat s'est-il produit ?

Exemples :
  • Hacking serveur Zurich depuis attaquant en Allemagne → Compétence Zurich
  • Email phishing vers employés multi-cantons → Compétence du canton où demandeur d'emploi travaille (au minimum)
  • Ransomware touchant hôpital Genève → Compétence Genève (+ escalade Fedpol)
  • Données volées cloud USA détenu par entreprise suisse → Compétence canton siège entreprise
Cas Limites : Multi-Cantons
Conflit de compétence
Si crime touche cantons différents → Coordination via Fedpol.

Enquête leads par canton "le plus lésé" + coordination fédérale
Chaque canton maintient enquête = redondance prudente (CH décentralisé)

⏰ Prescription (Délais Poursuite)
Art. 97 CP : 2-10 ans selon gravité crime. Exemples :
• Vol données simple : ~3 ans
• Fraude bancaire : ~5 ans
• Ransomware infrastructure critique : ~10 ans
• CSEM : Pas de prescription jusqu'à majorité victime + 10 ans
📋 Timeline : Du Dépôt de Plainte à Jugement
Processus procédural schématisé. Timing = variable selon canton/crime/complexité. Régi par CPP (Code Procédure Pénale, varie par canton). Prescription : 2-10 ans selon crime (Art. 97 CP).
⚠️ CPP Cantonal
Chaque canton a son CPP propre. Zurich ≠ Genève ≠ Tessin légalement.
Impact : délais, procédures, appels peuvent varier significativement.
À faire : Consulter procureur/avocat pour canton spécifique.

Checklist : Avant Appel Autorités
Préparez :
  • ☐ Qui : Nom victime / accusé
  • ☐ Quand : Date/heure incident
  • ☐ Quoi : Type crime (vol, ransomware, phishing, etc.)
  • ☐ Où : Canton où incident a eu lieu
  • ☐ Preuves initiales : Screenshots, logs, emails suspects
  • ☐ Dommage estimé : Montant, données exposées
  • ☐ Chaîne custody : Qui a manipulé preuves
