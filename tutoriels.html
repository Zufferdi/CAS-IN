🎯 Tutoriels DFIR — Apprendre en faisant

5 outils open source, pas à pas. Chaque tutoriel te fait exécuter les commandes, vérifier ce que tu obtiens, et valider ta progression. Quiz final + trophée à la clé.
⏱ 30–60 min par tutoriel 💻 Cross-platform 🏆 Trophées dédiés 📴 Hors ligne
ℹ️ Comment lire un tutoriel CAS-IN
Chaque tutoriel est divisé en sections numérotées. Pour chaque section : lis, exécute, compare ta sortie à celle attendue (encart vert), puis clique sur « Marquer comme réussie ». Le sommaire à gauche suit ta progression. À la fin, un mini-quiz de 5 questions débloque le trophée.

Autopsy & Sleuth Kit
Plateforme forensique open source de référence. Analyse multi-FS, modules d'ingestion, timeline, recherche d'artefacts. Le couteau suisse du DFIR analyste.
⏱ ~45 min 🪟 Windows 🐧 Linux 🍏 macOS 📁 Image disque
⚡
IPED
Indexador e Processador de Evidências Digitais (Police fédérale brésilienne). 400 Go/h, cas portables, parsers WhatsApp/Telegram/etc.
⏱ ~35 min 🪟 Windows 🐧 Linux 📁 Image disque
📱
MVT — Mobile Verification Toolkit
Outil Amnesty International pour détecter Pegasus, Predator et autres spywares sur iOS et Android via IoC publics (STIX2).
⏱ ~40 min 🐧 Linux 🍏 macOS 📱 iOS / Android
⏳
Plaso / log2timeline
Super-timelines unifiées sur Windows/Linux/macOS. 200+ parsers d'artefacts, export CSV/Elastic. Le standard de la timeline forensique.
⏱ ~50 min 🐧 Linux 🪟 Windows 🍏 macOS ⏰ Timeline
🧠
Volatility 3
Framework de référence pour l'analyse de la mémoire vive. 150+ plugins, Windows/Linux/macOS. Trouver les rootkits, processus cachés, secrets en RAM.
⏱ ~60 min 🐧 Linux 🪟 Windows 🍏 macOS 🧠 Mémoire
🦈
Wireshark
Capture et analyse de trafic réseau. 3000+ dissecteurs, filtres BPF + display, extraction de fichiers transmis, décryptage TLS, automatisation tshark.
⏱ ~50 min 🪟 Windows 🐧 Linux 🍏 macOS 📡 Network
🥋
KAPE — Triage Windows
Kroll Artifact Parser and Extractor. Triage forensique Windows en 5 minutes. Targets + Modules + EZ Tools. Standard CERT / MSSP.
⏱ ~45 min 🪟 Windows uniquement ⚡ Triage rapide 🧰 EZ Tools
🦖
Velociraptor
Forensique endpoint à distance et chasse aux menaces à l'échelle. VQL, hunts, Sigma/YARA, intégration KAPE, triage offline standalone.
⏱ ~70 min 🐧 Serveur Linux 🪟 Agents Windows/Linux/macOS 🛠️ VQL
💾
FTK Imager — Acquisition
Acquisition write-blocked d'images disque (E01), capture mémoire RAM, vérification de hash, montage lecture seule. La base de tout cas DFIR.
⏱ ~40 min 🪟 Windows uniquement 💾 E01 + RAM 🔒 Write-blocker
🧰
Eric Zimmerman Tools
15 outils Windows standalone : PECmd, RECmd, MFTECmd, EvtxECmd, JLECmd, SBECmd, etc. Le socle DFIR Windows, en standalone hors KAPE.
⏱ ~60 min 🪟 Windows uniquement 🧰 15 outils ⚡ CSV + Timeline Explorer
📲
Cellebrite Reader — UFDR
Lecture des rapports d'extraction mobile UFDR sans licence Cellebrite. Pour magistrats, avocats, analystes tiers. Conversations, médias, géolocalisation.
⏱ ~45 min 🪟 Windows uniquement 📱 iOS / Android ⚖️ Procédure pénale
🔓
Hashcat — Cassage de hash
Le casseur de hash le plus rapide au monde. 300+ algorithmes, dictionnaires + règles, masques, attaque hybride. NTLM, BitLocker, KeePass, Office, ZIP.
⏱ ~65 min 🪟 Windows 🐧 Linux 🎮 GPU recommandé ⚖️ Cadre légal strict
⌨️
Bases CLI — Terminal Windows & Linux
Socle DFIR universel. Naviguer, manipuler fichiers, rediriger et piper, rechercher, calculer hashs, lister processus et connexions, scripts de triage en bash + PowerShell.
⏱ ~50 min 🪟 cmd + PowerShell 🐧 bash + zsh ⌨️ Indispensable
🔧
CLI intermédiaire — Pipelines & scripts
Suite directe des Bases CLI. cut, sort, uniq, awk, sed, regex étendues, scripts bash robustes (set -euo pipefail), équivalents PowerShell.
⏱ ~60 min 🎯 Intermédiaire 🐧 bash / awk / sed 🪟 PowerShell
🚀
CLI expert — Automation & orchestration
jq, GNU parallel, SSH avancé (ProxyJump, ControlMaster), tcpdump/tshark CLI, strace, tmux, systemd, PowerShell remoting, scripting Python, multi-host.
⏱ ~80 min 🎯 Expert 🐧 jq / parallel / ssh 🐍 Python DFIR

Sherlock — OSINT pseudonymes
Recherche d'un pseudo sur 400+ sites en 30s. Pip / Docker, options, faux positifs, Tor / proxy, croisement avec Maigret et Holehe.
⏱ ~40 min 🎯 Intermédiaire 🔍 400+ sites ⚖️ Cadre légal OSINT

Maigret — OSINT approfondi (3000+ sites)
Successeur avancé de Sherlock. 3000+ sites, extraction métadonnées (photo, bio, dates), rapports HTML/PDF, recherche multi-IoC (email, téléphone, nom), récursive.
⏱ ~55 min 🎯 Expert 🕵️ 3000+ sites + métadonnées ⚖️ nLPD / RGPD
🔑
John the Ripper — Cassage multi-format
Complément CPU à Hashcat (cf. v127). 400+ formats, mode single crack unique, scripts *2john incontournables (KeePass, Office, ZIP, PDF, BitLocker).
⏱ ~60 min 🎯 Expert 🔧 CPU optimisé ⚖️ Cadre légal strict
