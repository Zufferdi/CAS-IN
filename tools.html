🗄 Décodeur Run List NTFS

Décode une run list NTFS nibble par nibble. Format : séquence d'octets hex séparés par des espaces. Chaque run : octet header + longueur + offset LCN. Fin de liste : 00.

Exemple basique Exemple cours Multi-runs

📐 Rappel — Structure Run List

Octet header (nibbles)
Nibble haut = nb octets offset · Nibble bas = nb octets longueur
Exemple : header 0x21
0x2 → 2 octets d'offset · 0x1 → 1 octet de longueur
Offset LCN
Little-Endian · Relatif au run précédent (sauf 1er) · Signé
Fin de liste
Octet 0x00

🔐 Calculateur de Hash

Calcule SHA-256, SHA-1 et MD5 d'un texte ou de bytes hex. Utile pour vérifier l'intégrité, comprendre l'effet avalanche (changer 1 caractère change ~50% des bits du hash), ou générer des valeurs de référence.

Exemple texte + espace (avalanche) Hash "FILE" (NTFS sig)
⚠ MD5 et SHA-1 sont cryptographiquement cassés — ne pas utiliser pour la sécurité. En forensique, ils restent valides pour la chaîne de custody historique et la correspondance NSRL.

📄 Décodeur entrée SFN FAT (32 octets)

Colle les 32 octets d'une entrée de répertoire FAT (Short File Name) pour décoder automatiquement nom, extension, attributs, dates, cluster et taille.

Structure SFN (32 octets) : 0x00–0x07 Nom (8 o, maj) · 0x08–0x0A Extension (3 o) · 0x0B Attributs · 0x0C–0x0D Réservé · 0x0E–0x0F Heure création · 0x10–0x11 Date création · 0x12–0x13 Date accès · 0x14–0x15 Cluster hi (FAT32) · 0x16–0x17 Heure modif · 0x18–0x19 Date modif · 0x1A–0x1B Cluster lo · 0x1C–0x1F Taille (LE32)
