⌨️ Bases CLI — Terminal Windows & Linux

À la fin de ce tutoriel, tu sauras naviguer dans l'arborescence (cd, ls/dir), manipuler les fichiers (cp, mv, rm, type), rediriger et piper (>, >>, |), rechercher avec grep / Select-String et find / Get-ChildItem, calculer des hashs SHA-256, lister processus et connexions réseau, et écrire un mini-script de triage en bash et PowerShell.
🎯 Niveau débutant ⏱ ~50 min 🪟 cmd + PowerShell 🐧 bash + zsh ⌨️ Socle DFIR universel
ℹ️ Pourquoi la CLI est non négociable en DFIR
La ligne de commande est l'outil universel du DFIR. La quasi-totalité des outils forensiques (Plaso, Volatility, Hashcat, EZ Tools, KAPE, tshark) s'utilise en CLI. Maîtriser le terminal, c'est passer du niveau utilisateur au niveau analyste. Sans CLI, tu plafonnes à 20 % de la puissance de chaque outil forensique.

01 Pourquoi apprendre la CLI en DFIR

La CLI est l'outil universel pour trois raisons :

  1. Automatisation : un script bash ou PowerShell traite 1000 fichiers en une commande, là où l'interface graphique demande 1000 clics.
  2. Distance : sur un serveur distant via SSH/RDP CLI, tu n'as pas le choix — la CLI est ton seul accès.
  3. Reproductibilité : une commande peut être copiée dans un rapport, rejouée, partagée. Un clic est invisible.

Tous les outils DFIR sérieux ont une interface CLI (Plaso, Volatility, Hashcat, tshark, KAPE, EZ Tools, MVT, ...). Sans CLI, tu es coupé de 80 % de la puissance de chaque outil.

02 Les terminaux Windows : cmd vs PowerShell

Windows offre trois terminaux principaux :

TerminalAnnéeCaractéristiques
cmd.exe1987 (NT)Historique, syntaxe DOS, limité, omniprésent
PowerShell2006 (5.1) / 2018 (Core 7+)Moderne, basé objets, .NET, scriptable
Windows Terminal2019Wrapper moderne pour cmd / PowerShell / WSL — UI améliorée

Recommandation :

  • cmd : seulement pour les .bat legacy ou commandes très courtes (ipconfig, cls).
  • PowerShell : ton terminal Windows par défaut. PowerShell 7+ (pwsh) si disponible, sinon PowerShell 5.1 (powershell).
  • Windows Terminal : application hôte recommandée (onglets, profils, raccourcis).

03 Les terminaux Linux : bash, zsh, fish

Linux offre une multitude de shells :

ShellCaractéristiques
bashStandard POSIX, présent sur 100 % des Linux. Référence pédagogique.
zshBash compatible + autocomplétion enrichie + thèmes (Oh My Zsh)
fishConvivial, autocomplétion intelligente, syntaxe simplifiée (incompatible POSIX)
dashMinimal, rapide, utilisé pour les scripts système

Recommandation DFIR :

  • Apprendre bash : c'est sur 100 % des serveurs Linux que tu rencontreras.
  • Optionnel : utiliser zsh + Oh My Zsh pour ton confort quotidien.
  • Tes scripts en .sh doivent être POSIX-compatible (bash).

04 Ouvrir un terminal — Windows

Méthodes

  • Win + R → cmd ou powershell ou wt (Windows Terminal)
  • Win + X → choisir « Terminal » ou « PowerShell »
  • Menu Démarrer → taper « PowerShell » ou « Terminal »
  • Dans l'Explorateur : Shift + clic droit dans un dossier → « Ouvrir une fenêtre PowerShell ici »

Clic droit → Exécuter en tant qu'administrateur ou Ctrl + Shift + Enter pour ouvrir directement en admin.

09 Rediriger et piper (>, >>, |)

C'est le secret de la puissance CLI.

Redirection vers un fichier

SymboleAction
>Écrit la sortie dans un fichier (écrase)
>>Ajoute la sortie à la fin d'un fichier
2>Redirige les erreurs vers un fichier
2>&1Fusionne erreurs et sortie standard
bash
# Linux : sauvegarder la liste des fichiers
ls -l /etc > listing.txt

# Linux : ajouter à la fin
ls -l /var >> listing.txt

# Linux : capturer les erreurs en plus
ls -l /etc /inexistant > listing.txt 2>&1
powershell
# PowerShell : équivalent
ls C:\Windows > listing.txt
ls C:\Windows\System32 >> listing.txt
ls C:\Windows, C:\InvalidPath > listing.txt 2>&1

Pipe (|)

Le pipe passe la sortie d'une commande comme entrée d'une autre. C'est le LEGO du DFIR.

bash
# Linux : compter les fichiers .pdf
ls *.pdf | wc -l

# Linux : trier le contenu et garder les uniques
cat fichier.txt | sort | uniq

# Linux : top 10 IPs d'un access.log
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -n 10
powershell
# PowerShell : compter les fichiers .pdf
ls *.pdf | Measure-Object | Select Count

# PowerShell : trier et garder les uniques
cat fichier.txt | Sort-Object | Get-Unique

# PowerShell : top 10 process par mémoire
Get-Process | Sort-Object WS -Descending | Select -First 10
💡 Astuce
« extraire | filtrer | trier | compter ». 90 % des analyses CLI suivent ce pattern.

10 Rechercher dans des fichiers (grep, findstr, Select-String)

grep (Linux)

bash
# Recherche simple
grep "192.168.1.5" /var/log/auth.log

# Sensible/insensible casse
grep "admin" file.txt           # case sensitive
grep -i "admin" file.txt        # case insensitive

# Recherche récursive dans un dossier
grep -r "password" /etc/

# Avec numéro de ligne
grep -n "error" /var/log/syslog

# Inverser (lignes qui NE contiennent PAS le motif)
grep -v "DEBUG" application.log

# Plusieurs motifs (regex)
grep -E "ERROR|WARN|CRITICAL" application.log

# Compter les occurrences
grep -c "Failed password" /var/log/auth.log

# Afficher 3 lignes avant et après (contexte)
grep -B 3 -A 3 "exception" app.log

# Recherche dans des fichiers binaires
grep -a "magic_string" suspicious.exe

findstr (Windows cmd)

bat
findstr "motif" fichier.txt
findstr /i "admin" fichier.txt       :: case insensitive
findstr /s "password" *.txt          :: récursif
findstr /n "error" syslog.log        :: avec numéros de ligne
findstr /v "DEBUG" app.log           :: inversé
findstr /r "ERROR\|WARN" app.log     :: regex
findstr /c:"motif avec espaces" f    :: motif littéral avec espaces

Select-String (PowerShell)

powershell
# Équivalent grep
Select-String "motif" fichier.txt
Select-String -Pattern "admin" -Path *.txt -CaseSensitive:$false
Select-String "password" -Path C:\Logs -Recurse
Select-String "error" fichier.txt -Context 3,3   # 3 lignes avant et après
Select-String "ERROR|WARN" app.log               # regex par défaut

# Pipe vers count
(Select-String "Failed" auth.log).Count

Cas DFIR : recherche d'IoC dans des logs

bash
# Linux : chercher une IP dans tous les logs
grep -rn "185.142.236.123" /var/log/ 2>/dev/null

# Linux : chercher des hashs IoC dans un dossier de fichiers
sha256sum * | grep -f hashes_ioc.txt
powershell
# Windows : chercher des hashs dans un dossier
Get-ChildItem -Recurse | Get-FileHash | Where-Object { $_.Hash -in $iocHashes }

11 Rechercher des fichiers (find, where, Get-ChildItem)

find (Linux)

bash
# Par nom
find /var -name "*.log"

# Par nom avec wildcards
find / -name "auth*" 2>/dev/null

# Par type
find /home -type f                    # fichiers seulement
find /home -type d                    # dossiers seulement

# Par taille
find / -type f -size +100M            # > 100 Mo
find / -type f -size -10k             # < 10 Ko

# Par date de modification
find / -mtime -7                      # modifiés dans les 7 derniers jours
find / -mtime +30                     # modifiés il y a plus de 30 jours
find / -newer /tmp/marker             # plus récents qu'un fichier de référence

# Par utilisateur / permissions
find /home -user suspect
find / -perm -u+s 2>/dev/null         # binaires SUID (escalade de privilège potentielle)

# Exécuter une action sur chaque résultat
find /var/log -name "*.gz" -exec zcat {} \;          # afficher
find /tmp -type f -mtime +30 -delete                 # supprimer

where (Windows cmd) et Get-ChildItem (PowerShell)

bat
where /R C:\ "*.log"                  :: récursif
where /R C:\Windows /T "auth*"        :: avec timestamps
powershell
# Get-ChildItem est l'équivalent moderne et puissant
Get-ChildItem -Path C:\ -Filter "*.log" -Recurse 2>$null

# Par taille
Get-ChildItem -Recurse | Where-Object { $_.Length -gt 100MB }

# Par date
Get-ChildItem -Recurse | Where-Object { $_.LastWriteTime -gt (Get-Date).AddDays(-7) }

# Combiné : fichiers .ps1 modifiés ces 7 derniers jours
Get-ChildItem -Path C:\ -Filter "*.ps1" -Recurse |
    Where-Object { $_.LastWriteTime -gt (Get-Date).AddDays(-7) }

Cas DFIR concret : trouver les exécutables récents dans les Temp

bash
# Linux : exécutables modifiés dans les 7 derniers jours
find /tmp /var/tmp -type f -name "*.sh" -mtime -7 2>/dev/null
powershell
# Windows : exécutables récents dans Temp utilisateur
Get-ChildItem $env:TEMP -Filter "*.exe" -Recurse |
    Where-Object { $_.LastWriteTime -gt (Get-Date).AddDays(-7) } |
    Select-Object FullName, LastWriteTime, Length

12 Compresser et décompresser

Linux

bash
# tar (sans compression)
tar -cf archive.tar dossier/             # créer
tar -xf archive.tar                      # extraire
tar -tf archive.tar                      # lister

# tar.gz (avec gzip)
tar -czf archive.tar.gz dossier/         # créer
tar -xzf archive.tar.gz                  # extraire

# tar.bz2 (avec bzip2, plus compressé)
tar -cjf archive.tar.bz2 dossier/
tar -xjf archive.tar.bz2

# tar.xz (avec xz, encore plus compressé)
tar -cJf archive.tar.xz dossier/
tar -xJf archive.tar.xz

# zip / unzip
zip -r archive.zip dossier/
unzip archive.zip

# 7z
7z a archive.7z dossier/
7z x archive.7z

PowerShell

powershell
# zip natif
Compress-Archive -Path C:\dossier -DestinationPath archive.zip
Expand-Archive -Path archive.zip -DestinationPath C:\extracted

# Avec 7z (si installé)
& "C:\Program Files\7-Zip\7z.exe" a archive.7z C:\dossier
& "C:\Program Files\7-Zip\7z.exe" x archive.7z
💡 Astuce
.tar.gz pour les collectes Linux, .zip pour Windows, .7z pour la compression maximale (preuves volumineuses).

14 Permissions et droits

Linux : ls -l et chmod

bash
ls -l /etc/passwd
-rw-r--r-- 1 root root 2580 Jan 15 14:32 /etc/passwd

Format : [type][owner][group][others]

  • - : fichier (d = directory, l = symlink)
  • rw- : owner peut lire et écrire
  • r-- : group peut lire seulement
  • r-- : others peut lire seulement

Changer les permissions :

bash
chmod 755 script.sh        # owner: rwx, group: rx, others: rx
chmod +x script.sh         # ajouter exécutable
chmod -w fichier           # retirer écriture

chown user:group fichier   # changer propriétaire

Windows : icacls

powershell
# Voir les permissions
icacls C:\Cases\preuve.E01

# Donner full control à un utilisateur
icacls C:\Cases\preuve.E01 /grant "DOMAIN\analyst:F"

# Retirer une permission
icacls C:\Cases\preuve.E01 /remove "BUILTIN\Users"

# Hériter / ne pas hériter
icacls C:\Cases\preuve.E01 /inheritance:r    # désactive l'héritage
💡 Astuce
sur le coffre de preuves, mettre lecture seule pour l'équipe forensique entière, propriété uniquement au lead investigator. Audite régulièrement avec icacls ou ls -l.

15 Calculer un hash de fichier

Fondamental en DFIR pour vérifier l'intégrité d'une image ou d'un artefact.

Linux

bash
md5sum fichier.E01
sha1sum fichier.E01
sha256sum fichier.E01

# Sur plusieurs fichiers
sha256sum *.E01

# Stocker dans un fichier
sha256sum *.E01 > hashes.txt

# Vérifier ensuite
sha256sum -c hashes.txt

PowerShell

powershell
# Hash SHA-256 (par défaut)
Get-FileHash C:\Cases\image.E01

# Hash MD5 (pour comparaison legacy)
Get-FileHash C:\Cases\image.E01 -Algorithm MD5

# Plusieurs fichiers
Get-ChildItem *.E01 | Get-FileHash

# Stocker dans un CSV
Get-ChildItem -Recurse | Get-FileHash | Export-Csv hashes.csv

Cas DFIR concret

bash
# Linux : hasher tous les artefacts collectés
cd /cases/2026/MP-VD-001/triage/
sha256sum * > MANIFEST_SHA256.txt
powershell
# Windows : hasher tous les fichiers d'une collecte KAPE
Get-ChildItem D:\Triage\WORKSTATION01 -Recurse -File |
    Get-FileHash -Algorithm SHA256 |
    Export-Csv D:\Triage\WORKSTATION01_hashes.csv

18 Écrire un mini-script de triage

Voilà la magie : enchaîner les commandes pour automatiser.

Linux : triage.sh

bash
#!/bin/bash
# Mini-triage Linux pour DFIR

CASE_DIR="/cases/$(hostname)_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$CASE_DIR"

echo "[*] Triage en cours dans $CASE_DIR"

# Système et utilisateurs
hostname > "$CASE_DIR/hostname.txt"
uname -a > "$CASE_DIR/uname.txt"
who > "$CASE_DIR/who.txt"
last > "$CASE_DIR/last.txt"

# Processus et services
ps -auxf > "$CASE_DIR/processes.txt"
systemctl list-units --type=service > "$CASE_DIR/services.txt"

# Réseau
ip addr show > "$CASE_DIR/network.txt"
ss -tunap > "$CASE_DIR/connections.txt"

# Logs récents (7 derniers jours)
journalctl --since "7 days ago" > "$CASE_DIR/journal_7d.txt" 2>/dev/null
find /var/log -mtime -7 -type f -exec cp {} "$CASE_DIR/" \; 2>/dev/null

# Hashes des binaires sensibles
sha256sum /bin/* /sbin/* /usr/bin/* /usr/sbin/* 2>/dev/null > "$CASE_DIR/binary_hashes.txt"

# Hash de la collecte
cd "$CASE_DIR"
sha256sum * > MANIFEST_SHA256.txt

echo "[+] Triage terminé : $CASE_DIR"
ls -lh "$CASE_DIR/"

Pour exécuter :

bash
chmod +x triage.sh
sudo ./triage.sh

PowerShell : Triage.ps1

powershell
# Mini-triage Windows pour DFIR
$CaseDir = "D:\Cases\$env:COMPUTERNAME`_$(Get-Date -Format yyyyMMdd_HHmmss)"
New-Item -ItemType Directory -Path $CaseDir | Out-Null

Write-Host "[*] Triage en cours dans $CaseDir"

# Système et utilisateurs
$env:COMPUTERNAME | Out-File "$CaseDir\hostname.txt"
Get-CimInstance Win32_OperatingSystem | Out-File "$CaseDir\os.txt"
Get-LocalUser | Out-File "$CaseDir\users.txt"
Get-EventLog -LogName Security -Newest 100 -InstanceId 4624 |
    Out-File "$CaseDir\recent_logons.txt"

# Processus et services
Get-Process | Sort-Object CPU -Desc |
    Select Name,Id,CPU,WS,Path | Format-Table | Out-File "$CaseDir\processes.txt"
Get-Service | Where-Object { $_.Status -eq "Running" } |
    Select Name,DisplayName | Out-File "$CaseDir\services.txt"

# Réseau
Get-NetIPConfiguration | Out-File "$CaseDir\network.txt"
Get-NetTCPConnection -State Established | Out-File "$CaseDir\connections.txt"

# Persistance
Get-CimInstance Win32_StartupCommand | Out-File "$CaseDir\startup.txt"
Get-ScheduledTask | Where-Object { $_.State -ne "Disabled" } |
    Out-File "$CaseDir\tasks.txt"

# Hash de la collecte
Get-ChildItem $CaseDir -File |
    Get-FileHash -Algorithm SHA256 |
    Export-Csv "$CaseDir\MANIFEST_SHA256.csv"

Write-Host "[+] Triage terminé : $CaseDir"
Get-ChildItem $CaseDir

19 Astuces de productivité

Universel

🔹 Tab key : auto-complétion des chemins et commandes. Indispensable.

🔹 Flèches haut/bas : historique des commandes.

🔹 Ctrl+C : interrompre la commande en cours.

🔹 Ctrl+L ou clear (Linux) / cls (Windows) : nettoyer l'écran.

🔹 Ctrl+R (bash) : recherche incrémentale dans l'historique.

🔹 Ctrl+A / Ctrl+E : début / fin de ligne (bash, PowerShell).

🔹 !! (bash) : rejouer la dernière commande.

🔹 !sudo (bash) : rejouer la dernière commande avec sudo.

Linux spécifique

🔹 alias ll='ls -lah' dans ~/.bashrc : crée des raccourcis personnalisés.

🔹 which commande : retrouve où est installé un binaire.

🔹 man commande : manuel d'une commande (q pour quitter).

🔹 tldr commande : version courte et avec exemples (à installer : apt install tldr).

🔹 htop au lieu de top : interface beaucoup plus lisible.

🔹 tmux ou screen : sessions persistantes (essentiel sur SSH long).

Windows spécifique

🔹 Get-Help Get-Process -Full : documentation complète d'une commande PowerShell.

🔹 Get-Command string : chercher une commande par mot-clé.

🔹 Get-Alias : voir tous les alias (ls = Get-ChildItem, cat = Get-Content, etc.).

🔹 Windows Terminal supporte les profils (un par shell, couleurs custom, raccourcis).

🔹 PSReadLine (intégré PowerShell 7+) : auto-complétion intelligente avec Tab et flèches.

Pour le DFIR

🔹 Toujours rediriger la sortie vers un fichier (> output.txt) pour conserver une trace pour le rapport.

🔹 Documenter chaque commande importante dans un journal .md : commande + output abrégé + interprétation.

🔹 Hash systématique : à chaque artefact collecté.

🔹 Lire avant supprimer : cat fichier avant rm fichier, toujours.

🔹 Tester sur VM avant d'exécuter sur preuve. Un script qui efface 50 Go par erreur = catastrophe.

21 Conclusion

La ligne de commande n'est pas un luxe en DFIR — c'est la langue universelle qui te connecte à tous les outils, tous les serveurs, tous les artefacts. Sans CLI, tu plafonnes à 20 % de la puissance de chaque logiciel forensique.

Apprendre la CLI prend 2-4 semaines de pratique régulière pour les bases (ce tutoriel), et plusieurs mois pour la maîtrise. La meilleure stratégie : forcer son usage. Quand tu peux faire en CLI ce que tu ferais en GUI, fais en CLI. Au début lent, vite plus rapide.

Recommandations finales :

  1. Pratiquer 30 min/jour pendant un mois sur une VM Linux et une VM Windows.
  2. Tenir un fichier notes.md des commandes utiles que tu découvres.
  3. Faire les wargames OverTheWire Bandit (50 niveaux de bash progressifs).
  4. Écrire un script de triage maison adapté à ton contexte (cf. §18).
  5. Lire les logs de tes propres systèmes (/var/log/auth.log, Event Viewer) pour t'habituer aux formats.
  6. Apprendre tmux ou Windows Terminal pour gérer plusieurs sessions sans s'y perdre.

La CLI, c'est l'investissement le plus rentable de ta carrière DFIR. Bonne pratique ! ⌨️
