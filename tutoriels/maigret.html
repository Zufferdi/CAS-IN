🕵️ Maigret — OSINT approfondi (3000+ sites)

À la fin de ce tutoriel, tu sauras utiliser Maigret sur 3000+ sites, extraire les métadonnées (photo, bio, dates, posts), générer des rapports HTML et PDF directement présentables, rechercher par email, téléphone, nom complet, utiliser la recherche récursive pour pivoter sur les IoCs trouvés, filtrer par tags (social, dating, business, etc.), et orchestrer un workflow OSINT complet Sherlock + Maigret + outils complémentaires.
🎯 Niveau expert ⏱ ~55 min 🐧 Linux / macOS 🪟 Windows 🕵️ 3000+ sites + métadonnées 📄 Rapports HTML/PDF ⚖️ nLPD / RGPD
⚠️ Maigret produit des dossiers d'enquête
Là où Sherlock détecte une présence, Maigret produit une fiche d'enquête avec photos, bio, dates, posts. C'est un traitement de données personnelles au sens de la nLPD (Suisse, 2023) et du RGPD. Stockage chiffré, accès restreint, durée de conservation limitée : comme tout dossier d'enquête sérieux. Le nom rend hommage au commissaire Maigret de Simenon — l'enquêteur méticuleux et éthique.

📦 github.com/soxoj/maigret · Licence MIT · Auteur : soxoj

01 Présentation générale

Maigret est un script Python qui :

  1. Prend un username (ou email, téléphone, nom)
  2. Teste 3000+ sites web et services
  3. Extrait les métadonnées (photo de profil, bio, dates, posts) sur les sites qui le permettent
  4. Génère un rapport structuré (HTML, PDF, JSON, CSV)
  5. Peut enchaîner : trouver un email dans un profil et relancer la recherche dessus

C'est le standard OSINT moderne pour les enquêtes nominatives sérieuses. Là où Sherlock fait du "présence/absence", Maigret produit une fiche d'enquête.

Particularités :

  • 3000+ sites supportés (vs 400 Sherlock)
  • Extraction de plus de 100 types de métadonnées
  • Rapports HTML interactifs, PDF prêts pour la procédure, JSON / CSV / TXT / XMind
  • Support recherche email, téléphone, nom complet (pas que username)
  • Recherche récursive : pivote automatiquement sur les emails/usernames trouvés
  • Pas seulement réseaux sociaux : forums, e-commerce, gaming, dating, professionnel
  • Open source MIT
  • Actif et bien maintenu

Règle :

  • Sherlock : vérification rapide, premier passage
  • Maigret : enquête sérieuse, livrables professionnels

Idéalement : les deux. Sherlock pour le triage rapide, Maigret pour l'enquête approfondie.

03 Cadre légal et éthique

Identique à Sherlock — relire la section §2 du tutoriel Sherlock.

Spécificités Maigret :

  • L'extraction de métadonnées (photo, bio) constitue un traitement de données personnelles plus poussé.
  • En Suisse : nLPD entrée en vigueur 2023 — Maigret tombe dans son champ d'application pour usage professionnel.
  • En UE : GDPR — exige un intérêt légitime documenté ou un mandat.
🚨 Critique
Les rapports Maigret (avec photo, bio, dates de naissance déduites) sont des dossiers d'enquête sensibles. Stockage chiffré, durée de conservation limitée, accès restreint — comme pour toute donnée personnelle traitée professionnellement.

04 Cas d'usage typiques

  • Enquête pénale sur cybercriminel : retrouver TOUS ses comptes, métadonnées, photos.
  • Investigation harcèlement : tracer les multiples comptes d'un harceleur.
  • OSINT corporate : audit de surface d'attaque d'un dirigeant (avec mandat interne).
  • Anti-fraude : vérifier la cohérence d'un partenaire commercial multi-sites.
  • Recrutement vérifié : audit complet de profil candidat (avec accord).
  • Journalisme d'investigation : retracer un compte anonyme propageant fake news.
  • Trace Labs / Persons missing CTF : retrouver une personne disparue via traces numériques.
  • Threat intelligence APT : tracer les opérateurs derrière un groupe APT par pseudo.

06 Installation via pip

Méthode recommandée : environnement virtuel

bash
mkdir -p ~/osint && cd ~/osint
python3 -m venv venv
source venv/bin/activate
pip install maigret

Sur Windows :

powershell
mkdir $env:USERPROFILE\osint
cd $env:USERPROFILE\osint
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install maigret

Vérification

bash
maigret --version
maigret --help

Optionnel : wkhtmltopdf pour les rapports PDF

Linux Debian/Ubuntu :

bash
sudo apt install -y wkhtmltopdf

macOS :

bash
brew install --cask wkhtmltopdf

Windows : télécharger depuis <https://wkhtmltopdf.org/downloads.html>

Sans wkhtmltopdf, les rapports PDF ne fonctionnent pas, mais HTML/JSON/CSV restent disponibles.

Installation depuis Git (dernière version dev)

bash
git clone https://github.com/soxoj/maigret.git
cd maigret
pip install -r requirements.txt
python -m maigret --version

07 Installation via Docker

bash
docker pull soxoj/maigret

# Recherche avec output local
docker run --rm -t -v $(pwd):/app/reports soxoj/maigret \
    username_to_search --folderoutput /app/reports
💡 Astuce
Docker isole complètement Maigret de ton système. Idéal pour OSINT dans une VM dédiée.

08 Premier lancement

Syntaxe basique

bash
maigret pseudo_a_chercher

Exemple :

bash
maigret johndoe

Maigret affiche en temps réel chaque site testé. Sortie finale :

shell
Search by username johndoe completed.
Total found: 47 of 3023 sites
Recommendations: try 'johndoe' with email enrichment
Reports saved in current folder

Plusieurs fichiers ont été générés dans le dossier courant :

  • report_johndoe.html — rapport HTML interactif
  • report_johndoe.json — données structurées
  • report_johndoe.csv — tableau exploitable
  • report_johndoe.txt — texte simple
  • report_johndoe.xmind — mind map pour MindNode/XMind (visualisation arbre)
  • report_johndoe.pdf — si wkhtmltopdf installé

Ouvrir le rapport HTML

bash
xdg-open report_johndoe.html         # Linux
open report_johndoe.html             # macOS
start report_johndoe.html            # Windows

Le rapport HTML est interactif : photos, liens cliquables, regroupement par catégorie, métadonnées extraites.

09 Options essentielles

Format de sortie

bash
maigret johndoe --html              # HTML uniquement
maigret johndoe --pdf               # PDF
maigret johndoe --json simple       # JSON structuré
maigret johndoe --csv               # CSV
maigret johndoe --txt               # texte
maigret johndoe --xmind             # mind map

# Tout
maigret johndoe -a       # all formats

Folder de sortie

bash
maigret johndoe --folderoutput results/

Timeout

bash
maigret johndoe --timeout 10

Verbose et logs

bash
maigret johndoe -v          # verbose
maigret johndoe -vv         # encore plus verbose
maigret johndoe --no-color  # sans couleurs (pour scripts)

N'afficher que les trouvés

bash
maigret johndoe --print-found      # uniquement trouvés (équivalent Sherlock)

Nombre de sites parallèles

bash
maigret johndoe --connections 50    # 50 sites simultanés (défaut 10)

Trop élevé → rate limit, certains sites bannissent. 50 est un bon compromis.

10 Extraction de métadonnées (photo, bio, posts)

C'est la valeur ajoutée de Maigret sur Sherlock.

Comportement par défaut

Maigret extrait automatiquement les métadonnées qu'il sait extraire de chaque site. Le rapport HTML les affiche.

Types de métadonnées récupérées

MétadonnéeSites supportant
Photo de profilTwitter, GitHub, Instagram, LinkedIn (partiel), Reddit, GitLab, ...
Bio / DescriptionTwitter, GitHub, Pinterest, Telegram, ...
Nom completLinkedIn, Facebook, Stack Overflow, ...
Date d'inscriptionReddit, Twitter (estim.), GitHub, ...
Nombre d'abonnés / abonnementsTwitter, Instagram, GitHub, ...
Posts récents (titre, date)Reddit, Medium, dev.to, ...
Localisation déclaréeTwitter, GitHub, certains forums
Email publicGitHub (si renseigné), certains forums
Liens externesTwitter, GitHub, blog perso, ...

Dans le rapport HTML

Cliquer sur un profil affiche :

  • Photo en grand
  • Bio extraite
  • Toutes les métadonnées disponibles
  • Lien direct vers le profil

Format JSON pour traitement automatisé

bash
maigret johndoe --json simple --folderoutput results/

# Extraire toutes les photos de profil :
jq -r '.. | .photo_url? // empty' results/report_johndoe.json
💡 Astuce
un rapport Maigret HTML est souvent directement transmissible à un client/magistrat. Pas besoin de retravailler.

11 Rapports HTML et PDF

Rapport HTML (par défaut)

Interactif, riche, avec photos. Le standard pour les présentations internes ou la consultation rapide.

bash
maigret johndoe --html

Le HTML est autonome (CSS/JS embarqués) — partageable par email.

Rapport PDF (procédure)

Pour transmission formelle en dossier :

bash
maigret johndoe --pdf

Nécessite wkhtmltopdf installé. PDF formaté, paginé, immutable.

Idéal pour pièce de procédure pénale (datable, hashable, partageable).

Hash du rapport

Une fois le PDF généré, hash systématique :

bash
sha256sum report_johndoe.pdf >> MANIFEST_SHA256.txt
🚨 Critique
un rapport non hashé n'a pas de valeur juridique sérieuse.

12 Recherche par email, téléphone, nom complet

Maigret ne se limite pas au username.

Par email

bash
maigret john.doe@example.com

Maigret reconnaît le format, cherche sur Gravatar, GitHub, HaveIBeenPwned (intégration limitée), et des dizaines de sites acceptant l'email comme login public.

Par téléphone

bash
maigret "+41 79 123 45 67"
maigret "+1 (415) 555-0100"

Maigret teste sur les sites supportant la recherche par téléphone (Telegram, WhatsApp via API publique, certains forums).

Par nom complet

bash
maigret "John Doe" --use-nicknames

--use-nicknames génère des variations (jdoe, john.doe, etc.) à partir du nom.

💡 Astuce
maigret johndoe john.doe john_doe jdoe j_doe john-doe teste toutes les variations en une commande.

13 Recherche récursive (chaînage d'IoCs)

Maigret peut enchaîner : trouve un email sur GitHub → relance la recherche sur cet email → trouve un username sur Stack Overflow → relance dessus, etc.

bash
maigret johndoe --recursive-search

À utiliser avec parcimonie — ça peut s'enchaîner sur de nombreuses étapes et générer un dossier énorme.

Maigret limite par défaut la profondeur récursive. Réglable via --max-recursion.

Cas d'usage

Tu pars d'un username, tu veux explorer toute la galaxie identitaire d'une personne :

bash
maigret target_username --recursive-search --max-recursion 3 --pdf --folderoutput case_2026_001/

Tu obtiens un rapport multi-niveaux qui explore les pseudos liés, emails liés, et leurs propres connexions.

🚨 Critique
peut générer beaucoup de faux positifs (un pseudo générique trouvé sur 100 sites lance 100 recherches secondaires). Toujours valider manuellement les profils de premier niveau avant d'autoriser la récursivité.

14 Filtrer les sites par tags

Maigret tague les sites par catégorie. Tu peux limiter aux catégories pertinentes.

Catégories disponibles

bash
maigret --tags

Liste typique : dating, gaming, social, business, forum, photo, tech, coding, russian, chinese, crypto, etc.

Filtrer

bash
# Seulement les sites de dating
maigret johndoe --tags dating

# Plusieurs catégories
maigret johndoe --tags social,business

# Exclure une catégorie
maigret johndoe --tags "!gaming"

Cas DFIR

bash
# Enquête sur fraude financière : cibler les sites crypto + business
maigret suspect --tags crypto,business,finance --pdf

15 Personnaliser la base de sites

Maigret stocke sa base de sites dans data.json (au format JSON Maigret). Tu peux la modifier pour :

  • Ajouter un site interne à ton organisation
  • Désactiver des sites qui produisent trop de faux positifs
  • Ajouter un site régional non couvert

Localiser data.json

bash
python3 -c "import maigret; print(maigret.__file__)"
# Le data.json est dans le dossier sites/ à côté

Format d'un site

json
{
  "MonSite": {
    "tags": ["forum", "tech"],
    "checkType": "status_code",
    "url": "https://monsite.example/u/{}",
    "urlMain": "https://monsite.example/",
    "username_claimed": "blue",
    "username_unclaimed": "xxxxx_unlikely_username"
  }
}

Valider toujours avec un compte connu (username_claimed) et un improbable (username_unclaimed).

16 Utiliser un proxy ou Tor

Comme Sherlock — masquer ton IP est recommandé pour les enquêtes sensibles.

Tor

Démarrer Tor en background :

bash
sudo systemctl start tor

Lancer Maigret via Tor :

bash
maigret johndoe --proxy socks5h://127.0.0.1:9050
⚠️ Attention
️ Maigret via Tor est 3-5x plus lent mais protège totalement ton IP.

Proxy HTTP

bash
maigret johndoe --proxy http://proxy.example.com:8080

Stratégie IP rotation

Pour des enquêtes massives, utiliser un VPS dédié OSINT avec IP rotative (Mullvad, Proton VPN multi-hop, ou pool de VPN).

17 Workflow OSINT complet avec Maigret

Mise en pratique : enquête sur un compte suspect.

Setup

bash
USERNAME="suspect_2026"
mkdir -p "case_$USERNAME"
cd "case_$USERNAME"

# Activer venv
source ~/osint/venv/bin/activate

Étape 1 — Triage rapide Sherlock

bash
sherlock --print-found --json sherlock.json "$USERNAME"

Si rien trouvé : pseudo très spécifique, peu d'empreinte → enquête courte. Si beaucoup trouvé : préparation enquête approfondie avec Maigret.

Étape 2 — Enquête approfondie Maigret

bash
maigret "$USERNAME" \
    --html --pdf --json simple \
    --folderoutput . \
    --timeout 15 \
    --connections 30 \
    --tags social,forum,business,tech

Étape 3 — Inspection du rapport HTML

Identifier les 3-5 profils de référence avec photos, bio, dates cohérentes.

Étape 4 — Pivots manuels

Pour chaque profil de référence trouvé :

bash
# Archive Wayback Machine
curl -s "https://web.archive.org/save/https://twitter.com/$USERNAME"

# Reverse image search sur photo (manuel : TinEye, Yandex, Google Images)

# Si email trouvé dans GitHub → relancer Maigret dessus
EMAIL=$(jq -r '.entries[].metadata.email // empty' report_$USERNAME.json | head -1)
[ -n "$EMAIL" ] && maigret "$EMAIL" --html --folderoutput pivot_email/

Étape 5 — Synthèse et rapport

bash
# Hasher tous les rapports
sha256sum *.pdf *.html *.json > MANIFEST_SHA256.txt

# Documenter
cat > rapport_synthese.md <<EOF
# Investigation OSINT — $USERNAME

**Date :** $(date -Iseconds)
**Autorité :** [mandat / autorisation]
**Analyste :** [nom]

18 Profils confirmés (corroborés par 2+ sources)

  • ...

19 Profils possibles (à investiguer)

  • ...

20 Pivots emails / téléphone

  • ...

21 Méthodologie

  • Outils : Sherlock $(sherlock --version), Maigret $(maigret --version)
  • Réseau : VPN OSINT [identifiant]
  • Période d'investigation : ...

22 Manifest des fichiers

$(cat MANIFEST_SHA256.txt) EOF

shell

Tu disposes d'un dossier complet, traçable, hashé, exploitable en procédure.

18 Forces et faiblesses

Forces

✅ 3000+ sites — couverture quasi exhaustive.

✅ Extraction de métadonnées — photo, bio, dates → dossier d'enquête direct.

✅ Rapports HTML/PDF — directement présentables.

✅ Recherche multi-IoC : username, email, téléphone, nom.

✅ Recherche récursive — automatisation des pivots.

✅ Tags par catégorie — recherche ciblée.

✅ Communauté active — mises à jour fréquentes.

✅ Multi-plateforme — Linux, macOS, Windows, Docker.

✅ Open source MIT — auditable, modifiable.

✅ Bien documenté — README détaillé, exemples nombreux.

Faiblesses

❌ Plus lent que Sherlock (3000 vs 400 sites).

❌ Plus de faux positifs mécaniquement (plus de sites = plus de candidats).

❌ Dépendances Python : besoin de Python 3.10+, parfois conflits avec d'autres outils.

❌ wkhtmltopdf : dépendance externe pour PDF, parfois pénible à installer.

❌ Récursivité peut exploser : sans --max-recursion strict, peut générer des téraoctets de rapports inutiles.

❌ Détection : User-Agent Maigret est connu de certains sites — bans temporaires possibles.

❌ Pas de bypass captcha / Cloudflare : faux négatifs sur sites lourdement protégés.

❌ Sites privés invisibles : ne voit que les pages publiques.

❌ Aspect dual-use : peut servir des usages problématiques (stalking, doxxing). Discipline éthique requise.

19 Bonnes pratiques OSINT

🔹 Toujours utiliser un VPN OSINT dédié ou Tor pour les enquêtes sensibles.

🔹 Environnement isolé : VM dédiée OSINT, pas tes comptes personnels.

🔹 Documenter chaque enquête : autorité, finalité, période, outils, versions.

🔹 Hasher tous les rapports dès leur production (chaîne de preuve).

🔹 Archiver immédiatement les profils trouvés (Wayback Machine + screenshots horodatés).

🔹 Corroborer avant conclure : 2+ sources cohérentes (photo, bio, dates) pour valider l'identité.

🔹 Différencier piste et preuve : Maigret fournit des pistes.

🔹 Mettre à jour régulièrement : pip install --upgrade maigret.

🔹 Limiter la récursivité : --max-recursion 2 par défaut, plus seulement si justifié.

🔹 Stocker les rapports chiffrés : conteneur VeraCrypt ou disque chiffré BitLocker / LUKS.

🔹 Durée de conservation limitée : effacer les enquêtes closes après le délai légal (souvent 3-10 ans selon affaire).

🔹 Respect du secret de l'instruction : un rapport Maigret ne quitte pas le dossier sans autorisation.

🔹 Combiner avec Sherlock pour gain de temps (Sherlock = triage, Maigret = approfondissement).

🔹 Combiner avec Holehe pour les enquêtes partant d'un email.

🔹 Suivre soxoj sur GitHub : nouveautés régulières.

26 Conclusion

Maigret est l'outil OSINT de référence pour les enquêtes username sérieuses. Sa profondeur (3000+ sites, métadonnées, rapports professionnels) en fait l'équivalent enquêteur méticuleux du commissaire Maigret dont il porte le nom — par opposition à Sherlock, plus généraliste.

L'usage demande discipline éthique et rigueur procédurale. Un rapport Maigret est un dossier d'enquête : il doit être traité comme tel (chaîne de preuve, hash, accès restreint, durée de conservation).

Recommandations finales :

  1. Configurer un environnement OSINT dédié : VM, VPN OSINT, pas de comptes perso.
  2. Combiner avec Sherlock : Sherlock pour le triage rapide, Maigret pour l'enquête.
  3. Ajouter Holehe et PhoneInfoga au toolkit selon les inputs.
  4. Archiver systématiquement : Wayback Machine, screenshots horodatés.
  5. Documenter chaque enquête : c'est ton dossier juridique.
  6. Lire Bazzell — Open Source Intelligence Techniques.
  7. Faire des CTFs Trace Labs (recherches sur personnes disparues, encadrement éthique).
  8. Suivre l'auteur soxoj : il publie régulièrement sur Telegram et Medium.

Une enquête Maigret bien menée vaut un mandat : précise, traçable, exploitable. À toi de la mener avec la même rigueur qu'un magistrat. 🕵️
