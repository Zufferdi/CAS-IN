🔧 CLI intermédiaire — Pipelines & scripts

À la fin de ce tutoriel, tu sauras utiliser cut, sort, uniq, wc en pipelines, maîtriser grep avec regex étendues, transformer des données avec sed, parser logs et CSV avec awk, manipuler avec tr/xargs, écrire des scripts bash robustes (conditions, boucles, fonctions, set -euo pipefail), et l'équivalent en PowerShell (Where-Object, ForEach-Object, Select-Object).
🎯 Niveau intermédiaire ⏱ ~60 min 🐧 bash / awk / sed 🪟 PowerShell 📝 Scripts robustes
ℹ️ Prérequis : Bases CLI (v127)
Ce tutoriel suppose acquis les fondamentaux : navigation, fichiers, pipes, redirection, grep et find basiques. Si ce n'est pas le cas, passe d'abord par le tutoriel Bases CLI.

Tu vas apprendre à transformer des heures de clic en 30 secondes de commande, à parser n'importe quel log Apache/syslog/EVTX, et à écrire des scripts de triage qui fonctionnent vraiment.

01 Prérequis et positionnement

Prérequis : avoir terminé le tutoriel Bases CLI (v127). Tu dois savoir :

  • Naviguer (cd, ls, pwd)
  • Lire un fichier (cat, less, head, tail)
  • Rediriger (>, >>, 2>)
  • Piper (|)
  • Recherches basiques (grep, find)

Ce que tu sauras à la fin :

  • Parser des logs Apache/auth.log avec awk en quelques secondes
  • Transformer des données avec sed
  • Écrire des scripts bash robustes (gestion d'erreurs, conditions, boucles)
  • Manipuler du texte avec des regex étendues
  • Écrire l'équivalent en PowerShell moderne

02 cut — découper par colonne

Extraire des colonnes spécifiques d'un fichier structuré.

Par caractère

bash
echo "abcdefghij" | cut -c 3-7
# Sortie : cdefg

Par champ avec séparateur

bash
# /etc/passwd : "user:x:1000:1000:User Name:/home/user:/bin/bash"
cut -d':' -f1,3,7 /etc/passwd
# Sortie : user:1000:/bin/bash
  • -d':' : séparateur (deux-points)
  • -f1,3,7 : champs 1, 3 et 7
  • -f1-3 : plage 1 à 3

Cas DFIR

bash
# Extraire les IPs depuis un access.log Apache
cut -d' ' -f1 /var/log/apache2/access.log | head

# Lister tous les utilisateurs du système
cut -d':' -f1 /etc/passwd

03 sort, uniq, wc — trier compter dédupliquer

sort

bash
sort fichier.txt                 # alphabétique
sort -n nombres.txt              # numérique
sort -r fichier.txt              # ordre inversé
sort -k 2 fichier.txt            # tri sur le 2e champ
sort -t',' -k 3 -n data.csv      # CSV, champ 3, numérique

uniq

uniq supprime les doublons adjacents — il faut donc trier d'abord.

bash
sort fichier.txt | uniq                   # supprime doublons
sort fichier.txt | uniq -c                # compte les occurrences
sort fichier.txt | uniq -c | sort -rn     # tri par fréquence décroissante

wc

bash
wc fichier.txt          # lignes / mots / octets
wc -l fichier.txt       # lignes uniquement
wc -c fichier.txt       # octets
wc -w fichier.txt       # mots

Le pattern classique : top N

bash
# Top 10 des IPs ayant le plus consulté un site (access.log Apache)
cut -d' ' -f1 access.log | sort | uniq -c | sort -rn | head -n 10

C'est le pattern le plus utilisé en CLI analytics. Tu le verras partout.

04 grep avancé : regex étendues

Drapeaux essentiels

bash
grep -i "motif" file              # insensible casse
grep -v "motif" file              # inversé (lignes sans le motif)
grep -c "motif" file              # nombre d'occurrences
grep -n "motif" file              # avec numéro de ligne
grep -r "motif" dossier/          # récursif
grep -l "motif" *.log             # juste les noms de fichiers qui matchent
grep -A 5 "ERROR" log             # 5 lignes après le match
grep -B 5 "ERROR" log             # 5 lignes avant
grep -C 5 "ERROR" log             # 5 lignes avant et après

Regex de base

MotifSens
.un caractère quelconque
*zéro ou plusieurs (du caractère précédent)
^motifdébut de ligne
motif$fin de ligne
[abc]un caractère parmi a, b, c
[a-z]un caractère minuscule
[^abc]un caractère sauf a, b, c
\dun chiffre (en regex étendue, avec -E)

grep -E (regex étendues, ERE)

bash
# Pipe : OU
grep -E "ERROR|WARN|CRITICAL" application.log

# Quantificateurs : ? + {n,m}
grep -E "colou?r" file                    # color OR colour
grep -E "[0-9]{3}-[0-9]{4}" contacts      # 555-1234

# Groupes
grep -E "(http|https)://[a-z0-9.]+" pages.txt

Cas DFIR : extraire des IPs

bash
# Regex IP basique (ne valide pas strictement)
grep -oE "\b[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\b" access.log

# Avec sort + uniq -c pour le top
grep -oE "\b[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\b" /var/log/auth.log | sort | uniq -c | sort -rn | head

-o : afficher uniquement la partie qui matche (pas la ligne entière).

05 sed — Stream EDitor

Édition de texte ligne par ligne, non interactive. Utile pour les transformations massives.

Substituer

bash
sed 's/ancien/nouveau/' file              # 1re occurrence par ligne
sed 's/ancien/nouveau/g' file             # toutes les occurrences (global)
sed 's/ancien/nouveau/gi' file            # insensible casse
sed 's|/var/log|/tmp/logs|g' file         # changer le délimiteur si "/" gêne

Modifier en place

bash
sed -i 's/ancien/nouveau/g' file          # IMPORTANT : modifie le fichier
sed -i.bak 's/old/new/g' file             # avec backup file.bak

Supprimer

bash
sed '/motif/d' file                       # supprime lignes contenant motif
sed '5,10d' file                          # supprime lignes 5 à 10
sed '/^$/d' file                          # supprime lignes vides

Afficher uniquement certaines lignes

bash
sed -n '5,15p' file                       # affiche lignes 5 à 15
sed -n '/ERROR/p' file                    # affiche lignes contenant ERROR

Cas DFIR

bash
# Anonymiser des IPs dans un log (remplacer par X.X.X.X)
sed -E 's/\b[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\b/X.X.X.X/g' access.log

# Nettoyer un dump : enlever les commentaires bash
sed '/^#/d' script.sh

# Convertir CRLF en LF (Windows → Unix)
sed -i 's/\r$//' fichier_windows.txt

06 awk — le couteau suisse

awk est un langage de programmation intégré au shell, optimisé pour le traitement par ligne et colonne.

Syntaxe générale

bash
awk 'PATTERN { ACTION }' fichier

Premiers exemples

bash
# Afficher la 1re colonne d'un fichier (séparateur espace par défaut)
awk '{print $1}' file

# Afficher la 1re et la 3e colonne
awk '{print $1, $3}' file

# Compter le nombre de lignes
awk 'END {print NR}' file       # NR = Number of Records

# Champs d'une ligne particulière
awk 'NR==5 {print $0}' file     # ligne 5, $0 = ligne entière

Séparateur de champ

bash
# CSV
awk -F',' '{print $1, $3}' data.csv

# /etc/passwd (deux-points)
awk -F':' '$3 >= 1000 {print $1}' /etc/passwd     # users avec UID >= 1000

Conditions

bash
# Lignes où le 4e champ vaut "ERROR"
awk '$4 == "ERROR" {print $0}' app.log

# Lignes où la taille (champ 5) > 1000
awk '$5 > 1000 {print $1, $5}' file

Calculs

bash
# Somme des valeurs de la 3e colonne
awk '{sum += $3} END {print sum}' data.csv

# Moyenne
awk '{sum += $3; n++} END {print sum/n}' data.csv

# Min et max
awk 'BEGIN {max=0} {if ($3>max) max=$3} END {print max}' data.csv

Cas DFIR avec awk

bash
# Compter les codes HTTP dans un access.log Apache
# Format : IP - - [date] "METHOD URL HTTP/1.1" code size ...
awk '{print $9}' access.log | sort | uniq -c | sort -rn

# Taille totale transférée par IP
awk '{transfer[$1] += $10} END {for (ip in transfer) print transfer[ip], ip}' access.log | sort -rn | head

# Heures avec le plus d'erreurs 500
awk '$9 == 500 {print substr($4, 14, 2)}' access.log | sort | uniq -c | sort -rn

awk à lui seul mérite un tutoriel entier. Voici les 3 idiomes essentiels à connaître :

  1. Filtrer : awk '$3 > 100 {print}'
  2. Projeter : awk -F',' '{print $1, $5}'
  3. Agréger : awk '{count[$1]++} END {for (k in count) print count[k], k}'

07 tr — transformer des caractères

Substitutions caractère par caractère, ou suppression.

bash
# Tout en majuscules
echo "hello world" | tr 'a-z' 'A-Z'
# Sortie : HELLO WORLD

# Supprimer des caractères
echo "Hello, World!" | tr -d ',!'
# Sortie : Hello World

# Compresser les espaces multiples en un seul
echo "a    b    c" | tr -s ' '
# Sortie : a b c

# Remplacer toutes les ponctuations par des espaces
echo "Hello, world! How are you?" | tr -c 'a-zA-Z' ' '

Cas DFIR

bash
# Convertir un CSV en lignes (1 valeur par ligne)
cat data.csv | tr ',' '\n'

# Normaliser un journal : suppression des caractères non-imprimables
cat binary.log | tr -cd '[:print:]\n' > clean.log

08 xargs — passer une liste en arguments

xargs prend l'entrée standard et la transforme en arguments pour une commande.

Syntaxe basique

bash
# Supprimer tous les fichiers .tmp du dossier courant
ls *.tmp | xargs rm

# Mieux (gère les noms avec espaces)
find . -name "*.tmp" -print0 | xargs -0 rm

Plusieurs arguments à la fois

bash
# Par défaut, xargs passe tous les args en une fois
echo "a b c d" | xargs echo
# Sortie : a b c d

# Un par ligne :
echo "a b c d" | xargs -n 1 echo
# Sortie : a / b / c / d (sur 4 lignes)

Avec position d'argument

bash
# Copier chaque fichier dans un dossier en gardant le nom
ls *.txt | xargs -I {} cp {} /backup/{}

Cas DFIR

bash
# Hasher tous les fichiers .exe d'un dossier
find . -name "*.exe" | xargs sha256sum > hashes.txt

# Lancer une commande Volatility sur chaque dump mémoire
ls dumps/*.mem | xargs -I {} vol -f {} windows.pslist > {}.pslist.txt

09 find avec -exec et -delete

find peut exécuter une commande sur chaque résultat.

-exec

bash
# Hasher chaque fichier trouvé
find /var/log -name "*.log" -exec sha256sum {} \;

# Avec + (plus efficace : passe en lot, pas un par un)
find /var/log -name "*.log" -exec sha256sum {} +

{} est remplacé par le chemin du fichier. \; (ou ; échappé) termine la commande.

-delete

bash
# Supprimer tous les .tmp de plus de 30 jours
find /tmp -name "*.tmp" -mtime +30 -delete

🚨 Attention : -delete est définitif. Toujours tester d'abord avec -print :

bash
find /tmp -name "*.tmp" -mtime +30 -print     # vérifie ce qui sera supprimé
find /tmp -name "*.tmp" -mtime +30 -delete    # puis supprime

Combinaisons puissantes

bash
# Trouver les binaires SUID modifiés récemment (suspect en DFIR)
find / -type f -perm -u+s -mtime -30 2>/dev/null

# Trouver et hasher les exécutables récents dans /tmp
find /tmp -type f \( -name "*.sh" -o -name "*.exe" \) -mtime -7 -exec sha256sum {} \;

10 Pipelines complexes — exemples DFIR

Voici comment chaîner les commandes pour des analyses puissantes en une ligne.

Top 10 des comptes en échec d'authentification

bash
grep "Failed password" /var/log/auth.log | \
    awk '{print $9}' | \
    sort | uniq -c | sort -rn | head -n 10

Top 10 des IPs sources d'authentifications échouées

bash
grep "Failed password" /var/log/auth.log | \
    awk '{print $11}' | \
    sort | uniq -c | sort -rn | head -n 10

Activité par heure sur un serveur web

bash
awk '{print substr($4, 14, 2)}' /var/log/apache2/access.log | \
    sort | uniq -c | sort -k2

Codes HTTP les plus fréquents (Apache)

bash
awk '{print $9}' /var/log/apache2/access.log | \
    sort | uniq -c | sort -rn

IPs ayant tenté plus de 100 requêtes (scanners potentiels)

bash
awk '{print $1}' /var/log/apache2/access.log | \
    sort | uniq -c | \
    awk '$1 > 100 {print $1, $2}' | \
    sort -rn

Combiner les logs de plusieurs jours et chercher une IP

bash
zcat /var/log/auth.log.*.gz | grep "192.168.1.42" | head

zcat lit les fichiers .gz sans les décompresser.

11 Variables et substitution de commande

Définir et utiliser

bash
nom="alice"
echo "Bonjour $nom"

Substitution de commande : $(...)

Exécute une commande et remplace par son résultat.

bash
date_du_jour=$(date +%Y-%m-%d)

nb=$(ls *.log | wc -l)

bash

12 Conditions if/then/else

Syntaxe

bash
if [ condition ]; then
    commande
elif [ autre_condition ]; then
    autre_commande
else
    commande_par_defaut
fi

Tests courants

bash
# Fichier existe
if [ -f /etc/passwd ]; then echo "OK"; fi

# Dossier existe
if [ -d /home/user ]; then echo "OK"; fi

# Variable non vide
if [ -n "$var" ]; then echo "var contient quelque chose"; fi

# Variable vide
if [ -z "$var" ]; then echo "var est vide"; fi

# Comparer des chaînes
if [ "$user" = "root" ]; then echo "C'est root"; fi

# Comparer des nombres
if [ "$count" -gt 100 ]; then echo "Plus de 100"; fi
OpérateurSens
-eqégal (numérique)
-nedifférent
-gt -ltsupérieur / inférieur
-ge -lesupérieur ou égal / inférieur ou égal
= !=égal / différent (chaînes)

Syntaxe moderne [[ ... ]]

bash
if [[ "$file" == *.log ]]; then
    echo "C'est un fichier log"
fi

if [[ "$ip" =~ ^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
    echo "Format IP valide"
fi

[[ ... ]] est plus puissant que [ ... ] (regex avec =~, glob avec ==).

bash

for sur des fichiers

bash
for f in /var/log/*.log; do

bash
for i in {1..10}; do

bash
# Lire ligne par ligne un fichier

14 Fonctions bash

Pour structurer un script.

Définition

bash
ma_fonction() {
    echo "Bonjour $1"
    return 0
}

# Appel
ma_fonction "Alice"

Arguments et valeur de retour

bash
hash_fichier() {
    local fichier="$1"
    local algo="${2:-sha256}"   # défaut : sha256

    if [ ! -f "$fichier" ]; then
        echo "Erreur : $fichier introuvable" >&2
        return 1
    fi

    "${algo}sum" "$fichier"
}

# Usage
hash_fichier image.E01
hash_fichier image.E01 md5
  • $1, $2... : arguments positionnels
  • $# : nombre d'arguments
  • $@ : tous les arguments
  • local var : variable locale à la fonction
  • return 0 : succès, return 1+ : erreur

15 Gestion des erreurs (set -e, set -u, pipefail)

Par défaut, bash continue même si une commande échoue. Dangereux en script DFIR.

Les 3 options de robustesse

bash
#!/bin/bash
set -e          # Arrête si une commande échoue
set -u          # Arrête si variable non définie
set -o pipefail # Arrête si un élément du pipe échoue

# Combiné en une ligne :
set -euo pipefail

Avec ces options, un script s'arrête immédiatement à la première erreur au lieu de continuer en silence.

Trap pour le nettoyage

bash
#!/bin/bash
set -euo pipefail

# Dossier temporaire à nettoyer même en cas d'erreur
tmp_dir=$(mktemp -d)
trap "rm -rf $tmp_dir" EXIT

# ... script qui utilise $tmp_dir ...

trap exécute la commande au moment indiqué (EXIT = à la sortie du script, quelle qu'en soit la raison).

Logging

bash
log() {
    echo "[$(date +%H:%M:%S)] $*"
}

log "Démarrage du triage"
log "Traitement de $fichier"

16 PowerShell intermédiaire — équivalents

Tableau de correspondance

BashPowerShell
cut -d',' -f1,3`... \Select-Object -ExpandProperty col1, col3`
sort -uSort-Object -Unique
uniq -c`Group-Object \Select Name, Count`
wc -lMeasure-Object -Line
grep "motif"Where-Object { $_ -match "motif" }
sed 's/A/B/g'$str -replace 'A','B'

Exemple : top 10 IPs depuis un access.log

Bash :

bash
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -n 10

PowerShell :

powershell
Get-Content access.log |
    ForEach-Object { ($_ -split ' ')[0] } |
    Group-Object |
    Sort-Object Count -Descending |
    Select-Object -First 10 Name, Count

PowerShell est plus verbeux mais plus typé (objets, pas juste du texte). À long terme, c'est un avantage.

17 PowerShell : Where-Object, ForEach-Object, Select-Object

Les 3 cmdlets centraux du pipeline PowerShell.

Where-Object — filtrer

powershell
# Tous les processus utilisant > 100 Mo de mémoire
Get-Process | Where-Object { $_.WS -gt 100MB }

# Alias court :
Get-Process | Where { $_.WS -gt 100MB }
ps | ? { $_.WS -gt 100MB }

ForEach-Object — transformer

powershell
# Hasher tous les fichiers .E01
Get-ChildItem *.E01 | ForEach-Object {
    Get-FileHash $_ -Algorithm SHA256
}

# Alias :
Get-ChildItem *.E01 | foreach { Get-FileHash $_ }
ls *.E01 | % { Get-FileHash $_ }

Select-Object — projeter

powershell
# Garder uniquement certaines propriétés
Get-Process | Select-Object Name, Id, CPU, WS

# Les 10 premiers
Get-Process | Select-Object -First 10

# Avec un calcul
Get-Process | Select-Object Name, @{N='MB';E={[math]::Round($_.WS/1MB, 2)}}

Pattern DFIR PowerShell : top 10 processus consommateurs

powershell
Get-Process |
    Sort-Object WS -Descending |
    Select-Object -First 10 Name, Id, @{N='Memory(MB)';E={[math]::Round($_.WS/1MB)}}

18 Écrire un vrai script de parsing

Mettons tout ensemble. Voici un script bash qui parse un access.log Apache et produit un rapport DFIR.

Bash : analyze_apache.sh

bash
#!/bin/bash
#
# analyze_apache.sh — Analyse forensique d'un access.log Apache
# Usage : ./analyze_apache.sh /var/log/apache2/access.log

set -euo pipefail

# Validation des arguments
if [ $# -ne 1 ]; then
    echo "Usage: $0 <access.log>" >&2
    exit 1
fi

LOG_FILE="$1"

if [ ! -f "$LOG_FILE" ]; then
    echo "Erreur: fichier $LOG_FILE introuvable" >&2
    exit 1
fi

# Dossier de rapport
REPORT_DIR="report_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$REPORT_DIR"

log() {
    echo "[$(date +%H:%M:%S)] $*"
}

log "Analyse de $LOG_FILE"
log "Rapport dans $REPORT_DIR/"

# 1. Statistiques générales
{
    echo "=== Statistiques générales ==="
    echo "Total de lignes : $(wc -l < "$LOG_FILE")"
    echo "Taille : $(du -h "$LOG_FILE" | cut -f1)"
    echo "Période :"
    head -n 1 "$LOG_FILE" | awk '{print "  Début:", $4}'
    tail -n 1 "$LOG_FILE" | awk '{print "  Fin:  ", $4}'
} > "$REPORT_DIR/stats.txt"

# 2. Top 20 IPs
log "Top 20 IPs"
awk '{print $1}' "$LOG_FILE" | sort | uniq -c | sort -rn | head -n 20 > "$REPORT_DIR/top_ips.txt"

# 3. Codes HTTP
log "Codes HTTP"
awk '{print $9}' "$LOG_FILE" | sort | uniq -c | sort -rn > "$REPORT_DIR/http_codes.txt"

# 4. URLs les plus consultées
log "Top URLs"
awk '{print $7}' "$LOG_FILE" | sort | uniq -c | sort -rn | head -n 20 > "$REPORT_DIR/top_urls.txt"

# 5. User-Agents suspects (PowerShell, curl en User-Agent)
log "User-Agents suspects"
grep -E -i "(powershell|curl|wget|python-requests|sqlmap|nikto|nmap)" "$LOG_FILE" > "$REPORT_DIR/suspicious_ua.txt" || true

# 6. Erreurs 5xx (problèmes serveur)
log "Erreurs 5xx"
awk '$9 ~ /^5/ {print}' "$LOG_FILE" > "$REPORT_DIR/server_errors.txt"

# 7. Activité par heure
log "Activité par heure"
awk '{print substr($4, 14, 2)}' "$LOG_FILE" | sort | uniq -c | sort -k2 > "$REPORT_DIR/activity_per_hour.txt"

# 8. Manifest
log "Manifest"
cd "$REPORT_DIR"
sha256sum * > MANIFEST_SHA256.txt
cd - > /dev/null

log "Terminé."
ls -lh "$REPORT_DIR/"

Exécuter

bash
chmod +x analyze_apache.sh
./analyze_apache.sh /var/log/apache2/access.log

Équivalent PowerShell : Analyze-Apache.ps1

powershell
<#
.SYNOPSIS
    Analyse forensique d'un access.log Apache
.EXAMPLE
    .\Analyze-Apache.ps1 -LogPath C:\logs\access.log
#>

param(
    [Parameter(Mandatory)]
    [string]$LogPath
)

$ErrorActionPreference = 'Stop'

if (-not (Test-Path $LogPath)) {
    Write-Error "Fichier $LogPath introuvable"
    exit 1
}

$ReportDir = "report_$(Get-Date -Format yyyyMMdd_HHmmss)"
New-Item -ItemType Directory -Path $ReportDir | Out-Null

function Log { param($Msg); Write-Host "[$((Get-Date).ToString('HH:mm:ss'))] $Msg" }

Log "Analyse de $LogPath"
$lines = Get-Content $LogPath

# Stats
Log "Statistiques"
@"
=== Statistiques générales ===
Total de lignes : $($lines.Count)
Taille : $((Get-Item $LogPath).Length / 1KB) Ko
"@ | Out-File "$ReportDir/stats.txt"

# Top 20 IPs
Log "Top 20 IPs"
$lines | ForEach-Object { ($_ -split ' ')[0] } |
    Group-Object | Sort-Object Count -Descending |
    Select-Object -First 20 |
    Format-Table Count, Name | Out-File "$ReportDir/top_ips.txt"

# Codes HTTP
Log "Codes HTTP"
$lines | ForEach-Object { ($_ -split ' ')[8] } |
    Group-Object | Sort-Object Count -Descending |
    Format-Table Count, Name | Out-File "$ReportDir/http_codes.txt"

# Manifest
Log "Manifest"
Get-ChildItem $ReportDir -File | Get-FileHash -Algorithm SHA256 |
    Export-Csv "$ReportDir/MANIFEST_SHA256.csv" -NoTypeInformation

Log "Terminé. Rapport dans $ReportDir/"
Get-ChildItem $ReportDir

19 Bonnes pratiques DFIR

🔹 Toujours set -euo pipefail en début de script bash. Sécurité.

🔹 Quoter les variables : "$var", jamais $var nu. Les espaces et caractères spéciaux cassent tout sinon.

🔹 Tester avant le -delete ou rm -rf : remplacer par -print ou echo pour vérifier.

🔹 Loguer chaque action dans un fichier journal du script. Reproductibilité judiciaire.

🔹 Préférer find avec -print0 et xargs -0 pour gérer les noms avec espaces.

🔹 Hashes systématiques : ajouter une étape hash en fin de chaque script de collecte.

🔹 Tests sur VM avant production. Un sed -i mal placé peut détruire des preuves.

🔹 Garder un journal des pipelines utiles que tu découvres — futur cheat sheet personnel.

🔹 Lire les manpages : man awk, man sed. Souvent dense mais riche.

🔹 PowerShell : préférer les cmdlets aux alias dans les scripts (Get-ChildItem plutôt que ls) pour la lisibilité.

🔹 Versionner ses scripts : Git, même un repo personnel local. Récupérer une commande oubliée vaut souvent une heure de travail.

🔹 Apprendre awk progressivement : un nouvel idiome par semaine. C'est l'outil qui transforme un analyste.
