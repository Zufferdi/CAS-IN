🌱 Autopsy débutant — Première prise en main

À la fin de ce tutoriel, tu sauras installer Autopsy, créer ton premier cas, importer une image disque (.E01), comprendre les modules d'ingest essentiels (Recent Activity, Hash Lookup, Picture Analyzer, Keyword Search), naviguer dans l'arbre de résultats (Data Sources, Views, Results, Tags), faire une recherche par mot-clé, tagger des éléments importants, et générer un rapport HTML présentable. Tutoriel pédagogique zéro prérequis DFIR.
🎯 Niveau débutant ⏱ ~50 min 🪟 Windows 🐧 Linux 🌱 Zéro prérequis DFIR 📚 Pédagogique
ℹ️ Tutoriel pour débutants totaux en DFIR
Ce tutoriel est conçu pour la première utilisation d'Autopsy. Aucun prérequis DFIR. Tu vas créer ton premier cas, importer une image, lancer l'analyse et générer ton premier rapport.

Une fois à l'aise, passe au tutoriel Autopsy standard (v124) pour la vision complète, puis Autopsy avancé (v129) pour les techniques expertes.

01 À qui s'adresse ce tutoriel

Ce tutoriel est pour toi si :

  • Tu n'as jamais utilisé Autopsy
  • Tu débutes en DFIR ou en informatique forensique
  • Tu veux comprendre la logique d'une analyse de disque avant de plonger dans les outils CLI
  • Tu prépares une certification DFIR (CCFE, GCFE, CHFI, etc.) et besoin d'une base pratique
  • Tu fais partie d'une formation étudiante ou stagiaire en DFIR

Ce tutoriel ne couvre pas :

  • Le carving avancé, les plugins custom, le scripting Python (→ Autopsy avancé)
  • Les techniques très spécifiques (mobile via Android Analyzer, iOS, etc.)
  • L'intégration Volatility / Plaso au sein d'Autopsy

Pour ces sujets, voir le tutoriel Autopsy avancé.

02 Qu'est-ce qu'Autopsy

Autopsy est un logiciel gratuit et open source qui permet d'analyser le contenu d'un disque dur ou d'une image disque sans avoir à le monter sur ton système. Il est utilisé par :

  • Forces de l'ordre dans le monde entier
  • Cabinets d'audit et entreprises de cybersécurité
  • Étudiants en formation DFIR
  • Particuliers qui font leur propre récupération de données

Ce qu'Autopsy sait faire (en simple)

  • Ouvrir une image disque (.E01, .dd, .raw, .vmdk, ...)
  • Lister tous les fichiers (y compris ceux supprimés)
  • Reconstituer l'historique de navigation, les emails, les pièces jointes
  • Trouver les photos, vidéos, documents automatiquement
  • Détecter les fichiers EXIF, géolocalisations, métadonnées
  • Repérer les fichiers chiffrés ou suspects
  • Indexer le contenu pour la recherche par mot-clé
  • Générer un rapport lisible

Ce qu'Autopsy n'est PAS

  • ❌ Un outil de récupération de données grand public (utilise plutôt PhotoRec, Recuva).
  • ❌ Un outil de diagnostic disque (pour ça, S.M.A.R.T., CrystalDiskInfo).
  • ❌ Un outil d'investigation réseau (utilise Wireshark, Zeek).
  • ❌ Un outil de mémoire vive (utilise Volatility, MemProcFS).

Autopsy ne touche que les disques (ou copies de disques).

03 Vocabulaire DFIR essentiel

Voici les mots que tu vas rencontrer :

MotDéfinition simple
Image disqueCopie binaire fichier-pour-fichier d'un disque dur, sous forme d'un gros fichier (.E01, .dd, .raw).
Source de donnéesDans Autopsy, c'est l'image disque (ou le disque physique) que tu vas analyser.
Cas (case)Dossier de travail pour une enquête. Un cas peut contenir plusieurs sources de données.
Ingest moduleModule qui analyse automatiquement la source de données (extraction navigateurs, EXIF, etc.).
ArtefactTrace numérique trouvée par Autopsy (un historique, un email, une photo, un fichier chiffré).
CarvingRécupérer des fichiers supprimés en cherchant leur "signature" sur le disque.
MFT (Master File Table)Index Windows qui liste tous les fichiers d'une partition NTFS. Une mine d'or DFIR.
TimelineChronologie reconstituée de l'activité (création, modification, accès aux fichiers).
TagMarqueur (étiquette) que tu poses sur un fichier intéressant.
BookmarkSynonyme de tag dans Autopsy.
HashEmpreinte numérique unique d'un fichier (MD5, SHA-1, SHA-256).
EXIFMétadonnées dans une photo (date, GPS, appareil photo).
💡 Astuce
ne pas essayer de mémoriser tout d'un coup. Reviens à ce tableau quand tu rencontres un mot inconnu dans l'interface.

04 Installation pas à pas (Windows)

Étape 1 : prérequis

  • Windows 10 ou 11 64 bits
  • 8 Go de RAM minimum (16 recommandés)
  • 50 Go d'espace disque libre (pour le cas + l'image de test)

Étape 2 : téléchargement

  1. Aller sur <https://www.autopsy.com/download/>
  2. Cliquer sur Autopsy x.x.x for Windows 64-bit (la dernière version)
  3. Lancer l'installeur .msi téléchargé

Étape 3 : installation guidée

L'installeur est classique « Next, Next, Finish ». Quelques points d'attention :

  • Emplacement : laisser C:\Program Files\Autopsy-X.X.X\.
  • Java : Autopsy inclut son propre Java. Ne pas désinstaller ce Java.
  • Pare-feu : si Windows demande, autoriser Autopsy (uniquement pour les fonctions réseau locales).

Étape 4 : vérifier l'installation

Double-cliquer sur le raccourci Autopsy sur le Bureau. Au premier lancement, Autopsy crée des dossiers de configuration dans %APPDATA%. Patiente 30-60 secondes.

L'écran d'accueil s'ouvre. Bravo, c'est installé.

05 Installation pas à pas (Linux)

Autopsy fonctionne sous Linux mais l'installation est plus technique (compilation depuis sources).

Méthode rapide : machine virtuelle

Solution pour débutant : utiliser la VM CSI Linux ou Tsurugi Linux, qui ont Autopsy préinstallé.

  • CSI Linux : <https://csilinux.com/>
  • Tsurugi Linux : <https://tsurugi-linux.org/>

Méthode native (avancée)

bash
# Installer SleuthKit (le moteur)
sudo apt install -y sleuthkit libtsk-dev

# Java
sudo apt install -y openjdk-17-jdk

# Télécharger Autopsy
cd /opt
sudo wget https://github.com/sleuthkit/autopsy/releases/latest/download/autopsy-X.X.X.zip
sudo unzip autopsy-X.X.X.zip
cd autopsy-X.X.X
./unix_setup.sh

Lancer

bash
cd /opt/autopsy-X.X.X/bin
./autopsy
💡 Astuce
, préférer la machine virtuelle CSI Linux ou Tsurugi. Tout est prêt, pas de configuration.

06 Premier lancement et tour d'horizon

L'écran d'accueil propose trois choix :

  1. Create New Case : créer un nouveau cas
  2. Open Recent Case : rouvrir un cas existant
  3. Open Case : ouvrir un cas depuis un fichier .aut

Pour ce premier tutoriel : on va créer un nouveau cas. Mais avant, on a besoin d'une image disque de test.

07 Préparer une image de test

Pour s'entraîner, on utilise une image disque pédagogique publique.

Option A : Digital Corpora (recommandé pour débuter)

<https://digitalcorpora.org/corpora/scenarios/>

  • Cas pédagogiques gratuits avec scénarios documentés
  • Image m57-jean : 30 jours d'activité d'une employée fictive
  • Format : .E01 ou .aff

Option B : NIST CFReDS

<https://www.cfreds.nist.gov/>

Images de référence avec questions et solutions.

Option C : créer sa propre image (recommandé pour la formation)

Sur une vieille clé USB ou un disque qu'on n'utilise plus :

  1. Formater le disque
  2. Y placer quelques fichiers (Word, PDF, photos)
  3. Supprimer une partie
  4. Imager avec FTK Imager (cf. tutoriel FTK Imager v126)

Tu disposes ainsi d'une image que tu connais déjà — idéal pour vérifier que tu trouves ce que tu attends.

Format à privilégier

  • .E01 (EWF Expert Witness Format) : standard forensique, contient hash et métadonnées.
  • .dd ou .raw : copie brute, plus simple.
💡 Astuce
Tutoriel : on suppose que tu as un fichier image_test.E01 à disposition. Si tu en as un autre format, tout fonctionne pareil.

09 Ajouter une source de données (Data Source)

L'assistant te propose immédiatement d'ajouter une source de données. Si tu l'as fermé, refaire depuis le menu : Case → Add Data Source.

Étape 1 : choisir le type

TypeQuand l'utiliser
Disk Image or VM FileUne image .E01, .dd, .raw, .vmdk
Local DiskUn disque physique encore branché (RARE en DFIR pro)
Logical FilesUn dossier ou des fichiers spécifiques
Unallocated Space Image FileUn fichier ne contenant que l'espace non alloué
Autopsy Logical Imager ResultsRésultat d'une collecte logique préalable

Choisir Disk Image or VM File. Cliquer Next.

Étape 2 : sélectionner le fichier

Cliquer Browse, puis sélectionner ton image_test.E01.

Time zone : très important. Mettre la timezone où l'image a été créée (par exemple Europe/Zurich). Si tu ne sais pas, laisser (GMT-0:00) UTC.

Étape 3 : valider et passer aux ingest modules

Cliquer Next. Autopsy te propose de configurer les ingest modules.

10 Les modules d'ingest expliqués

C'est ici que la magie opère. Les modules d'ingest sont des analyseurs automatiques qui parcourent l'image.

Modules essentiels (cocher pour démarrer)

ModuleCe qu'il fait
Recent ActivityHistorique navigateur, fichiers récents, USB connectés, programmes installés
Hash LookupCompare les fichiers avec des bases de hashs (NSRL pour fichiers connus, hashs custom pour IoCs)
File Type IdentificationDétecte le vrai type de fichier (extension trompeuse repérée)
Embedded File ExtractorExtrait les fichiers contenus dans des archives (.zip, .7z, etc.)
Picture AnalyzerEXIF des photos (date, géolocalisation, appareil)
Keyword SearchIndexe tout le texte pour recherche par mot-clé
Email ParserParse les .pst, .mbox, .eml
Encryption DetectionRepère les fichiers chiffrés
Interesting Files IdentifierDétecte des patterns "intéressants" (configurations connues, etc.)
PhotoRec CarverRécupère les fichiers supprimés par carving
Android AnalyzerPour les images Android
iOS AnalyzerPour les images iOS
Plaso (super-timeline)Génère une super-timeline complète (long)

Pour ce TP

Coche au moins :

  • ✅ Recent Activity
  • ✅ Hash Lookup
  • ✅ File Type Identification
  • ✅ Picture Analyzer
  • ✅ Keyword Search
  • ✅ Encryption Detection

Décoche (pour gagner du temps) :

  • ❌ PhotoRec Carver (long)
  • ❌ Plaso (long)

Cliquer Next, puis Finish.

💡 Astuce
pour un premier TP, mieux vaut une analyse rapide (30 min) avec les modules essentiels qu'une analyse complète (8 h) où tu attends.

11 Lancer l'analyse et patienter

L'analyse démarre. En bas à droite, une barre de progression s'anime.

Pendant l'analyse

  • Tu peux commencer à explorer : les résultats s'ajoutent au fur et à mesure.
  • Pour une clé USB de 8 Go : 5-15 minutes.
  • Pour un disque dur de 500 Go : 2-8 heures.
  • Pour un disque chiffré : Autopsy détectera le chiffrement et ne pourra pas l'analyser sans la clé.

Suivi

Menu Tools → Status affiche l'avancement des modules.

💡 Astuce
pendant ta première analyse, laisse Autopsy travailler sans intervenir. Profite pour relire ce tutoriel.

12 Comprendre l'interface des résultats

Quand l'analyse est terminée (ou en cours), tu vois l'interface principale en 3 zones :

shell
┌──────────────────────────────────────────────────────────────┐
│ 1) Arbre (gauche)  │ 2) Liste (centre)   │ 3) Détails (bas) │
│                    │                     │                  │
│  Data Sources      │  [Liste des items   │   [Détails de    │
│  ├ Views           │   du nœud           │    l'élément     │
│  ├ Results         │   sélectionné       │    sélectionné   │
│  ├ Tags            │   à gauche]         │    dans la liste]│
│  └ Reports         │                     │                  │
└──────────────────────────────────────────────────────────────┘

1) Arbre de gauche

Tous les éléments analysés sont catégorisés :

  • Data Sources : structure du disque (volumes, fichiers, supprimés)
  • Views : vues thématiques (par type de fichier, dates, taille)
  • Results : ce que les modules ont trouvé (Recent Activity, EXIF, Web History, etc.)
  • Tags : tes propres marqueurs
  • Reports : rapports générés

2) Liste centrale

Affiche le contenu du nœud sélectionné dans l'arbre. Colonnes courantes : Name, Modified Time, Size, MD5.

3) Détails bas

Onglets : Hex, Strings, File Metadata, Picture preview (si image), Text (extraction texte), Other Occurrences.

Tu peux trier par date, filtrer, rechercher.

14 Première recherche par mot-clé

Imagine que tu cherches le mot "facture" sur tout le disque.

Lancer la recherche

  1. En haut à droite, barre de recherche (loupe).
  2. Taper facture et appuyer Enter.
  3. Choisir le mode : Exact match, Substring match (substring est plus permissif).

Résultats

Une nouvelle entrée apparaît dans Results → Keyword Hits. Cliquer dessus pour voir :

  • Tous les fichiers contenant "facture"
  • Position dans le fichier
  • Contexte (extraction de texte)

Recherches avancées (préliminaire)

  • @example.com (expression entre quotes)
  • Listes de mots : Tools → Keyword Search Settings → Keyword List. Importer une liste de mots-clés (par exemple termes financiers d'un cas de fraude).

15 Marquer des éléments (tagging)

Quand tu trouves un élément important, marque-le.

Tagger un fichier

  1. Cliquer-droit sur un fichier dans la liste centrale.
  2. Add File Tag → choisir un tag existant (Important, Follow-up, Bookmark, etc.) ou en créer un.

Le fichier apparaît maintenant dans Tags → [nom du tag].

Pourquoi tagger ?

  • Retrouver rapidement les éléments importants.
  • Les inclure dans un rapport (Autopsy peut filtrer le rapport sur les éléments taggés).
  • Documenter ta pensée : tags = trace de ton raisonnement.

Tags prédéfinis utiles

TagUsage
BookmarkTrouvé intéressant, à revoir
Follow UpNécessite une investigation complémentaire
Notable ItemÉlément clé de l'enquête
EvidencePièce de procédure formalisée (à utiliser avec parcimonie)
💡 Astuce
ne taggue pas tout. Si tu taggues 200 items, tu te perds. Mieux : 5-20 tags réellement signifiants.

Fermer

Rouvrir

18 Pièges classiques du débutant

🪤 Lancer tous les modules d'ingest : analyse interminable. Mieux : sélectionner ceux qui sont utiles à ton cas.

🪤 Travailler sur l'image originale : toujours faire une copie de travail. Imager le disque physique avec FTK Imager (cf. tutoriel v126) AVANT d'ouvrir dans Autopsy.

🪤 Ne pas vérifier le hash : avant analyse, comparer le hash de l'image avec celui du disque physique. Garantit l'intégrité de la preuve.

🪤 Oublier la timezone : analyser une image canadienne en croyant qu'elle est en UTC → toutes les dates sont fausses.

🪤 Ignorer les fichiers supprimés : View → Deleted Files contient souvent l'élément clé du cas. Toujours y aller.

🪤 Faire confiance aveuglément aux modules : un module peut manquer un artefact. Vérifier manuellement les zones critiques.

🪤 Travailler sur poste connecté à Internet : risque que Windows Defender supprime un fichier suspect en cours d'analyse. Mettre la machine offline pour l'analyse.

🪤 Stocker le cas sur le même disque que l'image : performance dégradée, risque de perte. Mieux : cas sur SSD interne rapide, image sur disque externe.

🪤 Ne pas documenter ce qu'on fait : prendre des notes pendant l'analyse. Tags + notes dans le cas = traçabilité.

🪤 Oublier de sauvegarder les rapports : Reports/ est dans le cas mais aussi à archiver à part.

19 Bonnes pratiques pour bien démarrer

🔹 Toujours travailler sur copie, jamais sur le disque original.

🔹 Hasher l'image avant et après analyse (SHA-256). Documenter.

🔹 Documenter le cas dès la création : numéro, examinateur, dates, contexte.

🔹 Choisir la bonne timezone au moment d'ajouter la source.

🔹 Commencer par les modules essentiels : Recent Activity, Hash Lookup, File Type, Picture Analyzer, Keyword Search, Encryption Detection.

🔹 Tagger judicieusement : 5-20 tags signifiants > 200 tags noyés.

🔹 Vérifier les fichiers supprimés systématiquement.

🔹 Croiser avec d'autres outils : la timeline Plaso (v124), le memory dump Volatility (v124), le triage KAPE (v125). Autopsy ne fait pas tout.

🔹 Rapport intermédiaire régulier (HTML) pour partager ton avancement.

🔹 Apprendre les raccourcis : F5 (refresh), Ctrl+F (search), Tab (changer de panneau).

🔹 Sauvegarder le cas sur un disque externe en fin de journée.

🔹 Prendre des notes manuscrites en parallèle — utile pour les audits et procès.

🔹 Ne pas presser : DFIR est une discipline lente. Mieux vaut une analyse soignée qu'une rapide qui rate l'essentiel.

🔹 Faire un point régulier : « qu'est-ce que je cherche, est-ce que j'ai trouvé ? » Ne pas se noyer dans les détails.

🔹 Apprendre progressivement : ce tutoriel + le tutoriel Autopsy standard (v124) + le tutoriel Autopsy avancé quand tu seras à l'aise.

21 Conclusion

Tu as créé ton premier cas Autopsy, ajouté une source de données, lancé les modules d'ingest, navigué dans les résultats, fait une recherche, tagué des éléments et généré un rapport HTML.

Ce sont les 5 actions fondamentales d'un analyste DFIR. Tu as franchi la marche du débutant total.

Recommandations pour la suite :

  1. Refaire ce TP avec ta propre image (clé USB de test) — la maîtrise vient avec la répétition.
  2. Compléter avec le tutoriel Autopsy standard (v124) pour une vision exhaustive de tous les modules.
  3. Apprendre Bases CLI (v127) en parallèle : tu utiliseras tsk_*, mactime, et autres outils CLI complémentaires.
  4. Faire un CTF DFIR débutant (Cyber Defenders, DFIR Diva) pour pratiquer sur un vrai cas.
  5. Lire Brian Carrier quand tu seras prêt — c'est la référence académique.

Le DFIR est une discipline qui récompense la patience. Bonne analyse ! 🔬
