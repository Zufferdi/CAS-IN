🌿 IPED débutant — Première prise en main pédagogique

À la fin de ce tutoriel, tu sauras installer IPED (outil DFIR open source de la Police Fédérale brésilienne), créer ton premier cas, importer une image disque, lancer l'indexation Lucene, naviguer dans les catégories automatiques, faire une recherche par mot-clé Lucene, exploiter l'OCR intégré (atout d'IPED), marquer des bookmarks et générer un rapport HTML.
🎯 Niveau débutant ⏱ ~45 min 🪟 Windows 🐧 Linux 🌿 Zéro prérequis DFIR 🔍 OCR intégré
ℹ️ Tutoriel zéro prérequis DFIR — pendant IPED de Autopsy débutant (v129)
IPED est l'équivalent brésilien d'Autopsy. Tutoriel pédagogique pour première utilisation. Vocabulaire DFIR essentiel inclus en §4. Une fois à l'aise, passe au tutoriel IPED standard (v124, niveau moyen) puis IPED avancé (v130) pour les techniques expertes.

01 À qui s'adresse ce tutoriel

Ce tutoriel est pour toi si :

  • Tu n'as jamais utilisé IPED
  • Tu débutes en DFIR ou tu connais Autopsy mais pas IPED
  • Tu veux comprendre pourquoi IPED est utilisé dans les services pro
  • Tu prépares une certification DFIR avec exposition aux outils brésiliens
  • Tu travailles sur des cas avec beaucoup de documents scannés (l'OCR d'IPED est un atout majeur)

Si tu connais déjà IPED : passe au tutoriel IPED standard (v124) ou IPED avancé (v130).

02 Qu'est-ce qu'IPED

IPED est l'équivalent brésilien d'Autopsy : un outil open source d'analyse forensique de disques. Particularités :

  • Développé par la Police Fédérale brésilienne (DPF / Departamento de Polícia Federal)
  • Utilisé en production par des forces de l'ordre et services pro
  • Java : fonctionne partout (Windows, Linux, macOS)
  • Rapide : indexation Lucene très optimisée
  • OCR intégré : reconnaît le texte dans les images (PDF scannés, captures d'écran)
  • Open source EPL 2.0

Ce qu'IPED sait faire

  • Indexer une image disque (.E01, .dd, .raw)
  • Extraire tout le contenu textuel des fichiers (Word, PDF, EML, OCR images)
  • Catégoriser automatiquement (images, vidéos, emails, fichiers chiffrés...)
  • Détecter les doublons par hash
  • Rechercher par mot-clé, regex, métadonnées EXIF, dates
  • Comparer avec NSRL et autres bases de hashs
  • Générer un rapport HTML présentable
  • Galerie d'images avec filtrage rapide

Ce qu'IPED n'est PAS

  • ❌ Un outil de mémoire (utilise Volatility)
  • ❌ Un outil réseau (utilise Wireshark, Zeek)
  • ❌ Un outil mobile dédié (a un support partiel via Android Analyzer)

03 IPED vs Autopsy — quand choisir lequel

AspectIPEDAutopsy
OriginePolice Fédérale brésilienneBasis Technology (US)
CommunautéPlus restreinteTrès large (50k+ stars)
IndexationPlus rapide sur gros volumesBonne
OCR intégréExcellent (Tesseract intégré, multi-langues)Limité
Détection doublonsNative, performanteVia Hash Lookup
Galerie d'imagesTrès ergonomiqueCorrecte
PluginsJava seulement (pas Python custom)Jython 2.7 custom
Documentation FRLimitée (anglais/portugais)Plus disponible
Multi-userNonOui (PostgreSQL+Solr)

Règle pratique :

  • Cas avec beaucoup de PDF scannés (fraude documentaire, espionnage industriel) : IPED (OCR puissant)
  • Cas Windows classique avec besoins de plugins custom : Autopsy
  • Cas en équipe (multi-utilisateurs) : Autopsy (mode multi-user)
  • Cas où la vitesse d'indexation prime (très gros volumes) : IPED

Idéalement : les deux installés. Beaucoup d'analystes croisent les résultats.

06 Installation sous Windows

Étape 1 : téléchargement

  1. Aller sur <https://github.com/sepinf-inc/IPED/releases>
  2. Télécharger iped-X.Y.Z.zip (la dernière release stable)
  3. Décompresser dans C:\Tools\IPED\

IPED n'a pas d'installeur classique — c'est un dossier auto-contenu avec Java embarqué.

Étape 2 : structure du dossier

shell
C:\Tools\IPED\
├── iped.exe              ← lanceur principal
├── iped.bat              ← lanceur alternatif (batch)
├── jre\                  ← Java embarqué
├── lib\                  ← bibliothèques
├── conf\                 ← configuration
├── htm\                  ← templates rapports
└── README.md

Étape 3 : vérification

Ouvrir cmd ou PowerShell dans C:\Tools\IPED\ :

cmd
iped.exe --version

Doit afficher la version.

Étape 4 : antivirus

Comme tous les outils forensiques, IPED peut être flagué (parsers de fichiers exotiques). Autoriser dans Windows Defender.

07 Installation sous Linux

Méthode standard

bash
# Dépendances
sudo apt update
sudo apt install -y openjdk-17-jdk

# Téléchargement
cd /opt
sudo wget https://github.com/sepinf-inc/IPED/releases/latest/download/iped-X.Y.Z.zip
sudo unzip iped-X.Y.Z.zip
cd iped-X.Y.Z

# Test
./iped.sh --version

VM préinstallée

Pour débuter, CSI Linux ou Tsurugi Linux ont IPED préinstallé.

💡 Astuce
IPED est un projet Java. Sur Linux, vérifier la version Java (java --version) — JDK 17+ requis.

08 Premier lancement et structure

Double-cliquer sur iped.exe (Windows) ou lancer iped.sh (Linux).

L'interface IPED s'ouvre avec un message d'accueil. Premier choix :

  1. Process new evidence : créer un nouveau cas
  2. Open existing case : ouvrir un cas existant

Pour ce tutoriel : Process new evidence.

  • Add Disk Image → image_test.E01

Cliquer Start ou Process.

11 Lancer l'indexation

IPED commence à parcourir l'image. Plusieurs phases :

  1. Mounting : monte l'image en lecture seule
  2. Enumeration : liste tous les fichiers
  3. Extraction : extrait le contenu de chaque fichier
  4. OCR : applique Tesseract sur les images de texte
  5. Indexing : construit l'index Lucene
  6. Categorization : classe par catégories

Durée typique

ImageDurée approximative
Clé USB 8 Go5-15 min
Disque dur 500 Go classique4-8 h
500 Go avec beaucoup d'images (OCR intense)12-24 h

Suivi

Pendant l'indexation, une fenêtre de progression affiche :

  • Pourcentage global
  • Module en cours (OCR, carving, etc.)
  • Fichiers traités par seconde
  • ETA

Tu peux interrompre (Ctrl+C ou bouton Stop) et reprendre — IPED supporte la reprise.

💡 Astuce
pour le premier TP, démarrer avec une petite image (clé USB ≤ 8 Go) pour voir le processus en entier.

13 Première recherche par mot-clé

Syntaxe Lucene

IPED utilise Lucene query syntax dans la barre de recherche :

shell
facture                        → mots contenant "facture"
"facture salariale"            → expression exacte
facture OR ticket              → l'un ou l'autre
facture AND 2026               → les deux
facture NOT brouillon          → facture sans brouillon
factu*                         → wildcard
?acture                        → 1 caractère wildcard

Exemple : chercher des emails contenant "contrat"

  1. Cliquer sur la catégorie Emails à gauche
  2. Dans la barre de recherche : contrat
  3. Appuyer Enter

Tu vois la liste filtrée des emails contenant "contrat".

Regex

Pour les regex (IPs, emails, hashs) :

shell
/[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/
/[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}/i

Encadrer la regex avec /.../. Le suffix i rend insensible à la casse.

Recherche avancée

Menu Search → Advanced Search ouvre un formulaire structuré : par taille, dates, type de fichier, hash, etc.

Galerie d'images

C'est l'un des atouts d'IPED. Clic sur Images → vignettes en grille.

Tu peux :

  • Filtrer par taille, date, source
  • Zoomer d'un clic
  • Sélectionner plusieurs images pour bookmark
  • Comparer visuellement rapidement

Très utile pour les cas avec beaucoup d'images à examiner.

15 Marquer des bookmarks

Quand tu trouves un élément important, bookmarker le pour le retrouver et l'inclure au rapport.

Bookmarker un fichier

  1. Sélectionner le fichier dans la liste
  2. Clic droit → Add to bookmark → choisir ou créer un bookmark
  3. Le bookmark apparaît dans la catégorie Bookmarks à gauche

Bookmarks prédéfinis

  • Important : élément clé
  • Follow-up : à investiguer plus
  • Suspect : suspect, à analyser

Tu peux créer tes propres bookmarks personnalisés (Manage Bookmarks).

Discipline

Comme pour Autopsy : 5-20 bookmarks signifiants > 200 noyés.

16 L'OCR intégré — atout d'IPED

L'OCR (Optical Character Recognition) est ce qui différencie le plus IPED d'Autopsy.

Comment ça marche

Pour chaque image trouvée (.jpg, .png, .pdf scanné), IPED applique Tesseract (moteur OCR Google) et indexe le texte reconnu.

Résultat : un PDF scanné de 50 pages est recherchable par mot-clé comme un PDF texte natif.

Cas DFIR

  • Fraude documentaire : recherche dans des factures, contrats scannés
  • Espionnage industriel : photos d'écran de documents confidentiels
  • Pédopornographie : recherche de texte dans des images modifiées (ex : insertion d'identifiants)
  • Communications cryptées : screenshots de conversations qui contournent les sauvegardes

Langues supportées

Tesseract supporte 100+ langues. Par défaut, IPED active anglais + langue de l'OS. Ajouter d'autres langues dans la config :

conf/LocalConfig.txt :

shell
ocrLanguage = eng+fra+deu+ita

Plus de langues = plus précis mais plus lent.

Performance

L'OCR est lent (de loin l'étape la plus chronophage). Sur un cas avec beaucoup d'images :

  • Désactiver l'OCR si pas nécessaire (cas Linux/serveur avec peu d'images) : enableOCR = false
  • Limiter aux images > taille minimale (évite OCR sur miniatures, icônes)

Lancer la génération

Menu Tools → Generate Report ou bouton dédié.

Include thumbnailsAvec vignettes images

Format

IPED génère un rapport HTML interactif, similaire à Autopsy :

  • Page d'accueil
  • Liste des bookmarks avec liens vers détails
  • Galeries d'images
  • Tableaux d'artefacts

Le HTML est autonome (CSS/JS embarqués), partageable par email ou USB.

Pour la procédure

Convertir en PDF (impression depuis le navigateur), hasher, joindre au dossier.

18 Fermer et rouvrir un cas

Fermer

Fermer simplement la fenêtre IPED ou menu File → Close case.

Rouvrir

Au lancement : Open existing case → naviguer vers le dossier du cas.

Le cas IPED est dans le Case Output Folder (D:\Cases\IPED\TP01_IPED\). Structure :

shell
TP01_IPED/
├── iped/                  ← métadonnées IPED + index Lucene
├── indexador/             ← index principal
├── htm/                   ← rapports HTML générés
├── thumbs/                ← vignettes images
└── log.txt                ← log d'indexation

Important : ne pas déplacer ce dossier (chemins absolus parfois).

19 Pièges classiques du débutant IPED

🪤 Ne pas allouer assez de RAM : sur cas > 100 Go, IPED plante. Allouer 16 Go minimum dans conf/IPEDConfig.txt :

shell
defaultRamSize = 16G

🪤 Lancer sur disque interne lent : IPED est très intensif disque (index Lucene). SSD NVMe obligatoire pour gros cas.

🪤 Garder l'OCR sur tout : multiplie le temps par 5-10. Désactiver si pas pertinent (cas serveur Linux, par exemple).

🪤 Oublier la langue OCR : avec eng seul sur des documents français, l'OCR rate beaucoup. Ajouter +fra.

🪤 Travailler sur l'image originale : règle DFIR universelle — toujours imager d'abord (cf. FTK Imager v126).

🪤 Confondre catégorie et bookmark : catégorie = auto, bookmark = manuel. Bookmarks sont ton raisonnement, catégories sont la classification IPED.

🪤 Faire confiance aveuglément à la catégorisation : un .exe renommé en .pdf peut tromper IPED. Vérifier les types détectés vs extensions (catégorie "Mismatch" dans certaines versions).

🪤 Ne pas tester l'OCR : sur ta première image, vérifier qu'une image de texte est bien recherchable par mot-clé. Si non, problème de config OCR.

🪤 Ne pas hasher l'image avant analyse. Toujours sha256sum image.E01 avant et après.

🪤 Stocker le cas sur le même disque que l'image : ralentit drastiquement. Séparer.

21 Conclusion

Tu as créé ton premier cas IPED, lancé l'indexation, navigué dans les catégories, fait une recherche Lucene, exploité l'OCR intégré et généré un rapport HTML. Tu maîtrises les bases de l'outil DFIR brésilien.

Recommandations pour la suite :

  1. Refaire ce TP sur ta propre clé USB de test pour ancrer les automatismes.
  2. Comparer avec Autopsy : ouvrir la même image dans les deux outils. Tu verras les forces de chacun.
  3. Passer au tutoriel IPED standard (v124) pour la vision complète des fonctionnalités.
  4. Faire un CTF DFIR (Cyber Defenders) en utilisant IPED comme outil principal.
  5. Lire la doc GitHub d'IPED — riche en exemples de profils custom et tips.

Le DFIR récompense la maîtrise multi-outils. IPED en fait partie. 🔬
